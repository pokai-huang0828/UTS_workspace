## 3. 環境準備：Python / Anaconda / Jupyter

### 3.1 為什麼要會 Python
課程說明：**不需要寫大量程式碼，但需要了解 Python 的基本功能**。Python 既是語言（有語法規則），也是直譯器軟體（讀原始碼並執行指令）。

課程理由：Google、Facebook、Dropbox、Wikipedia、Yahoo!、YouTube 都用 Python；PYPL 指數顯示 Python 近年一直是最受歡迎的程式語言。課程使用 **IPython**（I = interactive，互動式）。

**若不確定自己的 Python 程度**：官方強烈建議完成 Google 的 Python 課程 → <https://developers.google.cn/edu/python?hl=en>

Canvas「Python 新手？」頁內有一份**自我檢測小測驗**（LTI 外嵌，答案不公開、僅供自測）。

### 3.2 Anaconda（官方建議安裝）

**為什麼選 Anaconda**
- 免費且可靠：開源平台，專業領域廣泛使用。
- 跨平台：Windows、Mac、Linux 都相容。
- 一體化：預裝 Python 與常用套件（含 Jupyter Notebook 與常用資料科學函式庫），不必逐一安裝。

**安裝來源**

- 中文說明：<https://anaconda.org.cn/anaconda/install/>

### 3.3 Jupyter Notebook

**是什麼**：可分享的文件，把程式碼、文字說明、資料、3D 模型、圖表與互動控制項整合在一起。適合建立程式原型、探索與視覺化資料、分享想法。可把程式拆成小塊逐塊執行，並在程式旁記錄思路。

**三種啟動方式**
1. **Anaconda Navigator（GUI）**：開 Navigator → 點 Jupyter Notebook 下方的「Launch」→ 瀏覽器自動開啟。
2. **命令列／終端機**：打開命令提示字元（Windows）或終端機（macOS/Linux）→ 輸入 `jupyter notebook` → Enter。
3. **Anaconda Prompt（Windows）**：從開始選單開啟 Anaconda Prompt → 輸入 `jupyter notebook` → Enter。

**基本操作**
- 瀏覽檔案：用檔案瀏覽器移到要建立／開啟 Notebook 的位置。
- 新建：「New」→「Python 3」。
- 開啟既有檔：點任一 `.ipynb` 檔。
- 存檔：`Ctrl+S`（Mac 用 `Cmd+S`），或「File」→「Save」。

**下載課程 Notebook 的流程**：下載 `.ipynb` → 在 Jupyter 檔案瀏覽器移到下載位置 → 點檔案開啟 → 本地執行與修改。

**疑難排解**
- Jupyter 無法啟動 → 確認 Anaconda 安裝正確；安裝後重開機；Windows 請用「Anaconda Prompt」而非一般命令提示字元。
- 瀏覽器沒自動開 → 在終端機輸出找網址，通常是 `http://localhost:8888`，複製貼到瀏覽器。
- 套件匯入錯誤 → Anaconda 已預裝多數常用套件；需要額外套件用 `conda install package-name` 或 `pip install package-name`。

**更多文件**
- Anaconda 文件：<https://docs.anaconda.com/>
- Jupyter Notebook 文件：<https://jupyter-notebook.readthedocs.io/>
- Anaconda 入門指南：<https://www.anaconda.com/docs/getting-started/getting-started>

### 5.2 認識你的同學（迎新活動）
**活動內容**：
1. 用 AI 繪圖工具 DALL·E 創作一件能體現你當前世界觀的作品（需註冊免費帳號）。
2. 靈感參考：<https://www.kimp.io/dall-e2/>（用 DALL·E 2 建立圖像的六項提示）
3. 點「回覆」→「附件」分享你的作品。
4. 用幾句話介紹自己，說明圖像表達什麼、創作體驗如何。

**延伸知識（原文附註）**：此繪圖工具屬「生成式人工智慧」範疇，與應用更廣的 ANI 不同。它用機器學習演算法，依據從既有資料集學到的模式創造新事物，通常用在範例資料集上訓練的神經網路。一般包含兩個網路：**生成器網路**（負責創造）與**判別器網路 discriminator network**（評估新生成的資料，並回饋給生成器幫助其改進）。
