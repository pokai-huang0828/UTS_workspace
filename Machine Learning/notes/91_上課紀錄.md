## ⭐⭐⭐ 資料洩漏：前處理時**測試集要排除在外**

> 這場最技術、也**最直接影響 A3** 的內容。

**原則**：測試集必須**完全獨立**於訓練集。做**缺失值填補**、**正規化（normalization）**時，
**計算用的資料不能包含測試集**。

**老師的例子**：
> 資料 1 到 100，中間缺一個值，用**平均值**補。
> 如果平均值是用**全部資料（含測試集）**算的 → 已經用到測試集的資訊 → **資料洩漏**，之後的評估就**不嚴謹**。

**為什麼**：真實世界裡，未來從市場來的新資料**你事前完全沒見過**。測試集就是在模擬這件事。

## ⭐⭐⭐ k 折交叉驗證（老師用「考試」比喻）

### 流程（老師的數字例子）

1. 120 筆資料 → 先抽 **20 筆當測試集，鎖起來不碰**
2. 剩 100 筆做訓練，用 **5 折**：分 5 份、每份 20 筆
3. 每一輪 **80 筆訓練、20 筆驗證**，輪流換 → 共 5 輪

### ⭐ 考試比喻

| 資料 | 比喻 |
|---|---|
| 訓練折 | **平常讀書** |
| 驗證折 | **模擬考**（5 折 = 考 5 次模擬考） |
| 測試集 | **正式考試** —— 模型**從頭到尾沒見過** |

### 怎麼看結果

- 模型表現 = **5 次的平均**（例：5 次準確率取平均）
- ⭐ 還要看**穩不穩**：用**箱形圖（box plot）**看 5 次結果的分布
  - 5 次都在 80% 左右 → **穩定**，上線後也比較可靠
  - 5 次很分散 → **不穩定**，上線後也不可靠

### 驗證集拿來做什麼：調**超參數**

- 超參數例子：樹的**最大深度**、**節點至少幾筆才繼續分裂**、**max_features**
- 老師的流程：
  1. 用 k 折比較幾個分類器 → 選**表現好又穩定**的（例：隨機森林）
  2. 調它的超參數 → 用**驗證折**確認有沒有變好
  3. 最後用**測試集**（沒參與任何訓練或調參）評估 → 報 FP、FN、準確率等

> ⚠️ 老師一度口誤說「超參數用測試集調」，隨即更正為**驗證集**。
> 👉 **調參 = 驗證集；最終評估 = 測試集。**

## 2️⃣ 線性迴歸：找一條讓 MSE 最小的線

- 例子：**廣告投入（x）→ 銷量**，從散點中找一條最合適的線
- 線畫在哪由 **MSE** 決定：每個實際點到預測線的差值 → 平方 → 平均
- **訓練目標 = 讓 MSE 最小**
- 單一線性迴歸 = **截距 + 一個斜率**（一個特徵）；多元線性迴歸 = 往後加更多 θ 和特徵；**原理一樣**

## 3️⃣ 邏輯迴歸：把線性分數壓成 0～1 的機率

- 聊天室問「邏輯迴歸處理什麼問題？」→ Yonglong、Hsiao-Li：**分類** ✅
- 流程：特徵 → 算出**線性分數** → 經過**邏輯函數（Sigmoid）**映射到 **0～1** → 可理解為「**屬於類別 1 的機率**」
- 再設一個**閾值**，**預設 0.5**：例如 0.78 → 78% 機率 → 大於 0.5 → 歸為類別 1
- 同一類裡的每個點，**機率都不一樣**

### 訓練目標：交叉熵（cross-entropy）

- 交叉熵是**損失函數**：**不只看分對沒有，還看機率離真實標籤多遠**
- 老師的三個點（真實標籤 y = 1）：

| 預測機率 | 分類結果 | 損失 |
|---|---|---|
| 0.9 | 1 ✅ | **非常小** |
| 0.55 | 1 ✅（也分對了） | 稍大一些 |
| 0.05 | 0 ❌ | **非常大** |

- 所有點的損失加總再平均 = 交叉熵；**訓練目標 = 讓交叉熵最小**，夠好就停
- 預測機率越偏離真實值，**懲罰（penalty）越重**（log 曲線）

> **Yonglong 問**：「loss 越接近 1 越好嗎？」
> **老師**：圖上橫軸的 1 是**機率**，不是 loss。y = 1 是真實標籤。以客戶流失為例，y = 1 = 流失，某點代表「模型預測它有 90% 機率流失」。對 y = 1 的點，**預測機率越接近 1 越好、loss 越小越好**。

> 📍 課本對照：[02 §2.5.2](02_單元二_基礎機器學習模型與技術.md)（Sigmoid、閾值 0.5）、§2.5.2.1（交叉熵損失）。

## 4️⃣ 決策樹：選「讓節點更純」的分裂

- 訓練時在學：**用哪個特徵分裂、分裂的閾值是多少** → 選能讓節點**純度更高**的分裂
- **終極目標：用盡量少的節點，分出純度高的節點**
- 例：客戶留存問題 → 希望某個節點裡**全是留存客戶**，不要混流失的；混雜就繼續分

### 課堂問答

| 問題 | 答案 |
|---|---|
| S1 和 S2 哪個**不純度**更高？（S1 只混了 1 個不同類，S2 一半一半） | **S2**（Gengzhong 答對）—— 越混雜，不確定性越高 |
| 不純度越高，資訊熵越高還是越低？ | **越高**（Yonglong 答對）。**資訊熵 = 0 時最純**（節點裡只有一類） |
| 一次好的分裂之後，子節點的資訊熵變高還是變少？ | **變少**（Tung-an 答對；Yonglong 答「變高」「越來越純」，可能是在講純度） |

- **資訊熵和基尼係數基本上是同一個意思**，只是算法略不同，都在量化**節點的混雜程度**

### 資訊增益（information gain）

- 每次分裂：原節點 = **父節點**，分出的兩個 = **子節點**
- **資訊增益 = 父節點的資訊熵 − 子節點資訊熵的加權平均**
- 父節點不純 → 熵大；子節點變純 → 熵小 → 相減為正 = **有資訊增益** = 分裂往好的方向

> 📍 課本對照：[02 §2.5.3.1](02_單元二_基礎機器學習模型與技術.md)（資訊增益 = 父節點熵 − 子節點加權熵）。

## 5️⃣ 參數 vs 超參數、過擬合

- **訓練時**學的：分裂特徵與閾值（參數）
- **調優時**調的：**超參數**（樹的深度、每個節點的樣本數…），用**驗證集**比較後調整
- **調超參數基本上就是在調模型的複雜度**：樹越深越複雜

### 過擬合 vs 欠擬合

- **越複雜的模型越容易過擬合**：會連資料裡的**噪聲**都學進去 → 在**訓練時見過的資料**上很好，**換新資料就變差**（低偏差、高方差）。老師原話是「驗證集時表現都很好」；⚠️ **課本的判斷方式是：訓練集好、驗證／測試集差 = 過擬合**
- **簡單模型**（例：線性迴歸）面對複雜資料：受限於模型本身，**學不到複雜關係**，還是只會找一條直線；換一批資料重練，結果也「大差不差」

> ⚠️ **老師這段有口誤**：她說簡單模型「**偏差會稍微小一些，但方差會比較大**」—— **講反了**。
> 她舉的例子（學不到訓練資料的規律、換資料結果也差不多）描述的正是 **高偏差、低方差**，也就是**欠擬合**。
> ✅ **正確版本**：**簡單模型 = 高偏差、低方差（欠擬合）；複雜模型 = 低偏差、高方差（過擬合）**。
> 📍 課本對照：[02 §2.4.4](02_單元二_基礎機器學習模型與技術.md)（「對決策邊界的假設越強 → 偏差越大」）。

### ⭐⭐ 醫療篩檢：怎麼調邏輯迴歸的閾值？

**情境**：要預測患病的人。**漏掉真正患病的人代價非常高** → 你會怎麼調分類閾值？

- Tung-an：「**寧可錯判，不要漏判**」
- Yonglong：「**降低閾值、減少漏診**」「**提高召回率**」→ 老師：**非常對**
- 老師的解釋：閾值原本 0.5 → 某個真的患病的人預測機率只有 0.4 → 被判成沒病（**FN，漏報**）→ **把閾值調低**，這些人就會被標出來

| 閾值調低之後 | 變化 |
|---|---|
| **FN（漏報）** | **持平或減少**（通常減少） |
| **召回率（Recall）** | **只會持平或上升**：分母 TP+FN = 實際患病總數，**不會變**；是一部分 FN 變成 TP，**分子變大** |
| **FP（誤報：沒病被判有病）** | **持平或增加**（通常增加） |
| **精確率（Precision）** | **通常下降，但不保證**：TP 和 FP 都可能增加。判斷方式：拿「**新抓到的那批人裡真患者的比例**」和「**目前的精確率**」比 —— **比較高 → 上升；比較低 → 下降；一樣 → 持平**（跟有沒有過半無關）。例：TP 5、FP 5 → 0.5，多抓 3 真 1 假（75%）→ 8/14 ≈ 0.57，**上升**；TP 9、FP 1 → 0.9，多抓 3 真 2 假（60%，已過半）→ 12/15 = 0.8，**仍然下降** |
| F1、準確率 | **不一定**，要看實際例子 |

> ⚠️ **老師這段有兩處說得不準**：她說召回率上升是因為「分母變小」—— **機制講錯**（分母不變，是分子變大）；她說精確率「肯定」下降 —— **說得太滿**（通常下降，但不保證）。以上表為準。

## 9️⃣ Tung-an 問：每個模型的標準使用場景？

老師的回答重點：

- **最主要的區別就是迴歸 vs 分類**

- **邏輯迴歸 vs 樹模型**：
  - 樹模型**什麼特徵都能處理**（連續數值、類別都行）
  - 邏輯迴歸碰到**類別特徵**（性別、地區等級）可能處理不好
  - 但如果特徵**大多是連續數值**，邏輯迴歸雖然簡單，**表現不一定差** → 值得和複雜模型比一比
- **支援向量機（SVM）**：通常在**資料集比較小**時表現好，資料太大會下降
- **特徵太多** → 模型更複雜 → **容易過擬合** → 有時要**減少特徵數量**；不是特徵越多越好
- **穩定性**：用交叉驗證（例：**十折**），如果**每一折表現差很多** → 不穩定，就算平均還好，實際應用偏差也大 → **可以當作比較模型的一個面向**（和 9/10 的「箱形圖看穩定性」同一件事）

| **3 模型工程** | 好做法：**先建一個基準模型**。二分類先從簡單的試 → **邏輯迴歸**（快、可解釋性好）→ **決策樹**（學得到較複雜的關係、規則直觀，但容易過擬合）→ **集成**如隨機森林（通常較穩定，但複雜度高）。比較的目的是看「**多出來的複雜度，有沒有換到值得的效能提升**」；要看業務場景選（例如需要可解釋時，複雜模型比較難做到；反應速度） | ⭐ **模型註冊表**：記錄版本、參數、訓練資料、實驗紀錄 → 可溯源、可重現（像文件的版本一、版本二）。「這是我們之前**沒有涉及到**的」 |
| **4 模型評估** | 不能只看效能指標（準確率、召回率、F1）。還要看：**穩健性**（輸入有一點異常值或雜訊，效能就大跌 → 不穩健）、**可解釋性**（至少看哪個特徵影響最大；預測出來卻不知道為什麼，就沒辦法針對性處理）、**延遲**（反應速度）、**可擴展性**（客戶數突然變很大，系統還撐不撐得住）、**公平性**（在不同客戶群表現是否一致）。這些都在問：模型**能不能滿足產品要求和業務需求**。老師補一句：單元學習內容裡**還有其他面向**，這幾項是比較常討論的 | 效能只是其中一面 |
| **5 部署** | 考慮**部署平台、硬體**、能不能**嵌進原本的系統**、**資料安不安全**、**預測夠不夠快**。**部署策略**：要不要先測試？一部分一部分上？還是**先在一部分客戶群試驗**？ | — |
| **6 監控與維護** | 所有模型都隱含一個假設：**未來的資料和訓練時很像**，但現實常常不是 → **漂移**。**資料漂移**：X 的分布變了（例：以前沒有智慧手機和 5G，流量用得少；現在用很多 —— 人還是那些人，X 變了）。**概念漂移**：X 和 y 的**關係**變了（例：月費 80 的客戶原本算穩定，但**競爭對手推出很便宜的方案**後，突然變成很可能流失）。發現漂移 → **收集新資料、重新訓練、重新評估、再部署** | 「模型上線了，提案**不是就結束了**」—— 完整的提案要寫後續怎麼**監控、維護** |

### 三個成熟度級別（春平的說法）

- **不是級別 2 就比 0 好**：看部署在什麼環境、要多方考量；整體趨勢是 0 → 1 → 2 越來越自動化

| 級別 | 老師的重點 |
|---|---|
| **0 純手工** | 就像我們之前課堂做的一樣：手動訓練 → 手動部署到生產環境；評估、訓練、部署都一步一步人工做；發現異常再人工調整、重新訓練評估、再部署 |
| **1 半自動** | 自動化主要在**模型訓練**（關鍵詞：**持續訓練**） |
| **2 相對完全自動化** | 自動監測、自動訓練、自動部署、自動 delivery |

### 級別 0：不代表模型差

- 再強調一次：**級別 0 不代表模型差**，模型也可能表現非常好；可以是小公司，或看部署環境
- 例：**客戶流失模型**好長時間行為都不變、表現也還可以 → 不用重新部署、繼續用 → **不必花成本**在生產環境各處實現自動化
- 什麼時候要往上升：**變化頻率高**、客戶源不停在變、**客戶體量突然變很大** → 考慮部署環境成不成熟、是否需要不斷更新 → 才需要級別 1、2
- 優缺點很明顯：**頻繁更新的不適合**；**穩定、規模化的完全可以**，不需要擴展

### 級別 1（老師帶看流程圖）：持續訓練靠 trigger

- **持續訓練**不是一直在訓練，而是**發生異常時**才訓練 → 所以需要一個 **trigger（觸發機制）**
- 上半部和級別 0 基本一致：在訓練集上訓練、調整 → 覺得可以了，準備應用 → 正式上線 → 出現各種表現、回饋、問題 → 設 trigger（什麼樣的問題需要重訓）→ 觸發後重訓 → **這一塊實現了自動化**
- ⭐ **觸發後不是一上來就訓練，先做資料驗證**（新資料不一定能用）。例：性別特徵原本用 0／1 代表男女，後來公司其他系統收集、錄入或更新時改成 F／M 表示（逐字稿作 zoom／fmm，F／M 為推測），或類別變多 → 和之前不一樣了 → 得重新訓練。第一步先檢查所有資料有沒有**缺失、異常**
  > 📌 我的註：課本（03 §3.4.2.1 資料驗證）區分：**schema 偏斜**（欄位／編碼變了）→ 應停止 pipeline 調查；**值偏斜**（分布變了）→ 重訓。老師這個例子較像 schema 偏斜，但說「得重新訓練」；考題以課本區分為準
- ⭐ 訓練完還要做**模型驗證**（model validation）：新模型**是不是比之前更好**？真的更好才部署、上線。**這就是為什麼要有模型註冊表** —— 不是每次更新表現都一定更好

### 級別 2：流水線本身也會變 → CI/CD

- 流程：實驗那一塊做了新改變 → 產生新的資料源、新程式碼 → 存起來 → **整合 → 建置 → 測試 → 打包 → 部署**；不能直接丟進生產環境，要先驗證、看測試能不能通過 → **持續部署**

## 📚 第 6 週回顧：深度學習與神經網路（小節號對應 04 筆記；老師只明講 4.2）

### 4.1 深度學習的應用

- **科學研究**：生物學上**預測蛋白質結構**；物理學上**基於圖網路的模擬器**
- **遊戲**：**AlphaGo**（逐字稿作「二發 goal」）
- **內容創作**：大語言模型 **ChatGPT、DeepSeek** 用於文本創作；另有音訊、影片、音樂創作等成熟軟體
- 這些 AI 產品**本質上的基礎都是神經網路** → 所以 **4.2** 重點學神經網路基礎：神經元、神經網路的架構、怎麼訓練

### 4.2 神經網路基礎

- **架構＝三類層**：**輸入層**（輸入資料）、**隱藏層**（又稱**隱含層**）、**輸出層**；通常**一個輸入層、一個輸出層，隱藏層可以有多個** —— 層數依要解決的問題類型或複雜度自己定義；每層神經元個數也依問題複雜程度定義
- 每一層的神經元和前一層、後一層的**所有神經元都相互連接** → 這個基礎神經網路模型也叫**全連接網路模型**
- ⭐ 要著重了解的概念：**權重**、**偏置項**、**激活函數**；也要了解輸入層、隱含層、輸出層各自的功能
- ⭐ 常用的是 **sigmoid** 激活函數，和之前學的**邏輯迴歸**用的函數一樣 → **邏輯迴歸模型也可以當作單個神經元來看待**
- **函數表示形式**（老師說比較重要）：主要的計算**都發生在隱藏層**；多個隱藏層時，每層之間怎麼計算、輸出怎麼算 → 通過**前向傳播**進行，要著重看
- **訓練**：最常用的訓練算法還是**梯度下降法**，和之前的線性迴歸、邏輯迴歸一樣；目標還是**最小化損失**，調整模型參數 ＝ **權重和偏置項** → 得到最優參數
- ⭐ 訓練用的方法是**反向傳播**；可以照示意圖分清：**前向傳播**＝從輸入層出發，經過隱含層計算，一直到輸出層；**反向傳播**＝用來訓練模型、得到一組最優的模型參數
- **程式碼**：現在**不需要一行一行看或完全掌握**；實務會用成熟的建構與訓練框架 **TensorFlow／Keras**（逐字稿作「tensorflow car」），在 Python 裡直接調用；示例可以用 Jupyter notebook 跑，了解每個模組完成什麼任務、程式的邏輯和原理，**模型怎麼建、怎麼訓練、用什麼指標評估效能**就可以

### 4.3 卷積神經網路（CNN）

- 新概念：**卷積層、池化層、濾波器**
- 要了解卷積層由什麼部分構成；卷積運算怎麼用**濾波器**和輸入資料結合得到**輸出矩陣** —— 學習內容有計算的小例子，看例子比較快明白原理
- 也要了解**卷積運算的功能**、**池化運算的功能**，以及 CNN 的架構
- CNN 和 RNN 都是在**經典神經網路的基礎上升級**的；CNN 透過引入卷積層和池化層，能更好地**提取輸入資料的特徵**
- ⭐ 適合解決**圖像識別、圖像分類**問題，因為它更適用於分析**網格狀資料**（grid-based data）

### 4.4 循環神經網路（RNN）與 LSTM

- **RNN**：神經網路內部加入**自動循環的結構** → 處理每個元素的過程中能**保留並更新自身的狀態**
- ⭐ 更適合處理**時間資料或序列資料**，例如時間序列分析；應用上像**即時語音識別、即時影片**都有優勢
- RNN 在學習內容只有兩個小單元 → 主要了解它的**結構**和**適合解決什麼任務**
- **LSTM（長短期記憶網路）**：一種更複雜的 RNN，用來解決**梯度消失**問題，能更好地捕獲**長期依賴關係**
- ⭐ 可以照圖示比較基礎 RNN 和 LSTM 的差別：LSTM 加入了**輸入門、遺忘門、輸出門**
- 後面也有一些 Python 訓練的小示例，幫助理解這些不同的模型

### 多層網路、黑箱

- **輸入層**就是特徵值；每個神經元就是上面那個過程，得到一個值；多層網路的話，這些值作為**下一層的輸入**，一層層算到最後得到結果
- 計算量很大，而且中間每個神經元到底在算什麼、怎麼分配，**我們並不能知道** → 所以神經網路通常叫**黑箱算法（black box）**；但也正因為計算錯綜複雜，它更能**發現隱藏的特徵**來學習分類

### 權重向量、權重矩陣

### ⭐ 前向傳播 vs 反向傳播、停止條件

- 要知道訓練到什麼程度可以停 → 兩個概念：**前向傳播**、**反向傳播**
- **前向傳播**：從輸入特徵到輸出的過程，**只算出當前的預測值**
- 最終目的是減少損失 → 要把**預測值和實際值比較**、看損失多少 → 再回頭 → 這就是**反向傳播**（演算法細節不展開，理解概念就好：正向在算什麼、反向在做什麼）
- ⭐ **反向傳播：計算每個參數的梯度**（逐字稿「branding」＝ gradient）→ 決定**往哪個方向走**，這時**還不知道走多少**
- ⭐ 之後才是**梯度下降**：決定**走多少**，然後**把這些參數全都更新**
- ⭐ **停止條件有兩個**：① **模型表現不再改善** ② **手動設定跑多少次**，跑完就停
- 老師留的思考：知道了它學什麼、你的目的是什麼，就比較能理解**什麼是它的參數、什麼是它的超參數** ——「你在調整的時候，你調整的是什麼？」
  > 📌 我的註：照這場的講法整理 —— **參數**＝模型自己學的（權重、偏置；CNN 卷積核的權重）；**超參數**＝你自己決定、調整的（老師在 CNN 段明講**卷積核大小、步長**「算是那個模型的超參數」；層數、每層神經元數 10/7 說依問題自訂；「跑多少次」老師只講成停止條件，歸為超參數是我的推論）。

### 卷積神經網路（CNN）

- **為什麼要 CNN**：CNN 也是基於神經網路，而且作業三裡也有（📌 我的註：房仲情境的 Inception V3）。和普通神經網路不一樣的地方：能**捕捉空間結構** → 處理**圖像、像素相關**的問題比較好
- 圖片變成像素：長 × 寬 × **3（紅綠藍色值）** → 要處理的像素非常多
- 普通神經網路的問題：① 每個像素點代表一個數值、都是輸入 → **輸入值非常非常多**；② 攤成**平面的一串**，沒辦法呈現像素和像素之間有什麼關聯；③ 展開後輸入特徵很大，再加上神經元、權重、正向計算、反向計算 → **計算量非常大** → CNN 能比較好地解決
- 學習內容的圖：**28 × 28 × 1**（灰度圖；逐字稿作「22 乘 28 乘 28」）
- 把圖片無限放大 → 一格一格，**每一格代表一個數**
- **卷積核（濾波器）**：不想把所有像素攤成一長串 → 目的一是**減少計算量**，二是**捕捉一小塊區域的特徵**
  - ⭐ **卷積核大小可以自己定義**（例：3 × 3）
  - 把 3 × 3 的小塊放到圖片上，從頭開始在圖像上**移動**；每到一個地方就捕捉那 **9 個色塊的數值**
  - 同樣是**找權重**：找 9 個位置對應的權重，讓最後的**損失最小**；每到一個地方，9 個值和對應的權重分別相乘（和前面的運算差不多的邏輯）；在整張圖上都游走一遍後，就學到這些權重應該是多少
- ⭐ Zhimin Lin（24:28）問「**捕捉時會有重疊部分嗎**」→ 老師：**取決於步長**
  - 要看實際情況、你的特徵、應用案例，以及**算力允不允許**（逐字稿「算例」＝算力 [ASR 推定]）——「這些都是可以自己決定的，然後**算是那個模型的超參數**」
  - **步長 1**：濾波片從這格移到下一格；**步長 3**：直接跳到那裡；也取決於濾波片有多大；「實際的情況應該**不會選擇跳過去的**」
  > 📌 我的註：步長小於卷積核寬度 → 相鄰兩次會重疊（3 × 3、步長 1 每次重疊 2 欄）；步長大於卷積核寬度 → 會漏掉像素，應該就是老師說「不會選擇跳過去」的意思。
- ⭐ **參數共享**：共享的參數是**卷積核的權重**；模型學到卷積核內**每一個位置的權重**，在圖片上游走，每經過一處就和原始值相乘得到一個數 → 得到新的**特徵圖（特徵矩陣）**
- 得到特徵圖後，**可以選擇池化或不池化**
- ⭐ **池化**：例 **2 × 2 池化** → 在特徵圖中選 2 × 2 的矩陣；**最大值池化（max pooling）**就取最大值；也可以用**平均數**或其他統計量（老師先口頭舉例「幾乘幾的池化…把原來 3 × 3 的池塊變成一個數」〔📌 我的註：應只是舉例，3 × 3 池化也存在〕，翻到投影片後用 2 × 2 示範；老師問「看得到嗎」→ Zhimin Lin、Hsiao-Li Huang、Yonglong Cao 回「可以」）
- ⭐ **整體架構**：卷積層（卷積核運算）→ 新的特徵矩陣 → **池化** → 縮小的特徵矩陣 → 下一個卷積層 → 再池化 → 到這一步已經比較小 → **展開（攤平）** → 接上和普通神經網路差不多的部分 → 賦予權重和偏置（逐字稿「填寫」[ASR 推定]）→ 得到輸出值
- 所以 CNN 適合圖片、影像：要捕捉**空間結構**，比較細緻的**形狀、紋理**可以透過像素處理
- 老師後段補充：
  - ⭐ 例：**28 × 28 用 5 × 5 卷積核 → 變成 24 × 24**；這樣快速想像過程，對理解流程有幫助
    > 📌 我的註：步長 1、不補邊時，輸出邊長 ＝ 28 − 5 + 1 ＝ 24。
  - ⭐ **順序不是固定的**：也可以先用卷積核算 → 再用**激活函數** → 再**池化** → 這樣循環 → 得到輸出，再做反向的參數更新（逐字稿「方向它的一個參數更新」，「方向」＝反向 [ASR 推定]）
  - 投影片上另一個激活函數「就不是邏輯迴歸用到的激活函數」（📌 我的註：老師沒唸名稱；CNN 常用 ReLU，是我的推定）

### 循環神經網路（RNN）與 LSTM

- 長短期記憶網路（LSTM）也屬於循環網路的一種
- 特點：處理**序列**問題 —— 普通神經網路對資料的**連續性**沒辦法捕捉；**CNN 處理空間圖像上一塊有什麼特徵，RNN 處理一個序列有什麼特徵**
- 兩者差別：**RNN 處理短一點的序列**，**LSTM 能處理長一點的**；因為處理時學著學著，**之前學到的規律或特徵就忘掉了**，LSTM 可以控制這件事
- ⭐ 比較要理解的是**輸入**：輸入是**一個序列**，把整個序列當特徵看，因為要捕捉序列有什麼規律
  - 每個向量代表**一個時間點的各特徵值**（特徵 1、2、3 在時間 1 是這些值…）
  - ⭐ 例：**5 × 3 ＝ 5 個時間步 × 3 個特徵**
- 後段再講一次（📌 我的註：依順序推定是回應 Zhimin Lin 35:55「4.4.1 RNN 示例看的不是很懂」）：
  - 輸入序列：時間 1 是這些特徵值、時間 2 是那些…；**每個時間步對應一個輸入，每個輸入有一個輸出**
  - ⭐ **狀態（state）**：走到下一個時間步時，先算當下的輸入和輸出，但又想回頭看和前面有什麼聯繫 → 引入 state，**每到一個新時間步就持續更新 state**
  - 越往後走、回頭看的**時間跨度越大**
  - ⭐ 所有網路模型的訓練都有**向前和向後**兩個過程（前面為了好懂只講了前向）；RNN 走完一系列時間步後**也會往回走**，回去計算時也是在算**梯度**
  - 基礎 RNN 的函數設定決定了：**離得越遠的時間步越會被忘掉** → 損失非常大、模型表現不好 → **需要另一個模型（LSTM）來處理**
    > 📌 我的註：就是 10/7 Li Guan 講的「LSTM 解決**梯度消失**、捕獲長期依賴」，春平用「忘掉」講同一件事。
  - 展開圖：每個時間步一個特徵向量輸入 → 對應輸出 → 往下走、回頭看要不要更新 state
  - 「但終歸還是一個**決定權重**的問題，只是處理方式上稍有不同」
- 老師總結：**最基礎、最有幫助的是理解基礎神經網路怎麼計算** → 需要考慮算力、算多大時，才知道**怎麼調整超參數**
