## ⭐⭐⭐ 資料洩漏：前處理時**測試集要排除在外**

> 這場最技術、也**最直接影響 A3** 的內容。

**原則**：測試集必須**完全獨立**於訓練集。做**缺失值填補**、**正規化（normalization）**時，
**計算用的資料不能包含測試集**。

**老師的例子**：
> 資料 1 到 100，中間缺一個值，用**平均值**補。
> 如果平均值是用**全部資料（含測試集）**算的 → 已經用到測試集的資訊 → **資料洩漏**，之後的評估就**不嚴謹**。

**為什麼**：真實世界裡，未來從市場來的新資料**你事前完全沒見過**。測試集就是在模擬這件事。

## ⭐⭐⭐ k 折交叉驗證（老師用「考試」比喻）

### 流程（老師的數字例子）

1. 120 筆資料 → 先抽 **20 筆當測試集，鎖起來不碰**
2. 剩 100 筆做訓練，用 **5 折**：分 5 份、每份 20 筆
3. 每一輪 **80 筆訓練、20 筆驗證**，輪流換 → 共 5 輪

### ⭐ 考試比喻

| 資料 | 比喻 |
|---|---|
| 訓練折 | **平常讀書** |
| 驗證折 | **模擬考**（5 折 = 考 5 次模擬考） |
| 測試集 | **正式考試** —— 模型**從頭到尾沒見過** |

### 怎麼看結果

- 模型表現 = **5 次的平均**（例：5 次準確率取平均）
- ⭐ 還要看**穩不穩**：用**箱形圖（box plot）**看 5 次結果的分布
  - 5 次都在 80% 左右 → **穩定**，上線後也比較可靠
  - 5 次很分散 → **不穩定**，上線後也不可靠

### 驗證集拿來做什麼：調**超參數**

- 超參數例子：樹的**最大深度**、**節點至少幾筆才繼續分裂**、**max_features**
- 老師的流程：
  1. 用 k 折比較幾個分類器 → 選**表現好又穩定**的（例：隨機森林）
  2. 調它的超參數 → 用**驗證折**確認有沒有變好
  3. 最後用**測試集**（沒參與任何訓練或調參）評估 → 報 FP、FN、準確率等

> ⚠️ 老師一度口誤說「超參數用測試集調」，隨即更正為**驗證集**。
> 👉 **調參 = 驗證集；最終評估 = 測試集。**

## 2️⃣ 線性迴歸：找一條讓 MSE 最小的線

- 例子：**廣告投入（x）→ 銷量**，從散點中找一條最合適的線
- 線畫在哪由 **MSE** 決定：每個實際點到預測線的差值 → 平方 → 平均
- **訓練目標 = 讓 MSE 最小**
- 單一線性迴歸 = **截距 + 一個斜率**（一個特徵）；多元線性迴歸 = 往後加更多 θ 和特徵；**原理一樣**

## 3️⃣ 邏輯迴歸：把線性分數壓成 0～1 的機率

- 聊天室問「邏輯迴歸處理什麼問題？」→ Yonglong、Hsiao-Li：**分類** ✅
- 流程：特徵 → 算出**線性分數** → 經過**邏輯函數（Sigmoid）**映射到 **0～1** → 可理解為「**屬於類別 1 的機率**」
- 再設一個**閾值**，**預設 0.5**：例如 0.78 → 78% 機率 → 大於 0.5 → 歸為類別 1
- 同一類裡的每個點，**機率都不一樣**

### 訓練目標：交叉熵（cross-entropy）

- 交叉熵是**損失函數**：**不只看分對沒有，還看機率離真實標籤多遠**
- 老師的三個點（真實標籤 y = 1）：

| 預測機率 | 分類結果 | 損失 |
|---|---|---|
| 0.9 | 1 ✅ | **非常小** |
| 0.55 | 1 ✅（也分對了） | 稍大一些 |
| 0.05 | 0 ❌ | **非常大** |

- 所有點的損失加總再平均 = 交叉熵；**訓練目標 = 讓交叉熵最小**，夠好就停
- 預測機率越偏離真實值，**懲罰（penalty）越重**（log 曲線）

> **Yonglong 問**：「loss 越接近 1 越好嗎？」
> **老師**：圖上橫軸的 1 是**機率**，不是 loss。y = 1 是真實標籤。以客戶流失為例，y = 1 = 流失，某點代表「模型預測它有 90% 機率流失」。對 y = 1 的點，**預測機率越接近 1 越好、loss 越小越好**。

> 📍 課本對照：[02 §2.5.2](02_單元二_基礎機器學習模型與技術.md)（Sigmoid、閾值 0.5）、§2.5.2.1（交叉熵損失）。

## 4️⃣ 決策樹：選「讓節點更純」的分裂

- 訓練時在學：**用哪個特徵分裂、分裂的閾值是多少** → 選能讓節點**純度更高**的分裂
- **終極目標：用盡量少的節點，分出純度高的節點**
- 例：客戶留存問題 → 希望某個節點裡**全是留存客戶**，不要混流失的；混雜就繼續分

### 課堂問答

| 問題 | 答案 |
|---|---|
| S1 和 S2 哪個**不純度**更高？（S1 只混了 1 個不同類，S2 一半一半） | **S2**（Gengzhong 答對）—— 越混雜，不確定性越高 |
| 不純度越高，資訊熵越高還是越低？ | **越高**（Yonglong 答對）。**資訊熵 = 0 時最純**（節點裡只有一類） |
| 一次好的分裂之後，子節點的資訊熵變高還是變少？ | **變少**（Tung-an 答對；Yonglong 答「變高」「越來越純」，可能是在講純度） |

- **資訊熵和基尼係數基本上是同一個意思**，只是算法略不同，都在量化**節點的混雜程度**

### 資訊增益（information gain）

- 每次分裂：原節點 = **父節點**，分出的兩個 = **子節點**
- **資訊增益 = 父節點的資訊熵 − 子節點資訊熵的加權平均**
- 父節點不純 → 熵大；子節點變純 → 熵小 → 相減為正 = **有資訊增益** = 分裂往好的方向

> 📍 課本對照：[02 §2.5.3.1](02_單元二_基礎機器學習模型與技術.md)（資訊增益 = 父節點熵 − 子節點加權熵）。

## 5️⃣ 參數 vs 超參數、過擬合

- **訓練時**學的：分裂特徵與閾值（參數）
- **調優時**調的：**超參數**（樹的深度、每個節點的樣本數…），用**驗證集**比較後調整
- **調超參數基本上就是在調模型的複雜度**：樹越深越複雜

### 過擬合 vs 欠擬合

- **越複雜的模型越容易過擬合**：會連資料裡的**噪聲**都學進去 → 在**訓練時見過的資料**上很好，**換新資料就變差**（低偏差、高方差）。老師原話是「驗證集時表現都很好」；⚠️ **課本的判斷方式是：訓練集好、驗證／測試集差 = 過擬合**
- **簡單模型**（例：線性迴歸）面對複雜資料：受限於模型本身，**學不到複雜關係**，還是只會找一條直線；換一批資料重練，結果也「大差不差」

> ⚠️ **老師這段有口誤**：她說簡單模型「**偏差會稍微小一些，但方差會比較大**」—— **講反了**。
> 她舉的例子（學不到訓練資料的規律、換資料結果也差不多）描述的正是 **高偏差、低方差**，也就是**欠擬合**。
> ✅ **正確版本**：**簡單模型 = 高偏差、低方差（欠擬合）；複雜模型 = 低偏差、高方差（過擬合）**。
> 📍 課本對照：[02 §2.4.4](02_單元二_基礎機器學習模型與技術.md)（「對決策邊界的假設越強 → 偏差越大」）。

### ⭐⭐ 醫療篩檢：怎麼調邏輯迴歸的閾值？

**情境**：要預測患病的人。**漏掉真正患病的人代價非常高** → 你會怎麼調分類閾值？

- Tung-an：「**寧可錯判，不要漏判**」
- Yonglong：「**降低閾值、減少漏診**」「**提高召回率**」→ 老師：**非常對**
- 老師的解釋：閾值原本 0.5 → 某個真的患病的人預測機率只有 0.4 → 被判成沒病（**FN，漏報**）→ **把閾值調低**，這些人就會被標出來

| 閾值調低之後 | 變化 |
|---|---|
| **FN（漏報）** | **持平或減少**（通常減少） |
| **召回率（Recall）** | **只會持平或上升**：分母 TP+FN = 實際患病總數，**不會變**；是一部分 FN 變成 TP，**分子變大** |
| **FP（誤報：沒病被判有病）** | **持平或增加**（通常增加） |
| **精確率（Precision）** | **通常下降，但不保證**：TP 和 FP 都可能增加。判斷方式：拿「**新抓到的那批人裡真患者的比例**」和「**目前的精確率**」比 —— **比較高 → 上升；比較低 → 下降；一樣 → 持平**（跟有沒有過半無關）。例：TP 5、FP 5 → 0.5，多抓 3 真 1 假（75%）→ 8/14 ≈ 0.57，**上升**；TP 9、FP 1 → 0.9，多抓 3 真 2 假（60%，已過半）→ 12/15 = 0.8，**仍然下降** |
| F1、準確率 | **不一定**，要看實際例子 |

> ⚠️ **老師這段有兩處說得不準**：她說召回率上升是因為「分母變小」—— **機制講錯**（分母不變，是分子變大）；她說精確率「肯定」下降 —— **說得太滿**（通常下降，但不保證）。以上表為準。

## 9️⃣ Tung-an 問：每個模型的標準使用場景？

老師的回答重點：

- **最主要的區別就是迴歸 vs 分類**

- **邏輯迴歸 vs 樹模型**：
  - 樹模型**什麼特徵都能處理**（連續數值、類別都行）
  - 邏輯迴歸碰到**類別特徵**（性別、地區等級）可能處理不好
  - 但如果特徵**大多是連續數值**，邏輯迴歸雖然簡單，**表現不一定差** → 值得和複雜模型比一比
- **支援向量機（SVM）**：通常在**資料集比較小**時表現好，資料太大會下降
- **特徵太多** → 模型更複雜 → **容易過擬合** → 有時要**減少特徵數量**；不是特徵越多越好
- **穩定性**：用交叉驗證（例：**十折**），如果**每一折表現差很多** → 不穩定，就算平均還好，實際應用偏差也大 → **可以當作比較模型的一個面向**（和 9/10 的「箱形圖看穩定性」同一件事）
