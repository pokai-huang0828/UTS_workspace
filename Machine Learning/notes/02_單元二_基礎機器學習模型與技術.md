## 2.1 機器學習模型與演算法

### ML 的產業應用（開場舉例）

| 產業 | 用途 |
|---|---|
| 醫療保健 | 預測患者結果、識別潛在疾病風險 |
| 金融 | **詐欺偵測、風險管理、交易分析** |
| 行銷 | **個人化內容、優化廣告活動** |

> 🎯 **與 A2/A3 的關聯**：Bank X 情境同時踩到「金融」與「行銷」兩格。

**選模型的兩個依據**：所分析**資料的性質** + **分析目標**。
> 📌 **本課程重點放在監督式模型（supervised models）**，其他類型只做簡介以建立整體背景。

### ⭐ 模型 vs 演算法（易混淆的核心區分）

| | 定義 |
|---|---|
| **模型（Model）** | 一種**計算框架**，利用數學演算法，根據輸入資料作出預測或決策。透過**訓練**過程建構 —— 大型資料集輸入模型，使其識別資料中的模式與關係。 |
| **演算法（Algorithm）** | **用於解決問題的一系列指令**。為模型提供「如何從資料中學習」的指令。旨在執行特定任務：聚類、分類、迴歸分析或優化。 |

> **一句話記法**：**演算法是訓練模型所用的「方法」，模型是該訓練過程的「結果」（最終產物）。**

### 六種學習類型（後續頁面逐一展開）

監督學習 · 非監督學習 · 強化學習 · 半監督學習 · 自監督學習 · 遷移學習

**頁面活動**：拖放配對 —— 把場景配到對應的學習方法。

## 2.2 機器學習問題（分類 vs 迴歸）

> 🚨 **開場第一句就點名 A3**：
> 「**在評估任務三中，你需要說明應針對所提供的用例實施哪一類機器學習方法（演算法）。**」

### 兩種常見方法的對比

| | **分類（Classification）** | **迴歸分析（Regression）** |
|---|---|---|
| 預測什麼 | **分類**輸出變數 | **連續**輸出變數 |
| 目標 | 找一個函式，把新輸入指派到某個**預定義類別** | 找一個函式，準確預測新輸入對應的**輸出值** |
| 範例問句 | 「明天是冷還是熱？」→ **熱** | 「明天的氣溫是多少？」→ **29°C** |
| 常見應用 | 圖像辨識、情感分析、垃圾郵件過濾 | 預測股價、房價、銷售額 |
| 常用模型 | **邏輯迴歸、決策樹、隨機森林**、深度學習 | **線性迴歸、多項式迴歸、支援向量迴歸**、深度學習 |
| 評估指標 | **準確率、精確率、召回率、F1 分數** | **MAE、MSE、R-squared** |

> 🎯 **Bank X = 分類問題**（y 為接受／不接受），所以要用分類指標，不是迴歸指標。

### 更複雜的問題（超出分類與迴歸）

| 任務 | 說明 | 適用模型 |
|---|---|---|
| **排序（Ranking）** | 根據使用者過去行為或偏好**推薦項目** | **協同過濾（collaborative filtering）** |
| **生成（Generation）** | 建立新內容：文字、圖像、音樂、影片 | **VAE（變分自編碼器）、GAN（生成對抗網路）、Transformer** |

> 📌 這裡的「協同過濾」呼應單元一 1.7 互動活動裡的推薦引擎題。

## 2.3 模型訓練

**定位**：這是單元一 §1.9 四步驟中的**第三步**。
**定義**：把資料輸入模型，**迭代調整模型參數**，以最大化其在給定任務上的效能
（監督學習語境下＝最小化預測值與實際目標值之間的差異／「損失」）。

### 迭代方法（通用循環）

> 訓練模型就是**反覆調整模型，直到它能夠生成理想結果**。

重複以下兩步，直到滿足停止標準：
1. 在一個輸入上**執行模型**，獲得輸出
2. 根據對輸出的**評估來調整模型**

### ⭐ 監督學習的訓練循環（training loop）—— 必背四步

| 步驟 | 內容 |
|---|---|
| **1** | 抽取一批訓練樣本（**X**）及其對應的目標值（**y**） |
| **2** | 在 X 上執行模型，獲得預測值（**ŷ**） |
| **3** | 計算該批資料的**損失** —— 衡量 ŷ 與 y 之間差異的指標 |
| **4** | 以**略微降低該批損失**的方式，更新網路中所有權重／參數（**θ**） |

**符號表（考點）**

| 符號 | 意義 |
|---|---|
| **X** | 訓練樣本（training samples） |
| **y** | 目標值（targets） |
| **ŷ** | 預測值（predictions） |
| **θ**（theta） | 模型的參數或權重 |
| **D(y, ŷ)** | 損失函數；因為實際上是 θ 的函數，通常寫作 **J(θ)** |

### 類比：學樂器 vs 訓練模型（原文表格）

| 步驟 | 學樂器 | 訓練 ML 模型 |
|---|---|---|
| 1 | 為一組樂曲（X）選擇音符；錄音就是目標值（y） | 抽取一批訓練樣本（X）與目標值（y） |
| 2 | **你（＝模型）**練習這些樂曲，達到與錄音相似的表現（ŷ） | 在 X 上執行模型，獲得 ŷ |
| 3 | 把你演奏的（ŷ）與示範錄音（y）比較，找出錯誤 | 計算損失，衡量 ŷ 與 y 的差異 |
| 4 | 調整技巧以避免犯錯 | 更新權重／參數 θ，降低損失 |

**參考資料**：Google 機器學習術語表（Canvas 有中文與英文 PDF 各一份）

## 2.4 前置：2.3.1 訓練過程中的步驟 —— 梯度下降

### 四步的難易度（原文明講）

- **步驟 1** 只是簡單的輸入／輸出（I/O）操作
- **步驟 2、3** 在模型與成本函數定好後，也容易計算
- **⭐ 步驟 4 是困難的部分** —— 更新網路參數：每個參數該**增加還是減少？幅度多少？**

### 梯度下降（Gradient Descent）

**定義**：一種**優化演算法**，用於**尋找函數的最小值** —— 換句話說，尋找 ML 模型的最佳設定。

**損失梯度函數的直覺**：
- **梯度就是曲線在給定點的斜率**
- 損失函數 **J(θ)** 是模型參數的函數
- **J 相對於 θ 的梯度給出損失函數「最陡上升」的方向**
- → **沿梯度的相反方向移動**，就是往「最陡下降」走，從而降低損失

### 梯度下降的兩個步驟（公式）

**① 計算 J(θ) 相對於所有參數的梯度**

```
∇J(θ) = [ ∂J(θ)/∂θ₁ , … , ∂J(θ)/∂θₙ ]ᵀ
```

**② 將每個參數朝梯度的相反方向調整**

```
θ₁ = θ₁ − α · ∂J(θ)/∂θ₁
…
θₙ = θₙ − α · ∂J(θ)/∂θₙ
```

| 符號 | 意義 |
|---|---|
| **J(θ)** | 損失函數 |
| **∇J(θ)** | J(θ) 的梯度 |
| **α**（alpha） | ⭐ **學習率（learning rate）** —— 用於縮放梯度、控制**步長（step size）**，**會對效能產生顯著影響** |
| **∂** | 導數（derivative） |

**停止條件**：兩步重複執行直到滿足標準 —— 可以是**迭代次數**、**參數值最小變化量的預設閾值**，或兩者組合。

## 2.3.2 案例研究：時尚圖像分類（Fashion-MNIST）

**情境**：你是時尚電商公司的資料科學家，要用圖像分類模型提升產品推薦系統的準確率。

### 資料集規格（考點數字）

| 項目 | 數值 |
|---|---|
| 訓練集 | **60,000** 個示例 |
| 測試集 | **10,000** 個示例 |
| 圖像尺寸 | **28 × 28 灰階** |
| 類別數 | **10** 類 |
| 10 個類別 | T 恤／上衣、褲子、套頭衫、連衣裙、外套、涼鞋、襯衫、運動鞋、包、短靴 |

### 流程（用 CNN，單元四會深入）

1. 載入資料集，**將像素值歸一化到 0 與 1 之間**
2. 定義模型架構：**卷積層 + 池化層 → 全連接層**，並用 **dropout 正則化**
3. 編譯：**分類交叉熵（categorical cross-entropy）損失函數 + Adam 優化器**
   （原文註明：**Adam 是梯度下降的一種高級變體**）
4. 訓練：`model.fit(x_train, y_train, epochs=5, batch_size=32)`
5. 在測試資料上評估

### ⭐ batch_size 與 epochs 的計算（很可能考）

```
batch_size = 32  → 每次更新參數前處理 32 張圖
批次數 = 60,000 / 32 = 1,875 個批次
epochs = 5       → 整個訓練集通過模型 5 次
模型參數更新總次數 = 5 × 1,875 = 9,375 次
```

### 批量大小（Batch Size）—— 三種梯度下降

| 優化演算法 | 批量大小 | 每個 epoch 的模型更新次數 |
|---|---|---|
| **批量梯度下降**（Batch GD） | **N**（整個訓練資料集） | **1** |
| **小批量梯度下降**（Mini-Batch GD） | **B**（一個子集） | **N/B** |
| **隨機梯度下降**（Stochastic GD, SGD） | **1**（單一示例） | **N** |

| 演算法 | 優點 | 缺點 |
|---|---|---|
| 批量 GD | 梯度估計**較準確** | 大型資料集**計算成本高** |
| **小批量 GD** | **在準確性與效率之間取得平衡**<br>⭐ **實踐中最常用** | — |
| 隨機 GD | **計算效率高** | **有噪聲**；梯度估計**方差高**，可能收斂較慢 |

> 批量大小會顯著影響：**收斂速率、記憶體使用、泛化能力**。

## 2.1.1 監督學習、非監督學習與強化學習

> ML 的**三大主要類別**。

### 監督學習（Supervised Learning）

**定義**：模型使用**已標註資料**訓練 —— 資料集中每個輸入示例都有對應的輸出或目標值。
**目標**：學習從**輸入特徵到對應輸出的映射**，使模型能對未見資料作出準確預測。
**用於**：**迴歸分析與分類**任務。
> ⭐ **本課程重點學習監督學習技術。**

#### 真實範例一：貓還是狗？

技術人員執行的步驟：
1. 取得由**超過 20,000 張貓狗圖像**組成的資料集
2. 判斷每張圖像是貓還是狗，**逐張標註**「貓」或「狗」
3. 將資料集劃分為**訓練集、驗證集、測試集**（原文：**通常比例為 60% / 20% / 20%**）
4. 用**訓練集**訓練模型
5. 用**驗證集**調節模型參數
6. 用**測試集**評估準確率

### 非監督學習（Unsupervised Learning）

**定義**：處理**沒有輸出標籤或目標值**的資料。
**目標**：在資料中**發現模式或結構**，例如將相似的資料點歸為一組。
**用於**：**聚類、降維、異常偵測**。
> ⚠️ **由於缺少真實標籤，評估非監督模型的效能可能具有挑戰性。**

### 強化學習（Reinforcement Learning）

**定義**：**智能體（agent）透過與環境互動**來學習如何作出決策。
以**獎勵或懲罰**的形式接收回饋，隨時間推移改進決策能力。
**目標**：學習一種能**最大化累計獎勵**的策略。
**應用**：**機器人技術、遊戲、推薦系統**。

#### 真實範例二：掃地機器人

- 機器人有「**移動**」和「**吸塵**」的**動作集合**，以及對應的**獎勵集合**
- 在未知空間中自行採取動作，並接收每個動作對應的**獎勵**
- 根據所接收的獎勵**持續優化決策**
- 最終學會如何有效移動並吸走灰塵
- 前置攝影機用 ML 技術辨識電纜、鞋子等物體並繞開

## 2.1.2 半監督學習、自監督學習與遷移學習

> 這三種是「結合或擴展」前三大類的方法。

### 半監督學習（Semi-Supervised）

**定義**：介於監督與非監督之間的範式，**同時利用已標註與未標註資料**訓練模型。
**特別有用的時機**：**已標註資料稀缺**，或**標註成本高且耗時**時。

### 自監督學習（Self-Supervised）

**核心思想**：**利用輸入資料自身的結構，為學習過程創建監督訊號** ——
模型透過**基於輸入資料的某些部分來預測其他部分**，生成自身的監督訊號。**無需人工標註**。

| 領域 | 範例 |
|---|---|
| **NLP** | **掩碼語言建模（masked language modeling）** —— 用於 **BERT 和 GPT**。模型根據**周圍詞語的上下文**學習預測句子中缺失的詞語。<br>示範：隨機遮蓋「一隻敏捷的〔遮蓋〕狐狸從〔遮蓋〕狗的身上跳過」→ 預測「一隻敏捷的**棕色**狐狸從**懶惰的**狗身上跳過」<br>藉此捕捉語言的統計特性：**語法、句法、語義，以及一些事實性知識** |
| **電腦視覺** | 訓練模型**預測圖像的部分內容**，或完成**圖像上色、圖像修復**等任務，在**不需要顯式標籤**的情況下學到有意義的特徵與表示 |

### 遷移學習（Transfer Learning）

**定義**：使**預訓練模型**能在**新的相關任務**中被重複使用；利用從**源任務**獲得的知識提升**目標任務**表現。
**特別有效的時機**：**目標任務可用標註資料有限**時。

**背後的思想**：模型在某一任務中學到的特徵或表示通常包含**通用且可重複使用的知識**。
> 對**深度學習模型**尤其明顯（**CNN 或 Transformer**）—— 因為其**較低層通常捕捉可在多個任務中發揮作用的一般性特徵或模式**。

**兩個主要步驟**：① 在**源任務上預訓練** → ② 在**目標任務上微調（fine-tuning）**

## 2.4 模型評估

**為什麼重要**：判斷模型是否適合解決特定問題、了解優勢與不足、比較不同模型。

### 三大功能

#### 一、評估模型效能
評估模型對**新的、未見資料的泛化能力**，判斷是否能作出令人滿意且可靠的預測。

#### 二、識別模型的優勢與不足 ⭐

> **重點觀念：有時降低某一類錯誤，比最大化整體準確率更重要。**

| 情境 | 該優先降低什麼 | 為什麼 |
|---|---|---|
| **醫學診斷** | **假正類（False Positive）** | 避免把健康患者誤診為患病 → 避免不必要的治療與心理壓力 |
| **金融詐欺偵測** | **假負類（False Negative）** | 避免把詐欺交易誤判為合法 → 防止財務損失 |

> 🎯 **Bank X 對應**：漏掉會答應的客戶（FN）＝ 直接損失營收；打錯人（FP）＝ 浪費呼叫成本。
> **兩者都要權衡，這是 A3 可寫的論述。**

#### 三、模型選擇
不只看模型輸出，還要考慮**計算成本與速度**。

**原文的完整案例**（實時異常偵測系統，處理大量串流資料）：

| | 深度學習神經網路 | 較簡單的邏輯迴歸 |
|---|---|---|
| 準確率 | **更高** | 稍低 |
| 泛化能力 | **更好** | — |
| 計算成本 | **較高**，需要強大硬體 | **低** |
| 速度 | **較慢** | **更快** |
| 實施難度 | 較難 | **更容易** |

> **結論**：高準確率至關重要且能負擔資源 → 選深度學習；
> **速度與計算效率更重要**（實時偵測）→ 選較簡單的模型。

## 2.4.1 資料劃分

### 三個資料集的角色（必背）

| 資料集 | 用途 | 關鍵限制 |
|---|---|---|
| **訓練集**（Training） | 訓練模型，學習底層模式 | 可**多次使用** |
| **驗證集**（Validation） | **微調模型、優化超參數**；幫助達到最佳效能並**防止過擬合** | 可**多次使用**；⚠️ **若模型不涉及任何超參數，就不需要驗證集** |
| **測試集**（Test） | **最終效能評估**，估計模型在新的未見資料上的表現 | ⭐ **應僅使用一次**，作為最後的評估步驟 |

### 常見劃分比例

| 比例 | 適用時機 |
|---|---|
| **60 / 20 / 20** | **資料集規模不是很大**時 —— 讓驗證集與測試集都有足夠樣本 |
| **70 / 15 / 15** | 常見的通用劃分 |
| **80 / 10 / 10** | **規模較大的資料集** —— 更多資料給訓練集，驗證／測試仍夠用 |
| **80 / 20**（無驗證集） | 不使用驗證集時的常見劃分 |

### k 折交叉驗證（k-fold cross-validation）

**做法**：
1. 先留出一小部分資料作為**測試集**
2. 將剩餘資料劃分為**大小相等的 k 個折（folds）**
3. 模型進行 **k 次**訓練與評估，每次用**一個不同的折當驗證集**，其餘 **k−1 個折當訓練集**
4. 最終效能 = **全部 k 次迭代的平均效能**

> ⭐ **特別有用的時機**：**處理較小的資料集**時 —— 因為它可以有效地把**整個資料集同時用於訓練與驗證**。

## 2.4.2 分類評估指標 ⭐（高頻考點）

### 混淆矩陣的四個格子

| 縮寫 | 全名 | 中文 |
|---|---|---|
| **TP** | True Positive | 真正類／真陽性 |
| **FP** | False Positive | 假正類／假陽性 |
| **TN** | True Negative | 真負類／真陰性 |
| **FN** | False Negative | 假負類／假陰性 |

### 四個指標的公式

| 指標 | 公式 | 衡量什麼 |
|---|---|---|
| **準確率 Accuracy** | `(TP + TN) / 全部預測數量` | 全部實例中被**正確分類**的比例 |
| **精確率 Precision** | `TP / (TP + FP)` | 所有**正類預測**中真正類的比例；**避免把負類誤判為正類**的能力 |
| **召回率 Recall**<br>（敏感度、真正類率） | `TP / (TP + FN)` | 所有**實際正類**中被找出的比例；**避免把實際正類誤判為負類**的能力 |
| **F1 分數** | `2 × (Precision × Recall) / (Precision + Recall)` | 精確率與召回率的**調和平均數**；⭐ **特別適用於類別不平衡的資料集** |

### 該選哪一項指標？

| 指標 | 什麼時候用 |
|---|---|
| **準確率** | 簡單直觀，**但不適用於類別分布偏斜的不平衡資料集** ——<br>⚠️ 原文警語：「**始終預測多數類的模型可能具有較高的準確率，但在實際應用中未必有用。**」 |
| **精確率** | 當你希望**盡量減少假正類**數量時 |
| **召回率** | 當**假負類的代價較高**時。例：**醫學診斷中未能識別出疾病可能造成嚴重後果** |
| **F1 分數** | 需要在精確率與召回率之間**取得平衡**時；**特別適用於不平衡資料集** |

> 🎯 **Bank X 直接對應**：y=yes 只佔 **11.27%** → 高度不平衡 →
> **不能用 accuracy 當主指標**（全猜 no 就有 88.7%）。要用 **F1 / Recall / ROC-AUC**。

### ⭐ 頁面練習「試試看！」—— 我已算出答案

**題目**：醫學診斷的二元分類問題，10 筆資料（1 = 患病，0 = 未患病）。

| # | 實際值 | 預測值 | 落在哪一格 |
|---|:---:|:---:|---|
| 1 | 1 | 1 | **TP** |
| 2 | 1 | 0 | **FN** |
| 3 | 0 | 1 | **FP** |
| 4 | 0 | 0 | **TN** |
| 5 | 1 | 1 | **TP** |
| 6 | 1 | 1 | **TP** |
| 7 | 0 | 1 | **FP** |
| 8 | 1 | 0 | **FN** |
| 9 | 0 | 1 | **FP** |
| 10 | 1 | 1 | **TP** |

**混淆矩陣**：**TP = 4 ｜ FP = 3 ｜ TN = 1 ｜ FN = 2**（合計 10 ✓）

| 指標 | 計算 | 答案 |
|---|---|---|
| **Accuracy** | (4 + 1) / 10 | **0.5000 = 50.00%** |
| **Precision** | 4 / (4 + 3) = 4/7 | **0.5714 = 57.14%** |
| **Recall** | 4 / (4 + 2) = 4/6 | **0.6667 = 66.67%** |
| **F1** | 2 × (0.5714 × 0.6667) / (0.5714 + 0.6667) | **0.6154 = 61.54%** |

> 💡 **F1 的快速驗算法**：`F1 = 2TP / (2TP + FP + FN)` = 8 / (8 + 3 + 2) = **8/13 = 0.6154** ✓
> 考試時用這個式子比先算 P 和 R 再代入快很多。

> 📌 **這題本身就是個好例子**：Accuracy 只有 50%（跟丟銅板一樣），
> 但 Recall 有 66.67% —— **兩個指標講的是不同的事**。

## 2.4.3 迴歸分析評估指標

### 四個指標

| 指標 | 公式 | 特性 |
|---|---|---|
| **MAE**<br>平均絕對誤差 | `(1/n) Σ \|yᵢ − ŷᵢ\|` | 衡量**平均誤差幅度**，**不考慮誤差方向**；**對異常值不太敏感** |
| **MSE**<br>均方誤差 | `(1/n) Σ (yᵢ − ŷᵢ)²` | **對較大的誤差給予更高懲罰** → **對異常值更敏感**；<br>⭐ **經常被用作訓練迴歸模型時的損失函數** |
| **RMSE**<br>均方根誤差 | `√MSE` | ⭐ **與因變數使用相同單位**，因此**更容易解釋和理解** |
| **R²**<br>決定系數 | `1 − SSR/SST`<br>`= 1 − Σ(yᵢ−ŷᵢ)² / Σ(yᵢ−ȳ)²` | 衡量**迴歸模型對實際資料的擬合優度**。<br>**SSR** = 迴歸平方和（捕捉模型的預測誤差）<br>**SST** = 總平方和（目標變數的方差；可理解為「**始終用平均值當預測**」的朴素模型） |

### 該選哪一項指標？

| 指標 | 選它的理由 |
|---|---|
| **MAE** | 對異常值不敏感，**直接反映平均誤差大小** |
| **MSE / RMSE** | 對異常值更敏感；MSE 對大誤差施加更高懲罰；**RMSE 單位與目標變數相同，比 MSE 好解釋** |
| **R²** | 想了解**目標變數的方差中有多大比例由模型解釋** |

## 2.4.4 偏差—方差權衡 ⭐（本單元最深的一頁）

> 承接單元一 §1.7 的第四項挑戰，這裡給出**正式定義與數學分解**。

### 直覺類比（推薦系統版）

| | 類比 | 問題 |
|---|---|---|
| **高偏差模型** | 推薦系統**永遠推薦同一類熱門電影**（例如因為動作片普遍受歡迎就推給所有人） | **過於僵化，無法適應個體差異** |
| **高方差模型** | 推薦系統**對使用者當前偏好過度擬合**（注意到最近看了某演員幾部片，就只推那位演員） | **偏好改變時難以適應**，因為已過度客製化為過去的偏好 |

### 正式定義

**偏差—方差分解**：測試集中的誤差可分解為 **偏差 + 方差**（講座版再加 **噪聲**，共三項）。

| | 定義 | 公式 |
|---|---|---|
| **偏差 Bias** | **目標值與模型預測值之間距離的平均值**；即「模型在任意訓練集上的**擬合能力**」 | `Bias = E[θ̂] − θ` |
| **方差 Variance** | **平均預測值與具體預測值之間的偏差**；衡量模型**對特定訓練集的敏感程度** | `Var(θ̂) = E[θ̂] − (E[θ̂])²` |

**偏差的正負**：
- 偏差 = 0 → 估計量是**無偏的**
- 偏差 > 0 → **正偏**
- 偏差 < 0 → **負偏**

### 圖形說明

**高偏差圖**：多個線性迴歸模型分別擬合不同訓練集，這些假設函數在大多數位置**都不能很好近似真實函數**，只有約 x = −10 與 x = 6 兩點附近勉強接近。
**高方差圖**：預測值與預測期望值之間**平均差異很大**。

**誤差 vs 模型複雜度的經典圖**：
- 橫軸 = **模型複雜度**，縱軸 = **誤差**
- **下方藍線 = 訓練集誤差**（隨複雜度單調下降）
- **上方線 = 測試集誤差**（U 形）
- **最優選擇 = 兩者交會處的垂直灰線**

### 泛化設計（原文的關鍵論述）

> 分類器必須**泛化其決策邊界**，對訓練資料未覆蓋的區域作出合理推斷 —— 這是一個**與模型複雜度相關的設計選擇**。

- **模型對決策邊界的假設越強**（通常透過**減少參數**或**增加剪枝**達成）→ **偏差越大**
- **模型越簡單** → **偏差越大**、**方差越低**
- **模型越複雜** → **偏差越低**（能理解問題的複雜性）、**方差越高**（換個訓練集就得到截然不同的模型）

> Canvas 該頁附了完整逐字稿。以下是**Canvas 正文沒有、但講座裡有**的內容。

### ⭐ 三個組成部分（不是兩個！）

> 「偏差—方差分解指出，對於測試誤差…可以將其分解為**三個組成部分：偏差、方差和噪聲**。」

| 組成 | 定義 |
|---|---|
| **偏差** | 目標值與模型預測值之間的平均距離；「模型在解決這個問題方面有多大的能力？」 |
| **方差** | 預測值與平均預測值之間的偏差；衡量對**特定訓練集的敏感程度** |
| **噪聲** | **目標變數中的變動，是問題本身固有、我們實際上無法避免的** |

### ⭐ 可約誤差 vs 不可約誤差

假設真實關係為 `y = f(x) + ε`（ε 為均值為零的誤差項），ML 找到的是近似函數 `f̂`。

誤差 `E[(y − ŷ)²]` 可分解為：

| 組成 | 內容 | 能不能降低 |
|---|---|---|
| **可約誤差**（reducible error） | `(f(x) − f̂(x))²` —— 真實函數與預測函數差異的平方 | ✅ **可以** —— 選一個更好的 f̂ 即可；若 f̂ 完全反映 f，可約誤差為 0 |
| **不可約誤差**（irreducible error） | **ε 的方差** | ❌ **不行** —— 無論 f̂ 多好都無法降低 |

> ⭐ **關鍵結論**：**不可約誤差決定了模型誤差的下限。**
> 因此我們只能專注於降低**可約誤差**。

### 預期測試 MSE 的三項分解

```
預期測試 MSE = 方差 + 偏差² + 不可約誤差
```

- 「**期望**」的意思：用**許多不同的訓練集**反覆估計 f，但每次都只在**特定的 x₀ 點**測試模型，取平均
- **方差**：用不同訓練集估計時，f̂ 會變化多少
- **偏差²**：用某個簡單函數近似真實函數時引入的誤差
  （例：真實關係是非線性，卻只用線性函數建模）
- 由於**方差 ≥ 0、偏差² ≥ 0**，所以**預期測試 MSE 的最低值就是不可約誤差**

### 分類問題：改用誤分類率

分類問題用 MSE 沒有意義，改用**誤分類率**：

```
測試誤差率 = (1/n) Σ I(ŷᵢ ≠ yᵢ)
```

**I( ) 是指示函數**：條件為真 → 1；條件為假 → 0。
也就是**統計被錯誤分類的樣本數量**，再取平均。

### ⭐ 貝氏分類器（Bayes Classifier）—— 理論上的最佳分類器

**定義**：選擇能產生**最高後驗機率（條件機率）**的類別 j：

```
選 j 使 P(Y = j | X = x₀) 最大
```

**二元分類的版本**：若 `P(Y = 類別1 | X = x₀) > 0.5` → 選類別 1，否則選類別 2。

**貝氏誤差率（Bayes error rate）** = `1 − E[max_j P(Y = j | X = x₀)]`
—— 這就是**分類問題中理論上無法再降低的誤差下限**（對應圖中的綠線）。

> ❓ **為什麼不總是用貝氏分類器？**
> 原文回答：「**只有在我們了解所有資料點處 Y 在給定 X 條件下的完整條件分布時，才能使用貝氏分類器。
> 而在現實問題中，我們通常並不知道這一條件分布**，因此無法直接應用。」
> → 這就是為什麼還需要決策樹等各種方法。

### 為什麼不能只用訓練誤差選模型

> 「隨著模型變得越來越複雜，它會**開始擬合訓練樣本中的噪聲**，因此可以在訓練集上獲得較低的誤差。
> 但是，如果我們選擇另一個資料集，例如測試集，由於模型的方差較高，它在該資料集上的誤差表現就不會那麼理想。」

**實務做法**：先訓練模型，然後**選擇「測試樣本誤差開始上升」時所對應的模型複雜度**
—— 因為測試誤差開始上升就表示**方差正在增大**。

## 2.5.1 線性迴歸

**定位**：迴歸分析模型家族中的**基礎模型**。簡單但功能強大，因**良好的可解釋性與易於實作**而廣泛應用。

### 假設與方程式

線性迴歸假設輸入特徵與目標變數之間存在**線性關係**：

```
y = θ₀ + θ₁x₁ + θ₂x₂ + ⋯ + θₙxₙ + ϵ
```

**向量形式**：`y = xθ + ϵ`，其中
`x = [1, x₁, x₂, …, xₙ]`，`θ = [θ₀, θ₁, …, θₙ]ᵀ`
→ **xθ 就是預測得到的純量值 ŷ**。

**目標**：找到一組最優參數 (θ₀…θₙ)，使模型最好地擬合資料（**盡可能減小 ŷ 與 y 的差異**）。

### 兩個使用場景（原文範例）

| | **簡單線性迴歸**（單一特徵） | **多元線性迴歸**（多個特徵） |
|---|---|---|
| 情境 | 根據**廣告投入**預測**產品銷量** | 根據**引擎排量、車重、車齡**預測**汽車燃油效率** |
| 目標變數 y | 產品銷量（件） | 燃油效率（公里/升） |
| 輸入特徵 | x：廣告投入金額（澳元） | x₁ 引擎排量(cc)、x₂ 車重(kg)、x₃ 車齡(年) |
| 假設函數 | `hθ(x) = θ₀ + θ₁x` | `hθ(x) = θ₀ + θ₁x₁ + θ₂x₂ + θ₃x₃` |

> **直覺**：單一特徵時，假設函數就是**一條擬合資料點趨勢的直線**。
> **θ₁ = 斜率（slope）**，**θ₀ = 截距（intercept）**。

### 損失函數：MSE

```
J(θ) = (1/m) Σᵢ₌₁ᵐ ( hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾ )²
```

透過**最小化 J(θ)**，利用**梯度下降**優化 θ。訓練完成後即可對未見新資料預測。
評估時可使用**任何一種迴歸評估指標**（見 §2.4.3）。

## 2.5.2 邏輯迴歸

**定位**：**線性迴歸的擴展**，專門處理**二元分類**問題。
線性迴歸建立輸入與**連續目標變數**的關係；邏輯迴歸則對**某個類別或事件出現的機率**建模。

**適用範例**：客戶會流失還是留存 · 郵件是否為垃圾郵件 · 患者是否有某疾病
> 🎯 **Bank X 完全符合**：客戶會不會接受優惠。

### ⭐ 關鍵差異：預測值的範圍

| | 預測值範圍 |
|---|---|
| **線性迴歸** | **(−∞, ∞)** |
| **邏輯迴歸** | **(0, 1)** ← 有界預測值 |

### 邏輯函數（Sigmoid 函數）

**定義**：一種數學函數，將**任意實數輸入映射為 0 與 1 之間的數值**（不包括 0 和 1）。

```
σ(z) = 1 / (1 + e^(−z))
```

**從線性迴歸推導到邏輯迴歸**：
線性迴歸假設函數 `hθ(x) = θx` → 用 `θx` 替換 z：

```
hθ(x) = σ(θx) = 1 / (1 + e^(−θx))
```

在二元分類中，**預測值被解釋為樣本屬於「類別 1」的機率**。

### 閾值（Threshold）

模型輸出機率後，**再套用一個閾值**得到最終類別標籤。

**原文範例（腫瘤良惡性）**：模型輸出 0 到 1 的機率，某患者的惡性機率為 **0.75**。
套用閾值 **0.5**：
- 機率 **≥ 0.5** → 預測為**惡性（類別 1）**
- 機率 **< 0.5** → 預測為**良性（類別 0）**

→ 0.75 > 0.5，所以預測為**惡性**。

## 2.5.2.1 交叉熵損失（Cross-Entropy Loss）

**定位**：衡量模型有效性的指標，訓練時用來優化參數。**訓練目標 = 最小化交叉熵損失**（用梯度下降）。

### 分段形式

```
Loss = −log( hθ(x) )        若 y = 1
Loss = −log( 1 − hθ(x) )    若 y = 0
```

其中 y 是真實標籤，hθ(x) 是**樣本屬於類別 1 的預測機率**。

### 合併形式（完整損失函數）

```
J(θ) = (1/m) Σᵢ₌₁ᵐ [ −y⁽ⁱ⁾ log(hθ(x⁽ⁱ⁾)) − (1 − y⁽ⁱ⁾) log(1 − hθ(x⁽ⁱ⁾)) ]
```

### ⭐ 選擇交叉熵損失的兩項優勢（必考）

#### 優勢一：懲罰錯誤預測、獎勵準確預測

| 真實標籤 | 模型預測 | 損失 |
|---|---|---|
| **y = 1** | 預測類別 1 的機率**很低**（hθ(x) ≪ 0.5）—— 圖中點 a | **極大懲罰**；機率趨近 0 時，**損失趨近無窮大** |
| **y = 1** | 預測類別 1 的機率**很高** —— 圖中點 b | 損失**趨近 0** |
| **y = 0** | 預測（類別 1 的）機率**很高** —— 圖中點 d | **極大懲罰** |
| **y = 0** | 預測（類別 1 的）機率**趨近 0** —— 圖中點 c | 損失**趨近 0** |

#### 優勢二：凸函數形狀（convex shape）⭐

> **凸函數只有一個全域最小值（global minimum）**，可確保優化過程**收斂到唯一的最優解**。

**⚠️ 這也是為什麼「不」選 MSE 當損失函數**：
> 「儘管 MSE 可能看起來是更自然的選擇，但**在邏輯迴歸中，MSE 並不是凸函數**。」

### 訓練方式

與線性迴歸相同 —— 用**梯度下降**最小化 J(θ)。**唯一的區別是損失函數換成交叉熵**。
評估時使用**任何一種分類評估指標**（見 §2.4.2）。

## 2.5.3 決策樹

**定義**：一種預測模型，利用**按樹狀層級結構組織的一系列「問題」**引導決策。
模型依序回答問題、沿分支向下移動，最終產生預測結果。

### 三種節點（必背）

| 節點 | 位置 | 說明 |
|---|---|---|
| **根節點**（Root node） | **最頂端** | 決策樹的起點，**包含整個資料集**。根據某個特徵的條件決定**第一次劃分** |
| **決策節點**（內部節點） | 中間 | 根據特定條件**進一步將資料劃分為兩個子集** —— 一個滿足條件、一個不滿足 |
| **葉節點**（終端節點） | **最底部** | 決策樹的終點。包含滿足「從根節點到此路徑上所有條件」的資料子集。<br>⭐ **葉節點中資料的「多數類」（分類）或「平均值」（迴歸）就是對未見資料的預測** |

### 父節點與子節點

| | 說明 |
|---|---|
| **父節點** | 其下一層直接連接有一個或多個節點的節點。**根節點與決策節點都可以是父節點** |
| **子節點** | 直接從父節點延伸出來的節點。父節點劃分時形成**兩個**子節點（滿足／不滿足條件）。<br>子節點可以是**決策節點**（繼續劃分）或**葉節點**（最終預測） |

## 2.5.3.1 資訊熵：最小化不純度（決策樹的訓練過程）

### 核心問題與策略

> **核心問題**：如何決定每次劃分？
> **策略**：採用**貪心策略（greedy manner）** —— 選擇能使**劃分後子節點「不純度」最低**的劃分方式。

> 📌 這與訓練線性迴歸時**最小化損失函數**的過程類似。
> 有時也解釋為**最大化資訊增益（information gain）**：
> **資訊增益 = 父節點的資訊熵 − 劃分後兩個子節點的加權資訊熵**。

### 資訊熵（Entropy）

**定義**：衡量系統中的**不確定性或混亂程度**；在決策樹中用於衡量**節點的不純度**。

```
E(S) = − Σ ( Pᵢ · log₂(Pᵢ) )
```

其中 **Pᵢ = 隨機選取的一個樣本屬於類別 i 的機率**。

| 節點類型 | 資訊熵 |
|---|---|
| 類別組成**單一**、有明顯多數類 | **低** |
| 類別分布**混雜** | **高** |

### 決策樹構建演算法的三個步驟

1. **對每個特徵評估不同的潛在劃分條件**
   - **分類特徵**：每個唯一值都可以作為劃分條件
   - **連續特徵**：使用**排序後相鄰唯一值之間的中點**作為劃分條件
2. **對每個潛在劃分條件，計算劃分後子節點的整體資訊熵** —— 即**加權平均**（考慮每個子節點的樣本數）：

```
(n_c1 / n_p) · E(N_c1) + (n_c2 / n_p) · E(N_c2)
```
   n_c1、n_c2 = 兩個子節點的樣本數；n_p = 父節點樣本總數

3. **選擇能使加權平均資訊熵最低的特徵與劃分條件**

→ 對每個子節點**遞迴重複**，直到所有葉節點均為純節點或滿足停止標準。

### 其他不純度指標

| 指標 | 公式 | 用於 | 特性 |
|---|---|---|---|
| **資訊熵** | `E(S) = −Σ Pᵢ log₂(Pᵢ)` | 分類 | 需要對數運算 |
| **基尼系數**（Gini index） | `G(S) = 1 − Σ pᵢ²` | 分類 | ⭐ **不涉及對數運算，計算效率略高於資訊熵**；<br>兩者通常產生**較為相似的結果** |
| **方差**（Variance） | `V(S) = (1/N) Σ (yᵢ − μ)` | **迴歸（回歸樹 regression trees）** | 量化節點中資料點相對於**平均值**的離散程度 |

> **不論用哪種指標，演算法的基本結構不變** —— 只需調整步驟 2 中用於評估不純度的指標。
> 目標一律是**盡量降低劃分後子節點的不純度**。

## 2.5.3.2 使用決策樹進行預測

### 預測流程（三步）

1. **從根節點開始**，用新資料點的特徵值判斷劃分條件；依條件為真／假移動到左／右子節點
2. **繼續向下遍歷**，每個節點都判斷劃分條件，直到**到達葉節點**
3. **葉節點即最終預測**：
   - **分類任務** → 葉節點中訓練樣本的**多數類**
   - **迴歸任務** → 葉節點中訓練樣本目標值的**平均值**

> 決策樹的預測過程**簡單直觀且易於解釋** —— 這是它廣泛應用的原因之一。

### ⭐ 處理過擬合（三種方法）

**過擬合是決策樹中的常見問題** —— 模型捕捉的是訓練資料中的**噪聲或異常值**，而非底層模式。

| 方法 | 時機 | 做法 |
|---|---|---|
| **① 設定停止標準**<br>（stopping criteria） | **構建過程中**應用 | 限制決策樹的**最大深度**、設定每個葉節點所需的**最少樣本數**、要求每次劃分達到**最低的不純度下降幅度**。<br>可用**交叉驗證**微調這些參數 |
| **② 剪枝策略**<br>（pruning / **post-pruning 後剪枝**） | ⭐ **決策樹「完全生長後」**應用 | 從完全生長的決策樹中**移除部分分支**，簡化結構 |
| **③ 集成學習方法**<br>（ensemble methods） | — | **隨機森林、梯度提升樹** —— 組合多棵決策樹，透過**對預測結果取平均值來降低方差、改善泛化** |

> 📌 **停止標準 vs 剪枝的關鍵區別**：
> **停止標準在「構建過程中」應用；剪枝在「完全生長後」應用。** 這是常考的區分。

## 2.5.4 隨機森林

**定位**：一種**集成學習（ensemble）方法**，將多棵決策樹組合成學習能力更強的模型。

### ⭐ 兩種隨機性（必背，這是「隨機」森林的由來）

| # | 隨機性 | 做法 | 效果 |
|---|---|---|---|
| **①** | **對輸入資料隨機採樣**<br>(Random sampling of input data) | 每棵樹用**輸入資料的隨機子集**訓練，透過 **自助採樣（bootstrapping）** 產生 —— 即**從原始資料集有放回抽樣**。<br>因此**某些實例可能被多次抽取，另一些一次也不會被抽到** | 每棵樹用**略有不同的資料點集合**訓練 → **降低過擬合** |
| **②** | **每次劃分時隨機選擇特徵**<br>(Random selection of features at each split) | 每棵樹的**每次劃分**只考慮**隨機選取的特徵子集**來決定最佳劃分 | 各樹**不會依賴同一組特徵**作決策 → 更**多樣化**；<br>**降低受少數主導特徵影響的可能性** → 更均衡準確的預測 |

> 除了這兩點，隨機森林中每棵樹的訓練過程**與單獨一棵決策樹完全相同**。

**效果**：與單棵決策樹相比，提高**準確率、穩定性、泛化效能**。

### 用隨機森林預測（三步）

1. **輸入資料** —— 需包含與訓練時**相同的特徵集合**
2. **各棵決策樹的預測** —— 輸入資料傳給森林中每棵樹，各自作出預測
3. **匯總（Aggregation）**：

| 任務 | 匯總方式 |
|---|---|
| **分類** | **多數投票（majority voting）** —— 統計每個類別被各樹預測的次數，**票數最高者**為最終預測 |
| **迴歸分析** | **取平均值** —— 計算各樹預測值的平均值 |

> **匯總的價值**：降低單棵樹的**誤差、偏差、過擬合**所造成的影響。
> ⭐ **當各樹具有「互補的優勢與不足」時，集成學習尤其有效** —— 模型可綜合利用所有樹的集體知識。

### 定義與區分
1. **模型 vs 演算法**：演算法是「方法」，模型是「結果」。

4. **排序 → 協同過濾；生成 → VAE / GAN / Transformer**。

### 訓練
5. **訓練循環四步** + **X / y / ŷ / θ / J(θ)** 符號。
6. **梯度下降**：梯度指向最陡「上升」→ 要往**反方向**走。**α = 學習率 = 步長**。
7. **三種 GD 的批量大小與更新次數表**（Batch = N，1 次；Mini-Batch = B，N/B 次；SGD = 1，N 次）。**小批量最常用**。
8. **batch_size / epochs 計算**：60,000 / 32 = 1,875 批；× 5 epochs = **9,375 次更新**。

### 評估
9. **三個資料集**：測試集**只能用一次**；沒有超參數就**不需要驗證集**。
10. **常見劃分比例**與各自的適用時機；**k 折交叉驗證用於小資料集**。
11. **四個分類指標的公式**；**不平衡資料不能只看 accuracy**；**F1 = 2TP/(2TP+FP+FN)** 快算法。
12. **醫學診斷 → 降低 FP；詐欺偵測 → 降低 FN**（注意方向別記反）。
13. **四個迴歸指標**：MAE 不敏感、MSE 懲罰大誤差、**RMSE 單位與目標相同**、R² = 1 − SSR/SST。

### 偏差—方差
14. **偏差 = 擬合能力；方差 = 對訓練集的敏感度**。簡單 → 高偏差低方差；複雜 → 低偏差高方差。
15. ⭐ **講座版是三項**：偏差 + 方差 + **噪聲**。
16. ⭐ **可約誤差 vs 不可約誤差**；**不可約誤差 = 誤差下限**。
17. ⭐ **貝氏分類器 = 理論最佳**；**貝氏誤差率 = 分類問題的誤差下限**；**現實中不知道條件分布所以用不了**。

### 經典模型
18. **線性迴歸**：θ₁ = 斜率、θ₀ = 截距；損失用 **MSE**。
19. **邏輯迴歸**：範圍 **(0,1)**；**Sigmoid σ(z) = 1/(1+e^(−z))**；閾值 0.5。
20. ⭐ **為什麼用交叉熵不用 MSE**：兩個理由 —— **懲罰錯誤預測**（趨近無窮大）+ **凸函數只有一個全域最小值**（MSE 在邏輯迴歸中**非凸**）。
21. **決策樹三種節點**；葉節點 = 多數類／平均值。
22. **資訊熵 vs 基尼系數 vs 方差**；**基尼不用對數所以較快**；**回歸樹用方差**。
23. **資訊增益 = 父節點熵 − 子節點加權熵**；連續特徵用**相鄰值中點**當劃分條件。
24. ⭐ **停止標準（構建中）vs 剪枝（生長後）** 的時機差別。
25. ⭐ **隨機森林的兩種隨機性**：**bootstrapping 有放回抽樣** + **每次劃分隨機選特徵子集**；分類用**多數投票**、迴歸用**平均**。
