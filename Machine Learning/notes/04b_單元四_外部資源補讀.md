### 若要自行驗證的方法（已驗證可行）

Canvas 嵌入網址形如：
```
https://player.bilibili.com/player.html?isOutside=true&aid=...&bvid=BVxxxx&cid=NNNNN&p=1
```
用 bilibili API 以 `cid` 反查實際分 P：
```
https://api.bilibili.com/x/web-interface/view?bvid=BVxxxx
```
在回傳的 `data.pages[]` 中找 `cid` 相符的那一項，看 `part`（分 P 標題）與 `duration`（秒）。
