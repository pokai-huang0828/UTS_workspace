## 2. 第二個二選一：商業重點 vs 技術重點

**選好情境後，還要再選一條路徑。兩條路的評分標準完全不同。**

### 路徑 A：商業重點（Business Focus）

閱讀並理解為解決方案提供的**基礎 Python 程式碼**，並完成以下內容：
1. **根據程式碼中的提示與註解補全程式碼**，使其具備功能並能成功運行。
2. **結合成功標準與商業目標的達成情況，解釋並呈現結果。**
3. **說明已建構產品未來可改進之處／可新增功能**，並提出相關的**新產品構想**。

### 路徑 B：技術重點（Technical Focus）

在所提供的 Python 程式碼基礎上**進行擴展**，並確保程式碼具有**清晰註解**，重點說明：
1. 你將如何對所選演算法進行**超參數選擇（hyper-parameter selection）**？
2. 你所建構的模型／解決方案中**最重要的變數**是什麼？
3. 你將如何**評估模型／解決方案的效能，並選擇最佳模型**？
4. 與其他**替代模型**相比，所選最佳模型有哪些**優點與缺點**？

## 3. 最後一部分：後續問題（Follow-up Questions）

> **必須選擇與你所做專案對應的問題組。** 兩條路徑都要答。

### 若你做「目標行銷活動」（Bank X）

**新情境**：假設銀行決定**更改該產品的資格標準（eligibility criteria）**，以便在使用你的解決方案開展行銷活動時，能納入**更多符合條件的客戶**。其中一些客戶可能**與銀行此前開展隨機行銷活動時接觸的客戶有所不同**。

要回答：
- 你認為是否能夠將之前建構的**同一解決方案／模型原封不動地**應用於這一新的擴展客戶群體？
- 如果你認為需要調整，請說明**為什麼需要**以及**調整是什麼**（**無需實施**）。

> 💡 這題在問的是 **資料漂移／族群偏移（population shift）** 與模型泛化。

### 若你做「房仲」（Real Estate X）

**新情境**：房仲 X 希望自動化另一項繁瑣任務 —— **為房產撰寫並上傳吸引人且原創的描述**（該任務約需 20 分鐘）。房仲 X 認為可以**利用房產圖片來撰寫房產描述**。

要回答：
- **哪些機器學習技術適合用於此問題？請詳細說明原因。**
- 成功開發你所提出的解決方案需要滿足**哪些主要要求**，並會面臨**哪些主要挑戰**？
- 你在前一個問題（房產照片分類）中提出的解決方案，其**輸出是否能夠幫助解決本問題**（房產描述生成）？如果可以，請說明如何提供幫助。

> 💡 這題在問的是 **image captioning / 多模態（vision-to-text）**，以及前一階段分類輸出能否當成下游任務的輸入特徵。
