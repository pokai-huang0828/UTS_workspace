## 1. 目的與學習目標

**目的**：為一個資料分析專案提出一個**簡單的機器學習演算法方案**。展示對本課程原理的理解，並能將這些原理應用於實際情境。培養將知識應用於現實世界中「基於學習與資料驅動」專案的能力。

**對應課程學習目標**
- 描述多種機器學習方法的範圍、局限性與應用
- 使用或編寫機器學習方法
- 針對專業領域中的機器學習問題設計解決方案
- 展示對機器學習相關問題的理解，並成功概述解決機器學習問題的方法

**課程預期學習成果（CILO）**：**C1 和 D1**

## 2. 二選一：商業情境

### 情境一：Bank X —— 電話行銷活動（表格資料／分類問題）

X 銀行行銷團隊計劃開展一項**電話行銷活動**，推廣一款**新的信用卡產品**。將透過電話聯繫現有客戶，向其提供信用卡**優惠利率**。

為確保推廣成功，行銷總監計劃從**符合條件的客戶中隨機抽取樣本**進行試點行銷。樣本被劃分為：
- **目標組（Target Group）** —— 會收到優惠利率方案
- **對照組（Control Group）** —— 不會獲得任何特別優惠

隨後收集並分析兩組客戶**接受優惠方案的情況**，以不斷優化產品與行銷活動，從而：
- **最大化轉換率（conversion rate）**
- **最小化行銷成本**（例如呼叫中心成本、優惠利率所帶來的折扣成本）

### 情境二：房仲 X —— 圖像分類（CNN 問題）

房仲公司 X 每月在全國範圍內接收約**五萬套**待售房產。在各大房產網站上發布房源是市場推廣的重要環節，但過程非常耗時，尤其因為房源平台使用體驗不友善。

**現況成本**：每套新房源，員工平均需花約 **20 分鐘**將房產照片上傳並分類至預定義類別 —— 例如**臥室、客廳、廚房**等。員工一直對這項重複繁瑣的工作表示不滿。

**自動化的預期效益**：
- 讓員工投入更多創造性工作，**提升員工滿意度**
- **降低人力資源成本**

營運總監因此聯繫一家顧問公司，顧問公司建議利用 AI 技術解決。

## 3. 提案要交的內容（照這個順序寫）

1. **闡述當前商業問題／挑戰及其商業影響。**
2. **論證基於機器學習的解決方案**，以及解決給定問題所需滿足的**要求**。
3. **遵循機器學習開發生命週期（CRISP-ML）的各個階段**，提交你的專案提案：
   - **業務理解**：產品需求、產品商業價值、成功標準等
   - **資料理解**：資料需求、資料目錄、資料概況（data profile）、資料驗證等
   - **資料工程**：資料選擇、資料清洗、資料建構、資料標準化
   - **機器學習模型工程**：模型選擇、模型訓練、模型註冊
   - **機器學習模型評估與部署**
   - **機器學習模型監控**：模型持續評估與更新
4. **提出用於開發與營運的 MLOps（機器學習運維）設計方案**，並可選擇性地推薦技術棧。
