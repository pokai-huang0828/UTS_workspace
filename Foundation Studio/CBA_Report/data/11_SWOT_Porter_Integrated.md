# SWOT + Porter's Five Forces 整合分析
**標的:** CBA 房貸業務(ANZSIC K6221)

---

## SWOT 分析

### ✅ Strengths(優勢)
1. **市占第一(25.4% APRA)** — 比第二名 WBC 大 23%(相對)
2. **自有通路 66%** — 降低 Mortgage Broker 佣金成本(行業平均約 40-50% 來自 broker)
3. **NIM 2.08%(FY25)** — 高於行業平均,規模優勢攤平資金成本
4. **客戶數最大** — 1700 萬名澳洲客戶(全國人口 67%),交叉銷售基礎雄厚
5. **數位投資領先** — CommBank 應用程式市占與滿意度長期第一
6. **資本充足** — Tier 1 CET1 約 12.0%,優於 APRA 最低要求(10.5%)

### ❌ Weaknesses(劣勢)
1. **ROE 13.5%(FY25 −10bp)** — 仍低於全球同業均值(美加銀行 15-18%)
2. **本土集中** — 99% 收入來自澳紐,缺乏地理分散
3. **服務型外包高薪資成本** — 平均薪資 $230k,高於金融業整體
4. **房貸組合風險集中** — 房貸佔總資產 60%+,過度依賴單一資產類別
5. **存款定價戰侵蝕 NIM** — FY24 NIM 下滑 8bp 顯示在升息週期後段 pricing power 有限

### 🌟 Opportunities(機會)
1. **首購政策紅利** — Help to Buy + FHG 擴大可申貸群體
2. **再融資需求** — RBA 利率波動下,老客戶重新議價/轉貸是 cross-sell 機會
3. **綠色金融** — IBISWorld 指出再生能源/太陽能板貸款新藍海
4. **數位 + AI** — 自動化放款流程降本(房貸申辦時間從 30 天 → 1-2 天)
5. **規模優勢防禦小型銀行** — 規模經濟下,中小行難以攻破成本結構

### ⚠️ Threats(威脅)
1. **Macquarie 快速成長** — 房貸組合 +15-20% 年增率,從 ~$135bn → $160bn 一年內
2. **非銀行放款方** — Athena、Pepper Money、Tic:Toc 等 fintech 用低利率搶客
3. **RBA 利率上行(2026)** — 新一輪升息壓抑新貸款需求 + 違約風險回升
4. **APRA Buffer 3%** — 服務能力測試壓抑房貸批准率
5. **開放銀行(CDR)** — 客戶轉換成本下降,流失率上升
6. **房價回落(SYD/MEL)** — 2026 兩大主力市場月跌 −0.6%,LVR 風險回升

## Porter's Five Forces 分析

### 🥊 1. 現有業者間競爭 — **HIGH ↑**
**IBISWorld 評分: High, Increasing**

**證據:**
- 四大行合計房貸市占 74.6%,但內部競爭白熱化:
  - Westpac、ANZ 努力追趕 CBA(但近年成長落後)
  - NAB 守住中型房貸利基
- Macquarie、Bendigo、Suncorp 等中型銀行靠較低利率切入
- 開放銀行讓客戶比價成本下降 → 利率戰加劇

**對 CBA 影響:** 防守為主,靠規模 + 服務質量 + 自有通路維持溢價

### 🚪 2. 新進入者威脅 — **LOW(下降中)**
**IBISWorld 評分: Barriers to Entry High, Decreasing**

**證據:**
- APRA 銀行牌照仍是高門檻(資本要求 + 合規)
- 但 Open Banking(CDR)+ 數位優先銀行降低部分壁壘:
  - Up Bank、86 400 等獲得 ADI 牌照
  - 非 ADI 房貸放款方繞過銀行牌照
- Fintech 在房貸領域已有 ~5% 市占並持續擴大

**對 CBA 影響:** 短期威脅有限,但需透過數位投資維持競爭力

### ⚔️ 3. 替代品威脅 — **LOW Steady**
**IBISWorld 評分: Substitutes Low, Steady**

**證據:**
- 房貸最根本替代品 = 租屋(2024年澳洲租屋成長 +30%,但仍占住宅市場 ~30%)
- 自有資金:私募基金、家庭借貸,規模小且非組織化
- BNPL 等 fintech 主要侵蝕**消費信貸**,非房貸

**對 CBA 影響:** 結構性穩固,房貸需求基本面不會被取代

### 👥 4. 買方議價力 — **LOW(上升中)**
**IBISWorld 評分: Buyer Power Low, Increasing**

**證據:**
- 個別房貸客戶議價力低(借款人多、單筆金額相對銀行體量小)
- 但 **Mortgage Brokers 聚合需求** → 行業 ~70% 新貸款透過 broker → broker 集體議價力上升
- 開放銀行讓比較與轉貸成本下降 → 客戶 stickiness 下降

**對 CBA 影響:** 必須維持自有通路 66% 抵銷 broker 議價壓力

### 🏭 5. 供應商議價力 — **HIGH Steady**
**IBISWorld 評分: Supplier Power High, Steady**

**「供應商」= 存款戶 + 批發資金市場 + 監管機構**

**證據:**
- 存款戶在升息週期積極比較存款利率 → 推升銀行資金成本(NIM 壓力)
- APRA / RBA 不斷調整資本要求 + Buffer + LMI 等規定
- 批發融資市場成本受國際信用利差影響

**對 CBA 影響:** 大型銀行較中小行有更多存款基礎(零售存款佔 75%+),相對緩衝

### 📊 6. 行業集中度 — **HIGH**

**證據:**
- 四大行合計房貸市占 **74.6%**(2025年3月)
- HHI 指數估算 **~1,800**(中度走向高度集中)
- 屬於典型寡占市場(Oligopoly)

**對 CBA 影響:**
- 寡占有利於價格紀律(避免破壞性價格戰)
- 但同時引起監管關注(Royal Commission 2018 後合規成本永久性提升)

---

## 五力綜合評分(對 CBA 房貸的吸引力)

| 力量 | 對 CBA 影響 | 嚴重度 |
|---|---|---|
| 現有競爭 | ↑ 高且上升 | 🟠 高 |
| 新進入者 | ↓ 低但下降中 | 🟢 中 |
| 替代品 | → 低且穩定 | 🟢 低 |
| 買方議價力 | ↑ 低但上升 | 🟡 中 |
| 供應商議價力 | → 高且穩定 | 🟠 高 |
| 集中度 | High | 🟢 利多(寡占紀律) |

**結論:** CBA 房貸業務面臨的競爭結構**整體中性偏正面**,主要威脅來自:
1. 同業競爭(尤其 Macquarie)
2. 存款定價戰侵蝕 NIM
3. 數位轉型壓力

但結構性因素(替代品低、集中度高、新進者障礙仍存)為 CBA 提供護城河。
