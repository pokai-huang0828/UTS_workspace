## 3. 2.1 描述性分析與預測性分析(Page)
> ref: 2-dot-1-miao-shu-xing-fen-xi-yu-yu-ce-xing-fen-xi | updated 2026-10-19T05:04:28Z

單元二｜數據分析與機器學習技術概述

[圖:]

數據分析能夠幫助企業探索和研究其數據，從中提取有價值的知識。所發現的見解最終可以支持企業作出更明智的決策。分析主要分為兩種類型，即描述性分析和預測性分析。它們分別回答不同的問題。

描述性分析回答的問題是：

“ 過去發生了什麼？”

預測性分析回答的問題是：

“未來可能會發生什麼？”

### 描述性分析

描述性分析回答“過去發生了什麼”這一問題。它利用已經收集並存儲的歷史數據進行分析。描述性分析的主要目標是說明已經發生的事情，從而找出過去成功或失敗背後的原因。描述性分析通過簡單的數學和統計方法（例如算術運算）對現有數據進行彙總，然後利用折線圖、餅圖等可視化工具展示分析結果，使廣大業務受眾能夠輕鬆理解這些發現。

數據聚合（Data Aggregation）和數據挖掘（Data Mining）是描述性分析的兩項關鍵技術。數據聚合是收集原始數據並以彙總形式表達數據的過程。在完成數據聚合這一階段後，接下來進行數據挖掘，以識別模式和趨勢，並以易於理解的方式呈現相關洞見。

描述性分析通常應用於日常業務活動中，以獲取有助於決策的洞見，因為它易於應用，並且不一定需要深入的分析知識。另一方面，描述性分析的侷限性在於，它只能解釋歷史數據，而不能進行推斷或預測。例如，一份基於描述性分析的銷售報告可以提供過去按月或按年的銷售趨勢，但無法預測下個月或下一年的銷售情況。

### 預測性分析

預測性分析回答“未來可能會發生什麼”這一問題。它側重於根據當前可獲得的數據預測未來可能出現的結果。預測性分析能夠幫助企業設定切實可行的目標、制定有效計劃、合理管理預期以及控制風險。

預測性分析建立在概率的基礎之上。它利用統計建模、數據挖掘和機器學習等多種技術，預測未來結果發生的可能性。為了預測未來，算法會通過研究模式並識別現有數據集中各變量之間的關係，從而作出儘可能準確的推測。預測性分析所需的計算通常比描述性分析更加複雜。

請注意，預測性分析永遠不可能做到完全準確，因為它基於概率進行預測。大量歷史數據以及合適算法的選擇，都有助於提高預測的準確性。

## 4. 2.2 監督學習與無監督學習(Page)

單元二｜分析與機器學習技術概述

[圖:]

人工智能是指讓計算機表現出與人類所展示的智能行為相似的能力。人工智能這一術語是在 1956 年達特茅斯會議（Dartmouth Conference）上提出的。智能代理（Intelligent Agents）是能夠感知其環境並採取行動，以最大化實現某一目標成功概率的設備。

機器學習可以被定義為人工智能的一部分，也可以被視為人工智能的一種應用實例。在機器學習中，計算機能夠在無需明確編程的情況下自主學習。它允許系統基於實時場景中的數據進行自主調整和改進。

機器學習主要分為兩大類技術，即 監督學習（Supervised Learning） 和 無監督學習（Unsupervised Learning）

### 監督學習

顧名思義，監督學習存在一個“監督者”，利用經過良好“標註”的訓練數據來教導或訓練機器。所謂標註數據，是指部分輸入數據已經標記了正確的輸出結果。在監督學習中，提供給機器的訓練數據就像監督者一樣，指導機器正確預測輸出結果。其理念與學生在教師指導下學習的過程相同。監督學習方法通過訓練數據中的輸入與輸出樣本對學習兩者之間的關係，然後利用所學關係對新的“輸入”數據進行預測。

監督學習技術可進一步分為兩大類：迴歸（Regression）和分類（Classification）。

迴歸

是預測連續數值的過程，例如 “天氣溫度” 和 “年度收入”。

分類

是預測類別型輸出的過程，例如“是（Yes）”或“否（No）”，以及“紅色（Red）”“藍色（Blue）”或“綠色（Green）”。

監督學習技術的示例包括：

- 線性迴歸 Linear regression
- 邏輯迴歸 Logistic regression
- 決策樹 Decision tree
- 隨機森林 Random forest
- 支持向量機 Support vector machines
- 神經網絡 Neural networks

監督學習可應用於風險評估、圖像分類、欺詐檢測、垃圾郵件過濾等領域。

### 無監督學習

另一方面，無監督學習試圖從未標記數據中學習隱藏的模式。由於在先前訓練階段沒有提供帶標籤的數據，因此無監督學習能夠自行發現數據集的底層結構，並根據相似性、模式和差異對數據進行分組。無監督學習可以類比為人類大腦在學習新事物時所經歷的學習過程。通常，無監督學習能夠識別數據中的聚類、群組以及頻繁出現的模式。

無監督學習技術的示例包括：

- K均值聚類
- 層次聚類
- K最近鄰算法
- Apriori 算法
- 主成分分析

無監督學習可用於購物籃分析、客戶細分、異常檢測、推薦系統等。

### 監督學習與無監督學習

| | 監督學習 | 無監督學習 |
|---|---|---|
| 訓練數據 | 訓練需要帶標籤的數據 | 不需要帶標籤的訓練數據 |
| 計算複雜度 | 較簡單 | 計算複雜度較高 |
| 準確性 | 準確率較高 | 準確率較低 |

### 什麼是數據預處理

期望獲得完全完美的數據是不現實的。數據收集過程中存在的缺陷、測量設備的侷限性或人為錯誤都可能導致一些問題。為了解決這些問題，數據預處理是一種經過驗證的有效技術。良好的數據準備工作能夠提高後續分析的效率，減少錯誤，並確保所有必需的數據可供所有用戶訪問。

數據預處理是數據分析過程中的一個基礎步驟，它將原始數據轉換為可理解的格式。數據通常來自多個來源，而這些來源往往並不十分可靠，並且數據格式各不相同。在這種情況下，在處理數據分析問題時，往往有超過一半的時間被用於處理與數據質量相關的問題。

原始數據通常可能存在缺失值或不一致值，同時還包含大量冗餘信息。原始數據最常見的問題可以分為以下三類：缺失數據、噪聲數據和不一致數據。點擊每張卡片瞭解更多內容。

缺失數據 Missing Data

缺失數據通常出現在數據收集階段出現問題時，例如系統停機、數據錄入錯誤或隱私相關問題。

噪聲數據 Noisy Data

這一類別包括錯誤數據和離群值，這些都屬於無意義的信息。噪聲可能由人為錯誤、罕見異常情況、錯誤標註以及數據收集過程中出現的其他問題所導致。

不一致數據 Inconsistent Data

當數據以不同格式存儲在多個文件中時，就會出現數據不一致的問題。不同格式的重複數據、名稱編碼中的錯誤，或者缺乏數據約束，往往會導致數據不一致。

如果不處理上述問題，最終結果可能是不恰當且不準確的。當在數據挖掘之前應用數據預處理技術時，它們能夠顯著提高所挖掘模式的整體質量或縮短實際數據挖掘過程所需的時間。

數據處理技術包括：

- 數據清洗 Data cleaning
- 數據集成 Data integration
- 數據轉換 Data transformation
- 數據縮減 Data reduction

點擊各個標籤，瞭解更多關於這些技術的信息。

數據清洗

數據中可能存在許多缺失或無關的元素。數據清洗技術旨在填充缺失值、平滑噪聲數據、剔除無關數據或解決數據中的不一致問題。

為了處理缺失數據，通常採用以下兩種方法。

- 忽略包含缺失值的記錄。當同一記錄中存在多個缺失值時，該方法適用於大型數據集。
- 手動填充缺失值。缺失值是手動填充的，通常使用最可能的值或屬性均值。這種方法不適用於大型數據集，且過程耗時。

平滑噪聲數據主要有以下三種方法：

- 分箱 Binning: 該方法基於鄰近值對存儲的數據進行平滑處理。排序後的數值被劃分為若干個“桶”（或稱“箱”）。由於分箱法利用了鄰近數據，因此也被稱為局部平滑。可以將某個區間內的所有數據替換為該區間的平均值或邊界值。
- 迴歸 Regression: 數據平滑也可以通過迴歸來實現，這是一種將數據值映射到函數的技術。線性迴歸旨在尋找一條“最佳”擬合直線來描述兩個變量（或屬性）之間的關係，從而利用其中一個變量來預測另一個變量。
- 聚類 Clustering: 針對一組數據點，該方法利用聚類算法將每個數據點分配到特定的組中。每個聚類包含一組彼此距離較近、但與其他聚類距離較遠的數據點。位於聚類之外的數據點（即所謂的離群點）會被剔除。

數據集成

數據集成是另一種數據預處理技術，如下圖所示，它通過將來自各種異構數據源的數據合並到一個統一的數據存儲中，從而提供數據的統一視圖。這些數據源可以包括平面文件、數據庫或多個數據立方體。

謹慎的集成有助於避免並減少最終數據集中的不一致性和冗餘，從而提高後續挖掘過程的速度與準確性。構建企業數據倉庫被視為最常見的數據集成應用之一。

在實際操作中，數據集成面臨著諸多挑戰。

- 模式集成 Schema of integration: 將擬議或現有的數據庫模式集成到一個統一的全局模式中。元數據也可以從各種來源進行集成。例如，兩個模式中名為“設備（Equipment）”的屬性可能指代不同的事物：第一個“設備”可能指計算機、複印機等，而第二個“設備”則指空調、傢俱等。
- 語義異構性 Semantic heterogeneity: 當獨立方針對同一領域或數據庫模式開發數據集時，不同來源中的相似值可能具有不同的含義。例如，某個數據庫中的“Title”字段可能代表“Person Title”（個人頭銜/稱謂），而在另一個數據庫中則代表“Job Title”（職位名稱）。
- 記錄重複 Record duplication: 這是數據冗餘的另一種形式，即針對同一個特定的數據實體，存在兩條或多條相同的記錄。重複記錄之間往往會出現不一致的情況，這通常是由於數據錄入錯誤或僅更新了部分數據副本造成的。例如，一個採購訂單數據庫包含購買者的姓名和地址屬性；如果缺乏與購買者數據庫中相關信息的關聯鍵（key），就可能出現數據不一致，比如同一購買者的姓名對應了不同的地址。
- 數據值衝突 Data value conflicts: 對於同一個現實世界實體，來自不同來源的屬性值可能各不相同。這可能是由編碼、量綱（尺度）或表示方式的差異引起的。例如，某個系統中以英制單位存儲的重量屬性，在另一個系統中可能以公制單位存儲。為了實現成功的數據集成（參見數據審計），元數據通常是必不可少的。

數據轉換

在數據轉換過程中，數據被整合或轉換為適合分析的格式，從而提高後續挖掘過程的效率，並使發現的模式更易於理解。

數據轉換可以採用多種策略，包括：

- 平滑（Smoothing）：平滑是指去除數據中的噪聲。平滑技術包括數據清洗中提到的分箱（binning）、迴歸和聚類。
- 聚合 （Aggregation）: 聚合是指應用統計指標（如均值、中位數和方差）來彙總數據的過程。生成的聚合數據將用於數據挖掘算法中。為了在多個粒度上分析數據，聚合通常用於構建數據立方體。
- 概括 （Generalisation）: 這包括利用概念層次結構，將低層級數據（原始數據）替換為高層級概念。
- 歸一化 （Normalisation）: 歸一化旨在確保每個樣本的值具有同等權重，並能被統一理解。歸一化在神經網絡等分類算法，或最近鄰分類和聚類等涉及距離度量的算法中非常有用。典型的歸一化技術包括最小-最大歸一化（min-max）、Z-score 標準化和十進制標度法（Decimal scaling）。

數據縮減

對海量數據進行複雜的數據分析和挖掘是一個耗時的過程，往往導致分析變得不切實際或不可行。可以採用數據縮減的方法來獲取一個規模更小、但數據質量與原始數據相當的歸約數據集。其目標是在降低數據存儲和分析成本的同時，提高存儲效率。.

數據縮減的策略包括：

- 數據聚合 Data aggregation: 常用於構建數據立方體，以便在多個抽象層級上進行數據分析。多維聚合信息存儲在數據立方體中。
- 降維 Dimensionality reduction:也稱為特徵選擇或屬性子集選擇。該方法通過檢測並剔除弱相關、冗餘或不相關的維度（或屬性）來實現。降維的目標是確定一個最小屬性集，使得由此產生的數據類概率分佈儘可能接近使用所有屬性時得到的原始分佈。
- 數量歸約 Numerosity reduction: 通過採用非參數模型（如數據聚合、抽樣、聚類或直方圖）或參數模型（如對數線性模型或迴歸模型），用更小的數據表示形式來替代原始數據。這使得存儲數據模型（例如迴歸模型）成為可能，而無需存儲全部數據。
- 抽樣 Sampling: 這是數據選擇的主要方法，它允許用較小的隨機子集（或樣本）來代表大型數據集。它常用於數據的初步探索以及最終分析。在數據分析中，由於處理整個數據集往往耗時或成本高昂，因此經常使用抽樣。如果樣本具有與原始數據集大致相同的（關注的）特性，則稱該樣本具有代表性。用於數據縮減的常見抽樣方法包括簡單隨機抽樣、不放回抽樣、有放回抽樣、聚類抽樣和分層抽樣。
- 離散化與概念層次生成 Discretisation and concept hierarchy generation: 數據離散化是一種數量歸約形式，它將連續屬性轉換為分類屬性。通過使用更高層的概念標籤或較少數量的區間（即分箱/binning）來替代原始數據，從而簡化數據並提高挖掘效率。離散化對於自動生成概念層次結構非常有益。在數據挖掘中，概念層次生成和離散化是強有力的工具，能夠支持在多個數據抽象層面上進行數據挖掘。

## 6. 2.4 數據聚類(Page)

聚類是將數據點劃分為若干組的過程，使得同一組中的數據點彼此之間的相似度高於與其他組中數據點的相似度。簡單來說，其目標是將相似的對象歸為一組。

### 硬聚類與軟聚類

聚類可以分為兩大類：軟聚類（Soft Clustering）和硬聚類（Hard Clustering）。

- 在硬聚類中，一個對象只能屬於一個聚類，並且對象之間能夠較容易地被劃分到不同聚類中。
- 在軟聚類中，由於各聚類之間不存在明確的界限，一個對象可能同時屬於一個或多個聚類。

### 相似性與距離

相似性（similarity）與距離（distance）的概念彼此相反。兩個數據點之間的距離非常短時，其相似性就非常高；反之亦然。

為了衡量項目之間的相似性，需要有一種方法來度量這些項目之間的距離。距離度量方法的選擇非常重要，因為它會對聚類結果產生顯著影響。常見的距離度量包括曼哈頓距離（Manhattan distance）、歐幾里得距離（Euclidean distance）和餘弦相似度（Cosine similarity）。根據數據類型和研究問題的不同，也可能更適合採用其他不相似性度量。例如，基於相關性的距離（correlation-based distance）常用於基因表達數據分析。

### 什麼是好的聚類?

一種好的聚類方法能夠生成高質量的聚類結果，即具有較高的類內相似性（intra-class similarity）和較低的類間相似性（inter-class similarity）。

聚類結果的質量既取決於該方法所使用的相似性度量，也取決於其具體實現方式。這兩個方面將在本單元後續內容中進行討論。聚類方法的質量還可以通過其發現部分或全部隱藏模式的能力來衡量。

由於聚類尚無精確的定義，因此不同技術採用不同的聚類準則。聚類可以從多個方面進行分類，例如層次聚類技術和劃分聚類技術。聚類還可以分為基於模型的方法（model-based methods）、基於密度的方法（density-based methods）以及基於網格的方法（grid-based methods）。下圖展示了聚類方法的分類體系。

## 7. 2.5 數據可視化(Page)

數據可視化是通過圖表、圖形或地圖等形式，向觀看者傳達數據之間關係的過程。與直接查看原始數據點相比，當人們看到圖表或圖像時，更容易從數據中獲得洞察，例如識別相關性和異常值。

我們希望對數據進行可視化，因為數據本身只是對某些現象或事件的抽象表達，而這些現象或事件正是我們希望理解的對象。單純的數字無法幫助我們理解情境並回答問題，因此將數據轉換為可視化形式至關重要。人類是視覺導向的生物，擅長處理視覺信息；我們大腦中約有30% 的大腦皮層 (https://www.discovermagazine.com/mind/the-vision-thing-mainly-in-the-brain)專門負責視覺處理。

### 數據可視化過程

數據可視化過程包含若干要素，如下圖所示。首先是數據；如果沒有數據，就無法呈現任何信息。當數據被收集後，它會被轉換或編碼為圖表或圖形。隨後，由人類觀察這些可視化內容並感知其中的信息。在完成感知後，人類應能夠通過查看可視化內容來回答某些問題。

### 說明性可視化 Explanatory visualisation

說明性可視化用於向他人傳達和解釋某個觀點。當人們需要傳遞某種信息或想法時，可以創建可視化圖表來展示內容。它本質上是一種溝通形式。

如需查看一些優秀的說明性可視化案例，可以訪問 Driven by Data。 (https://driven-by-data.net/)在其中一個案例，運動員出生國家的堆疊面積圖中， (https://driven-by-data.net/2017/12/29/sports-i18n)你可以看到，1960 年葡萄牙足球超級聯賽（Portuguese Primeira Liga）的大多數球員都來自葡萄牙，以及這一趨勢隨後如何發生變化。到 2015 年底，該聯賽的球員已經來自各種不同的背景。超過 50% 的球員來自歐洲其他國家、南美洲國家或非洲國家。特別值得注意的是，相當大比例的球員來自巴西和安哥拉等葡萄牙語國家。

### 探索性可視化 Exploratory visualisation

另一方面，探索性數據分析用於從數據內容中提取信息，其目標是回答問題並生成新的假設。在探索性可視化中，分析者嘗試分析數據，以實現某種目標或回答特定問題。

例如，你可以利用紐約市開放數據平臺（NYC Open Data visualisation tool (https://data.cityofnewyork.us/d/h9gi-nx95/visualization)）提供的紐約市機動車碰撞數據集（New York City vehicle collisions dataset (https://data.cityofnewyork.us/Public-Safety/Motor-Vehicle-Collisions-Crashes/h9gi-nx95)）進行探索性數據可視化，以回答以下問題：受傷事件發生的頻率如何隨時間變化？

- 數據選擇（Data Selection）標籤頁中，在維度（Dimension）字段輸入“CRASH DATE”，並在度量（Measure）字段輸入“NUMBER of PERSONS INJURED”
- 系統應推薦顯示“時間線圖（Timeline Chart）”作為可視化形式，其中碰撞日期（Crash Date）顯示在橫軸（x-axis），受傷人數頻率顯示在縱軸（y-axis）。（如果可視化結果以其他形式顯示，請選擇“時間線圖”）

何時

在整個項目過程中，持續展示數據是一種常見做法。你可能會為自己的實驗快速創建數據可視化，以幫助解釋和理解結果。可視化內容和分析結果可能會在團隊會議中與團隊成員分享，或在與利益相關者溝通時進行展示。項目報告中的一個重要組成部分也是數據展示。

建議你養成保存數據展示內容和數據可視化成果的習慣。特別是，要有條理地進行整理，並清晰記錄數據來源（provenance）以及實驗過程。這些資料將有助於你在項目期間重新利用所積累的相關成果和材料。

為什麼

我們呈現數據，是為了讓數據講述一個故事。當然，每個數據故事都是獨特的。然而，關於為什麼要呈現數據，通常存在一些共通的主題。這些包括：

- 展示趨勢
- 進行比較
- 識別異常值
- 展示關係
- 表明績效水平（評估結果）
- 展示運作過程（圖示）

當你準備向他人呈現數據時，請問自己：“我希望這些數據講述什麼故事？”也就是說，需要傳達的核心信息是什麼？它是否符合上述已知主題中的某一種？

如何

一般來說，呈現數據有三種方式：

1. 圖表（plots/charts）
2. 表格（tables）
3. 圖示（diagrams）

選擇有效的數據呈現方式，將取決於你希望數據講述的故事，以及受眾的背景情況。接下來的章節將更詳細地探討各種可選方案。

是否使用表格不應是隨意決定的。只有當表格能夠滿足溝通需求時，我們才選擇用表格來呈現數據。當我們以表格形式向他人展示原始數據時，也是在表明我們對自己的分析結果或結論充滿信心。讀者可以利用表格自行得出結論，而這些結論往往會進一步證明我們的分析是正確的。

在以下情況下，表格可能比圖表更適合：

- 人們需要查閱個別數據值。
- 需要比較成對的數據值，而不是比較整個數據集。
- 需要精確的數據值，並且可能需要同時提供彙總統計信息。
- 數據涉及不同的計量單位，而這些單位不適合放在同一圖表中展示。
- 數據值之間差異過大，以至於無法使用統一的刻度進行繪圖。
- 僅需展示少量數值（例如不超過 20 個數值）。

在使用表格呈現數據時，通常會對特殊數值進行突出顯示（例如加粗處理），如異常值或獲勝者。下面的示例展示了一種較為極端的方法，即將圖形化表示疊加到表格中，從而提升表格的實用性。

#### 示例

### 優秀圖示的提示

以下是一些創建有效圖示的提示。你的圖示應當……

易於理解

- 在圖示符號的使用上保持一致。對於同一種概念，使用相同類型的形狀；對於同一種關係，使用相同類型的線條。僅在需要表示方向性時使用箭頭。
- 應將圖示元素的使用視為一種表達含義的語言。
- 圖表應儘量利用易於識別和理解的隱喻，例如填滿水桶、建造房屋、液體流動、繪製旅程路線等。
- 優先使用傳統且廣為接受的圖標形式，而不是自行創造新的圖標（如垃圾桶、磁盤驅動器、雲朵、表情符號等）
- 在使用正式圖表時，應遵循所選正式圖表方法論的規範。

易於閱讀

- 應清楚區分哪些內容屬於圖表的一部分，哪些不屬於。請在圖表周圍留出足夠的留白，或使用邊框線，或採用背景陰影，以明確界定圖表的邊界。
- 字體大小應足夠清晰易讀。通常情況下，圖表中所使用的字體可以比報告正文中的字體略小，但不應小太多。
- 文字不應穿過線條，也不應被遮擋。
- 文字應儘量保持一致的閱讀方向，並且無需旋轉頁面即可閱讀。
- 儘量採用不依賴顏色或細微變化來表達含義的圖表樣式。應考慮圖表在複印後的呈現效果。一般而言，圖表並不適合展示細微差別，這類內容更適合通過文字說明來表達。
- 在使用陰影或顏色時，應確保具有足夠的對比度。

一致性

- 儘量在所有圖表中使用相同的字體、線條樣式和配色方案。所使用的字體不必與報告正文的字體相同。
- 儘量保持對象大小的一致性。只有在需要強調某個重點時，才應改變對象的大小。

美觀

- 圖表應具有一定的對稱性或平衡感。
- 確保所有對象都經過適當的對齊和均勻分佈。
- 選擇與內容的專業性和整體風格相協調的樣式及配色方案。對於技術報告，應採用傳統、穩重的視覺風格，避免使用柔和的粉彩色和過於突兀的顏色。
- 文字和其他組成部分不應顯得過於擁擠，也不應過於稀疏。
- 避免出現像素化現象，優先使用經過抗鋸齒處理的字體和線條。
- 應優先追求簡潔，而非複雜。

### ACCENT 原則

圖表的本質在於清晰地傳達定量信息。ACCENT 原則強調了決定數據可視化展示效果的六個方面。這些原則摘自 D. A. Burn 的《有效圖形展示原則》（Principles for Effective Graphical Display）。

- Apprehension 理解性: 正確感知變量之間關係的能力。
圖表是否最大程度地幫助讀者理解變量之間的關係?
- Clarity 清晰性: 在視覺上區分圖表所有元素的能力。 (最重要的元素或關係是否在視覺上最為突出？)
- Consistency 一致性: 基於與先前圖表相似性來解釋圖表的能力。(圖表中的元素、符號形狀和顏色是否與之前圖表中的用法保持一致？)
- Efficiency 效率性: 以儘可能簡單的方式呈現可能較為複雜關係的能力。(圖表元素是否得到經濟且有效的使用？圖表是否易於理解？)
- Necessity 必要性: 圖表及其圖形元素存在的必要性。(與其他表示方式相比，圖表是否是展示數據的更有效方法？圖表中的所有元素是否都有助於傳達相關關係)
- Truthfulness 真實性: 圖形元素的大小、位置和比例是否能準確反映其所代表的真實數值。 (圖表元素的位置和比例是否準確？)

- 平均氣溫

## 15. 2.10 預測分析中的機器學習算法(Page)
> ref: 2-dot-10-yu-ce-fen-xi-zhong-de-ji-qi-xue-xi-suan-fa | updated 2026-10-15T23:16:04Z

單元二｜分析與機器學習技術概述

[圖:]

機器學習算法經常被用於在數據分析項目中構建預測模型，尤其是在涉及預測分析的項目中。在本週的學習過程中，我們將介紹四大類機器學習算法，包括線性模型、決策樹、集成方法和神經網絡。在深入學習這些技術細節之前，讓我們先對它們形成一些基本認識。

線性模型

線性模型用於通過自變量（x）的線性組合來描述因變量（y）。構建線性模型的目標是建立一個數學公式，將 y 定義為 x 變量的函數，也就是說，通常表示為各個 x 值加權求和的結果。一旦確定了這個函數，我們便可以利用它根據新的 x 值預測未來的 y 值。在實踐中，線性模型通常是進行建模時的首選嘗試方法，因為它們相對簡單。我們將在 2.11 線性模型族（Linear family） 頁面學習線性模型的相關內容。

決策樹

決策樹是一種樹狀結構圖，用於描述一系列相關決策可能產生的結果。它通常從一個稱為“根節點（root node）”的單一節點開始。根節點分支出各種可能結果，而這些結果又會延伸出更多節點，並進一步分支出其他可能性，直至到達稱為“葉節點（leaf nodes）”的終端節點。葉節點表示從根節點沿著某一決策路徑到達的最終結果。構建決策樹的關鍵在於找到最適合作為節點來對數據進行分支劃分的變量。決策樹具有非常強的可解釋性，容易理解，但也容易出現過擬合問題。我們將在 2.12 決策樹（Decision trees） 頁面學習如何識別用於“分裂（splitting）”的節點。

集成方法

集成方法是一類通過構建多個模型並將其組合起來，從而生成改進模型的技術。與單一模型相比，改進後的模型通常具有更好的性能。集成方法背後的核心思想是“組合”。我們將在 2.13 集成方法頁面向你介紹多種組合多個模型的方法。

神經網絡

神經網絡，也稱為人工神經網絡（Artificial Neural Networks），其設計靈感來源於生物神經系統處理數據的方式。神經網絡是深度學習（Deep Learning）的核心組成部分，而深度學習已經在許多現實世界應用中取得了巨大成功。神經網絡由多個節點層（node layers）組成，包括一個輸入層（input layer）、一個或多個隱藏層（hidden layers），以及一個輸出層（output layer）。節點（node），也稱為人工神經元（artificial neuron），是神經網絡中的基本單元。每個節點都與其他節點相連接，並且具有相應的權重（weight）。2.14 神經網絡（Neural Networks） 頁面將在第 2.2.2 節介紹的感知機模型（Perceptron Model）基礎上，進一步介紹人工神經元的概念。神經網絡通常能夠實現非常高的預測準確率，但需要大量數據來訓練模型。

本單元後續頁面將深入探討這四大類機器學習方法的技術細節。針對每一種方法，都設計了一項學習活動，以幫助你理解各類方法的優勢與侷限性。

## 16. 2.11 線性模型族(Page)
> ref: 2-dot-11-xian-xing-mo-xing-zu | updated 2026-10-19T03:09:49Z

單元二｜分析與機器學習技術概述

本頁將介紹“線性（Linear）”模型族。這類模型廣泛應用於數據分析項目中，既可用於迴歸問題，也可用於分類問題。

### 線性模型 Linear model

“線性模型”是一個統稱，用來描述這樣一種簡單而直接的思想：目標變量與所有數據屬性加權求和後的結果相關聯。當滿足適用條件時，即：當所有屬性都是數值型數據，或者已經被轉換為數值形式時，這一模型族通常能夠提供有助於表示屬性與目標變量之間關係的假設。

從 [圖:LaTeX: X_1, \dots, X_k] 形式上來看，給定各項屬性，線性模型假設用於重現目標變量 Y 所需的全部信息都可以概括為一個單一數值，而這個數值[圖:LaTeX: a = x_1\cdot w_1 + x_2 \cdot w_2 + \dots + x_k \cdot w_k] 就是各數據屬性加權求和後的結果。

感知機（Perceptron）模型族被視為線性模型的一個典型例子。感知機的設計靈感來源於生物神經系統：神經元通過與其他神經元的突觸連接接收刺激信號，並據此決定自身狀態。當累積的刺激超過某個閾值時，神經元被激活，並發出輸出信號。

感知機模型族將線性模型的思想應用於二元分類問題，其過程如下：首先計算數據屬性的加權和 a。然後將 a 與某個閾值進行比較，並根據比較結果預測目標變量。如果 a 超過該閾值，則樣本被分類為某一類別，例如正類（positive class）；否則，被分類為另一類別，即負類（negative class）。

由於判斷條件 a > b 等價於 a - b > 0，因此感知機分類器對數據樣本的處理可通過以下比較方式進行。

[圖:LaTeX: x_1\cdot w_1 + x_2 \cdot w_2 + \dots + x_k \cdot w_k + w_0 > 0]

其中，該項 [圖:LaTeX: w_0] 同時容納了在計算加權和 a 時的可選偏移常數（offset constant）以及前文提到的閾值（threshold）。在公式右側，比較對象始終為 0，這也是兩類分類結果命名的由來。 出於後續內容中將會說明的原因，習慣上將其中一類記為 +1，另一類記為 −1。也就是說，我們現在使用數字作為類別標籤（class labels）。 感知機 𝑓 對某個數據樣本 [圖:LaTeX: x_i] 進行預測並獲得預測結果 [圖:LaTeX: y_i] 這一事實，可表示為：[圖:LaTeX: f(x_i) \mapsto \tilde {y}_i] ， 由於預測類別和真實類別（ground truth class）都屬於{±1}，因此當且僅當（if and only if）滿足相應條件 [圖:LaTeX: \tilde {y}_i \cdot y_i = +1] 時，預測才是“正確的”；若結果為 −1，則表示預測“錯誤”。 請注意，下標 𝒊 表示數據集中某個樣本的索引（index），而不是某個數據屬性（attribute）的索引，不應將兩者混淆。

#### 動機

線性模型的動機是十分自然的。這類模型之所以受到廣泛應用，是因為它們在兩個方面都較為簡單：一方面，它們能夠表達的關係形式相對簡單；另一方面，在給定數據的情況下，尋找線性模型中最優權重解的計算成本也相對較低。

在實際應用中，當數據屬性為數值型，或者能夠方便地轉換為數值型時，線性模型族通常是經驗法則下的首選嘗試方法。

### 決策樹模型

決策樹模型體現了這樣一種思想：通過逐一檢驗數據屬性來消除目標變量的不確定性。直觀地說，這一過程就是針對某個數據樣本回答一系列問題，而每個問題都與某一項屬性有關。根據這些問題的答案，我們對目標變量的猜測會逐漸縮小範圍並變得更加準確。這個過程會持續進行，直到我們對目標變量達到足夠滿意的置信程度為止。

對於給定的數據樣本，這一過程類似於沿著一棵樹進行遍歷：

- 從樹的根節點（root）開始（當前節點 ← 根節點）。此時，除了知道目標值遵循總體數據分佈之外，我們對目標值沒有任何特定信息，因此不確定性最大。
- 在當前節點上進行處理。

- 葉節點終止(Leaf-node termination) 如果當前節點已經給出了目標值的預測結果，則終止流程並返回預測值；否則，
- 當前節點會指定一個數據屬性。我們檢查數據樣本中對應的屬性值。根據檢查結果，當前節點會指定應當進入的子節點。隨後將該子節點設為當前節點，並遞歸地繼續這一過程。

在統計學習（Statistical Learning）的框架下，決策樹這種以查詢為導向的目標推測過程，可以理解為不斷縮小數據空間中與目標概念對應的子集範圍。決策樹的假設（hypotheses）是能夠表示為這些子集並集（union）的概念。例如，在二維（2D）數據空間中，某些區域可能屬於正類（positive class）。

## 18. 2.13 集成(Page)
> ref: 2-dot-13-ji-cheng | updated 2026-10-15T23:16:04Z

單元二｜分析與機器學習技術概述

當處理複雜且困難的任務時，“分而治之”（divide-and-conquer）是一種自然而然的思路。對於機器學習問題而言，這意味著將多個經過學習得到的數據模型組合在一起，從而形成一個更複雜、更強大的模型。在本節中，我們介紹集成（ensemble）：集成是由多個預測器（predictors）組成的集合。我們可以將集成理解為一個負責執行預測任務的委員會。如果能夠證明該委員會比其單個成員能夠做出更可靠的預測，那麼就有可能利用較弱的預測器構建出可靠且準確的預測模型。

對於集成中所使用的成員預測器類型並沒有限制。這些成員預測器通常被稱為“基預測器（base predictors）”、“弱預測器（weak predictors）”，或者根據具體任務被稱為“基分類器／弱分類器”以及“基迴歸器／弱迴歸器”。出於實踐上的便利，人們通常使用簡單的決策樹來構建集成模型，例如“決策樹樁（decision stump）”，即僅在根節點（也是唯一節點）進行一次決策的決策樹。

最直接的集成方法是對多個預測器的結果取平均值。請回顧，預測器是基於隨機觀測到的數據學習得到的。這樣的隨機過程不可避免地會給學習系統引入方差。對多個預測器實例的結果取平均值，有助於降低這種方差。

對於實際問題，人們從哪裡獲得構建集成所需的多個預測器呢？

一種實用的方法是重採樣（resampling）技巧。我們從原始訓練樣本中隨機重新抽取偽訓練集（pseudo training sets），並在這些重採樣得到的數據上訓練預測器。這些訓練集副本彼此並非獨立。然而，我們仍然可以利用這些重採樣的數據來訓練弱預測器（weak predictors），並將這些訓練得到的預測器組合起來，構成有效的集成預測器。此外，重採樣還有助於衡量預測結果的方差（variance）。這種技術被稱為自助抽樣法（bootstrapping）。

已提出各種不同的集成方法，其區別主要在於：

- 如何對數據進行重採樣;
- 如何利用重採樣得到的數據副本來構建基預測器；以及
- 如何利用各個預測器組成委員會，從而形成集成模型

[圖:Bagging and boosting: explaining below.]改編自: Bagging and Boosting | Medium (https://medium.com/@saitejaposam9/bagging-and-boosting-2b6cd4a6bda1)

*parallel: 平行的；sequential：連續的

### Bagging（裝袋法）

Bagging 是一種直接且簡單的集成方法。給定一個訓練數據集，通過有放回抽樣（sampling with replacement）隨機抽取數據樣本，生成與原數據集大小相同的數據集副本。隨後，在這些重採樣（resampled）數據集上分別訓練各個預測器。最終的集成模型包含所有單獨訓練的預測器，並通過投票的方式進行決策。

不僅可以對數據實例進行重採樣，還可以隨機選擇屬性，從而形成隨機重採樣的數據副本。利用不同的重採樣策略，可以構建各種不同的決策樹。隨機森林就是一種集成模型，它由在隨機數據實例和隨機屬性集合上訓練得到的多個決策樹組成。

### Boosting methods（提升法）

Boosting 方法是一類利用重採樣訓練樣本構建集成模型的序列式迭代策略（sequential iterative strategies）。在每一次迭代中，都會從數據集中抽取一個帶權重的隨機樣本。樣本權重會根據當前模型對各個樣本進行預測的難易程度動態計算（初始步驟中所有樣本權重相同）。同時，基預測器也會根據其預測準確率被賦予不同的權重。

## 19. 2.14 神經網絡(Page)

神經網絡（Neural Networks）是最成功的模型家族之一。神經網絡最基本的實現形式也稱為多層感知機（Multi-layer Perceptrons，MLP）。從這個名稱不難看出，神經網絡模型家族與某一種線性模型（linear model）有著密切聯繫。回顧一下，線性感知機模型（linear perceptron model）是對數據屬性與預測目標之間關係的一種直接表達方式。

線性模型通過計算數據屬性的加權和（weighted sum），再通過簡單的閾值判斷（thresholding，即與 0 進行比較）[圖:LaTeX: a=w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + \dots] 將計算結果與預測結果聯繫起來：隨後根據是否滿足[圖:LaTeX: a > 0]進行預測。針對這種簡單的方案，可以有多種擴展方式，從而使數據模型能夠對具有更加複雜關係的數據[圖:LaTeX: (\mathcal X,\mathcal Y)]進行分類。

### 擴展類型 A

模型輸出與數值 [圖:LaTeX: a] 的關聯方式可以不同於二元閾值判斷。例如，一個“軟決策”可以是 [圖:LaTeX: \frac{1}{1 + e^{-a}}] 建議你繪製該函數在一系列輸入值 [圖:LaTeX: a] 下的響應曲線，以便理解為什麼它被稱為“軟決策”。

更複雜的模型可以通過遞歸構造（recursive constructions）來建立。理解這一思想有兩種等價的方式。自上而下：在計算感知機模型時，我們可以用經過處理的特徵來替代原始輸入數據屬性。此外，這種處理過程本身也可以由其他底層感知機模型來完成。自下而上：與其讓感知機模型的輸出直接連接到預測目標，不如將這些輸出饋送到更高層的感知機模型中。

這兩種視角表達的是同一個思想：感知機（perceptron）可以通過層次化的方式組合起來，從而構建複雜的數據模型，如上方的公式塊所示。需要注意的是，這種層次結構並不限於兩層。現代深度神經網絡可以使用幾十層甚至超過一百層的類感知機模型，在執行預測任務之前，對數據構建高度複雜的表示（representation）。

## 20. 2.15 深度學習(Page)
> ref: 2-dot-15-shen-du-xue-xi | updated 2026-10-19T03:22:03Z

單元二｜分析與機器學習技術概述

深度學習是機器學習的一個分支。深度學習利用神經網絡（其設計靈感來源於人腦的結構和功能）來執行分類、迴歸和表示學習等任務。近年來，深度學習因其能夠處理大量數據，並完成圖像識別、自然語言處理、語音翻譯和推薦等複雜任務而受到廣泛關注。

神經網絡（也稱為人工神經網絡）由稱為神經元的連接節點組成。神經元是一種函數，它接收一個或多個輸入，對這些輸入應用權重，並將其求和以生成輸入。這一計算過程稱為前向傳播（forward propagation）。

在前一頁“2.14 神經網絡”中，我們已經瞭解到，神經網絡通常包含一個輸入層、一個或多個隱藏層以及一個輸出層。僅包含一個隱藏層的神經網絡稱為淺層神經網絡（shallow neural network）。包含多個隱藏層的神經網絡稱為深度神經網絡（deep neural network）。“深度學習”中的“深度”一詞，指的是使用由多個隱藏層組成的神經網絡。隱藏層數量的選擇取決於問題的性質以及數據集的規模。

目前有多種廣泛使用的深度學習模型，包括卷積神經網絡（Convolutional Neural Networks，CNNs）、循環神經網絡（Recurrent Neural Networks，RNNs）、生成對抗網絡（Generative Adversarial Networks，GANs）以及 Transformer 模型。

- 卷積神經網絡 (CNNs) 是一類特別適合處理結構化網格數據（如圖像）的神經網絡。CNN 在其至少一個網絡層中使用一種稱為卷積（convolution）的技術，而不是通用矩陣乘法。它們能夠自動且自適應地從輸入圖像中學習特徵的空間層次結構，從而支持圖像分類和目標檢測等任務。與傳統前饋神經網絡不同，RNN 具有循環連接結構，即網絡連接會反饋到自身。這使得先前時間步的信息能夠影響當前輸出，從而使網絡能夠保留對歷史輸入的記憶。CNN 的侷限性包括計算成本高、容易出現過擬合，以及僅適用於網格狀結構的數據。
- 循環神經網絡 (RNNs) 是一類專門用於處理序列數據的神經網絡，因此特別適合需要考慮上下文和順序信息的任務，例如時間序列分析、自然語言處理以及語音識別。RNN 的兩個常見變體是長短期記憶網絡（Long Short-Term Memory，LSTM）和門控循環單元（Gated Recurrent Units，GRUs）。RNN 的侷限性包括梯度消失或梯度爆炸問題，以及訓練時間較長。
- 生成對抗網絡 (GANs) 是一種用於生成與給定訓練數據集相似的新數據樣本的深度學習模型。GAN 由兩個神經網絡組成，分別稱為生成器（Generator）和判別器（Discriminator），兩者相互對抗，因此被稱為“對抗式（adversarial）”。GAN 擅長學習數據的結構和模式，並利用這些知識生成與原始數據集相似的新樣本。它們可用於圖像生成、文本生成圖像以及數據增強等任務。GAN 的侷限性包括訓練過程不穩定以及資源消耗較大。
- Transformer 模型 是一類於 2017 年提出的深度學習模型。由於採用了自注意力機制（self-attention mechanism），Transformer 相較於 RNN 具有一定優勢。該機制使模型在進行預測時能夠衡量序列中不同單詞（或標記，tokens）的重要性。這有助於模型理解上下文以及單詞之間的關係，而不受其在輸入序列中位置的影響。Transformer 已徹底改變了自然語言處理（Natural Language Processing，NLP）領域，並且現已廣泛應用於文本以外的多個領域，包括圖像處理和強化學習。Transformer 的侷限性包括計算成本高以及對大量數據的依賴。

## 21. 2.16 大語言模型(Page)
> ref: 2-dot-16-da-yu-yan-mo-xing | updated 2026-10-19T03:24:01Z

單元二｜分析與機器學習技術概述

語言模型 Language Models (LMs) 是經過訓練以理解和生成人類語言的機器學習模型。語言模型利用統計和概率方法來計算特定詞序列在句子中出現的可能性。從本質上講，語言模型可以被視為詞序列上的概率分佈。語言模型通過學習來自書籍、文章、網站及其他文本來源訓練數據中詞語和短語之間的統計關係，來預測句子中的下一個詞，或根據給定提示生成連貫的文本。

大語言模型 Large Language Models (LLMs) 是大規模的語言模型。在這裡，“大”既指訓練模型所需的大量數據，也指模型所包含的數十億甚至數萬億個參數。

自20世紀60年代以來，實現當今大語言模型能力的發展歷程已經持續了數十年。如今，我們在第 2.15 節深度學習中介紹過的 Transformer 已成為大語言模型最先進的架構。Transformer 的一個關鍵特徵是自注意力機制（self-attention mechanism），該機制能夠通過關注輸入中最相關的部分來處理更長的序列，從而克服早期模型所面臨的記憶限制。與按順序逐步處理輸入的早期循環神經網絡（Recurrent Neural Networks，RNN）不同，Transformer 能夠並行處理整個序列，因此顯著縮短了訓練時間。

大語言模型特別擅長其最初設計的任務，即根據給定輸入生成最合理、最符合語境的文本。除此之外，它們還具有廣泛的應用場景，例如問答、翻譯、摘要生成、搜索、推薦、虛擬助手、代碼開發以及情感分析等。

### 提示工程 Prompt engineering

提示工程是設計和優化輸入內容（即提示詞，prompts）的過程，其目的是與大語言模型（LLMs）有效溝通任務需求。由於大語言模型並不會以傳統意義上的方式“理解”內容，因此指令的措辭方式對於輸出結果的質量、準確性和實用性具有至關重要的影響。提示工程涉及精心選擇用詞、結構、上下文，甚至示例，以引導模型生成符合預期的回答。這種實踐在代碼生成、摘要生成、數據提取或創意寫作等應用場景中尤為重要，因為這些場景對清晰度和可控性有較高要求。提示工程還包括一些特定技術，例如少樣本提示（few-shot prompting，即提供示例）、思維鏈提示（chain-of-thought prompting，即鼓勵逐步推理），以及通過設定角色或約束條件來塑造輸出結果。 歸根結底，提示工程是在創造性地、精準地運用語言;有多種 API 可供使用，讓你能夠將大語言模型（LLMs）應用於各種場景，以最大限度發揮人工智能系統價值的過程。 請參閱這篇文章 (https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-the-openai-api)，瞭解使用 OpenAI API 進行提示工程的最佳實踐。

### 微調 Fine-Tuning

微調（Fine-Tuning）是一種用於使預訓練大語言模型適應特定任務或領域的技術，其方法是在較小的任務專用數據集上繼續對模型進行訓練。大多數現代語言模型基於 Transformer 架構構建，並首先在大規模且多樣化的文本語料庫上進行訓練，以學習通用語言模式。在微調過程中，開發人員會準備帶標籤的示例數據，並進一步訓練模型，使其參數得到調整，從而能夠針對目標任務生成更準確的輸出。該過程通常包括選擇基礎模型、準備並分詞（tokenise）數據集、使用優化算法訓練模型，以及評估模型性能等步驟。與提示調優（prompt tuning）不同，提示調優會保持模型參數固定，僅優化特殊的提示詞標記（prompt tokens）來引導模型輸出；而微調則會直接更新模型權重（weights），使模型能夠更深入地內化特定任務相關的知識，但同時也需要更多的計算資源和數據支持。由於需要利用大型數據集更新數百萬甚至數十億個參數，因此對大語言模型進行微調通常計算成本高昂且費用較高。該過程需要多次遍歷訓練數據，大量使用圖形處理器（GPU）或張量處理器（TPU），並進行精細的優化以避免過擬合（overfitting），這些都可能轉化為高額的雲計算或硬件成本。完整微調（full fine-tuning）還會消耗大量存儲空間和內存，因為針對每個專門化任務，通常都需要維護模型的獨立副本。為了降低成本，開發人員通常會採用參數高效（parameter-efficient）的技術，例如，LoRA微調技術的應用與優化 (https://cloud.tencent.com/developer/article/2672597)。LoRA 僅更新模型中的一小部分參數，同時保持大部分權重被凍結（frozen），與完整微調相比，可以顯著降低計算成本和財務成本。如需進一步閱讀，請查看 大模型微調實戰：從原理到落地的完整指南 (https://developer.volcengine.com/articles/7605549043544965158)

### 檢索增強生成 Retrieval-Augmented Generation

檢索增強生成是一種通過結合外部信息檢索能力與大語言模型生成能力來增強大語言模型性能的技術。RAG 並非僅依賴於編碼在模型參數中的知識，而是首先從相關文檔數據庫、知識庫或語料庫中檢索與用戶查詢相關的信息。 隨後，檢索到的內容會被整合到模型的輸入提示中，使模型能夠生成更加準確、更加及時且具有更強上下文依據的回答。 與提示調優（prompt tuning）僅通過優化特殊標記（tokens）或指令來引導凍結模型的輸出不同，也不同於微調通過任務專用數據更新模型內部權重的方式，RAG 在推理階段（inference time）動態注入外部知識，而不會修改模型本身。 這一特性使 RAG 特別適用於需要專業知識、事實準確性或訪問專有信息的任務，同時無需承擔微調所帶來的高成本和複雜性。 如需進一步學習，請參閱相關教程 (https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-the-openai-api)。

### 大語言模型的侷限性 Limitations of LLMs

- 訓練大語言模型（LLMs）成本高昂，因為其需要海量數據集以及大量計算資源。
- 大語言模型有時會生成不準確或虛構的信息，這種現象被稱為“幻覺（hallucination）”。當模型生成的回答看似合理，但實際上在事實層面錯誤或毫無意義時，就會出現這種情況。
- 由於這些模型是基於人類語言進行訓練的，因此可能引發一系列倫理問題，例如語言被濫用的風險，以及與種族、性別、宗教等因素相關的偏見問題。
