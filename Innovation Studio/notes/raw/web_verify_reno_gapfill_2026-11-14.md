## 加總驗算(算式)

來源數字取自 `web_reno_setup_2026-11-14.md`(grep 第 57、58、62、65、73、116 行)與本次頁面。

- 原「低」2,637:2,000(Minoan)+ 250(Hometime 攝影基本低標)+ 145(BuyWisely)+ 242(Maid for You)= 2,637。對。
- 補查「低」:5,000 + 250 + 145 + 242 = 5,637。對。若 5,000 已含鎖:5,637 − 145 = 5,492。對。
- 原「中」:5,358 + 295 + 242 = 5,895。對。補查上緣:6,000(5,000 與 7,000 的算術中點)+ 295 + 242 = 6,537。對。差 6,537 − 5,895 = 642(筆記寫約 640,對)。5,358 落在 5,000–7,000 內,對。
- 原「高」:5,358 + 500 + 410 + 17,250 + 16,100 = 5,358 + 500 = 5,858;+ 410 = 6,268;+ 17,250 = 23,518;+ 16,100 = 39,618。對(與筆記括號內「只翻浴室約 23,518」也吻合)。
- 高 + 油漆低 + 地板低:39,618 + 1,850 + 2,520 = 43,988。其中地板低 63 × 40 = 2,520。對。
- 高 + 油漆高 + 地板高:39,618 + 3,600 + 5,600 = 48,818。其中地板高 140 × 40 = 5,600。對。
- 地板典型 92 × 40 = 3,680,與頁面例子相同。對。
- 1 房各區油漆:低 450 + 700 + 400 + 300 = 1,850;高 750 + 1,400 + 800 + 650 = 3,600。算式對。

口徑提醒(不是算錯):
1. 同一頁「At a Glance」表給 Sydney 臥室整間 $500–$900,筆記用的 450–750 是正文另一句;若改用 500–900,加總會變 1,900–3,750。差距不大,但簡報上請寫「約 1,850–3,600」並標「來源頁內有 500–900 的另一組臥室價」。
2. 「客餐廳合併 700–1,400」與「廚房牆 400–800」若屋型是開放式客餐廚,應改用「開放式 1,500–2,500」,兩者不能同時加,否則重複計算。
3. 地板含 GST(頁面明寫),油漆頁沒寫 GST;43,988–48,818 把兩者相加,GST 口徑不一致。
4. 地板 40 m² 是該頁的範例面積,不是我們 1 房的實際坪數;1 房實際面積不同,數字要等比例調整。
5. 頁面的 3.4%(地板)、ABS 的年增數字見表 3,簡報若要放「成本近一年漲多少」要用表 3 的修正版。

## 簡報上要加註或不要用的數字

- 不要用:「住宅營造對最終需求指數的貢獻 +1.1%」這個說法。頁面只說住宅營造是最終需求季增的主要貢獻項之一,+1.1% 較可能是該類價格自己的季增(頁面沒明說),且與最終需求整體季增 1.1% 同數字,容易被誤讀。要用就寫「住宅營造價格季增約 1.1%(ABS 2026 Q3,全澳)」並先人工看一次原頁。
- 不要用:「建築營造季增 1.3% 主因非住宅營造」。改寫為「建築營造價格季增 1.3%;ABS 歸因於中東衝突推高燃料與運費,以及技術工短缺」。
- 不要用:筆記的結論「近一年成本只能引最終需求年增 3.6%」。ABS 同頁有營造專屬年增(營造 4.9%、房屋營造 5.7%,全澳),比 3.6% 高;若放一句話,用營造 4.9%,並註明是全澳不是雪梨。
- 要加註:Hometime 5,000–7,000 寫「適中(modest)的 1 房」,不要寫「寬裕」;頁面沒列細項,不能與 Airbtics 5,358 逐項相比。
- 要加註:油漆價格頁面沒標 GST,地板價格含 GST;兩者相加要註明。
- 要加註:1 房各區油漆加總 1,850–3,600 是筆記作者自己加的,不是來源直接給的數字;不含門、踢腳板。
- 未查,不要放進簡報:Airbtics 7,539(2 房)、What's The Damage 鎖匠頁 17–57,以及上一份檔裡本次沒重開的列。
