## 三種新房東各自的每月固定成本清單(只做加總,不做收益預測)

共通:每月固定成本(要算的列)與「跟營收/訂單連動」的變動成本分開看。以下的「低/中/高」是我從上面表格挑出來的,挑法在括號寫明;沒查到的列,試算工具請預設為空白或讓使用者自填。

### 共通變動項目(三種人都有,不是固定月成本)
- 平台抽成 F1:15.5% 的訂房小計。
- 清潔 C1:每次退房 50 / 65 / 105 AUD(低/中/高,為向房客收的費行情)× 每月退房次數(使用者自填)。
- 代管/共同房東抽成(若有):15% / 20% / 25% 的收入(M1;M3 溝通型 10–15%)。
- 床單洗滌 C2:查不到,自填。

### 甲、已有房(自有房,貸款或已還清)
要算的列:電費、水費(查不到)、瓦斯(查不到)、網路(查不到)、管理費(公寓才有)、市政費(查不到)、保險(查不到)。
- 電費 E1–E4(自己換算 ÷12):低 約 156 / 中 約 164 / 高 約 201 AUD/月。取法:低 = E2 Ausgrid 2026-27 草案 1,875;中 = E1 Ausgrid 2025-26 1,965;高 = E3 Endeavour 2025-26 2,411。三個數字不同年度或供電區,只是粗略帶狀,不是同一口徑。
- 管理費 S3/S1(÷3):低 200 / 中 約 285 / 高 500 AUD/月。取法:低 = S3 下限 600/季;中 = S1 854/季;高 = S5 下限 1,500/季(大樓或設施多)。若是獨棟屋,此列為 0。
