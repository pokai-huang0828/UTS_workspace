---- ITEM 3 [Page] 2.1 描述性分析与预测性分析
> ref: 2-dot-1-miao-shu-xing-fen-xi-yu-yu-ce-xing-fen-xi | updated 2026-10-19T05:04:28Z

单元二｜数据分析与机器学习技术概述

[圖:]

数据分析能够帮助企业探索和研究其数据，从中提取有价值的知识。所发现的见解最终可以支持企业作出更明智的决策。分析主要分为两种类型，即描述性分析和预测性分析。它们分别回答不同的问题。

描述性分析回答的问题是：

“ 过去发生了什么？”

预测性分析回答的问题是：

“未来可能会发生什么？”

### 描述性分析

描述性分析回答“过去发生了什么”这一问题。它利用已经收集并存储的历史数据进行分析。描述性分析的主要目标是说明已经发生的事情，从而找出过去成功或失败背后的原因。描述性分析通过简单的数学和统计方法（例如算术运算）对现有数据进行汇总，然后利用折线图、饼图等可视化工具展示分析结果，使广大业务受众能够轻松理解这些发现。

数据聚合（Data Aggregation）和数据挖掘（Data Mining）是描述性分析的两项关键技术。数据聚合是收集原始数据并以汇总形式表达数据的过程。在完成数据聚合这一阶段后，接下来进行数据挖掘，以识别模式和趋势，并以易于理解的方式呈现相关洞见。

描述性分析通常应用于日常业务活动中，以获取有助于决策的洞见，因为它易于应用，并且不一定需要深入的分析知识。另一方面，描述性分析的局限性在于，它只能解释历史数据，而不能进行推断或预测。例如，一份基于描述性分析的销售报告可以提供过去按月或按年的销售趋势，但无法预测下个月或下一年的销售情况。

### 预测性分析

预测性分析回答“未来可能会发生什么”这一问题。它侧重于根据当前可获得的数据预测未来可能出现的结果。预测性分析能够帮助企业设定切实可行的目标、制定有效计划、合理管理预期以及控制风险。

预测性分析建立在概率的基础之上。它利用统计建模、数据挖掘和机器学习等多种技术，预测未来结果发生的可能性。为了预测未来，算法会通过研究模式并识别现有数据集中各变量之间的关系，从而作出尽可能准确的推测。预测性分析所需的计算通常比描述性分析更加复杂。

请注意，预测性分析永远不可能做到完全准确，因为它基于概率进行预测。大量历史数据以及合适算法的选择，都有助于提高预测的准确性。

单元二｜分析与机器学习技术概述

[圖:]

人工智能是指让计算机表现出与人类所展示的智能行为相似的能力。人工智能这一术语是在 1956 年达特茅斯会议（Dartmouth Conference）上提出的。智能代理（Intelligent Agents）是能够感知其环境并采取行动，以最大化实现某一目标成功概率的设备。

机器学习可以被定义为人工智能的一部分，也可以被视为人工智能的一种应用实例。在机器学习中，计算机能够在无需明确编程的情况下自主学习。它允许系统基于实时场景中的数据进行自主调整和改进。

机器学习主要分为两大类技术，即 监督学习（Supervised Learning） 和 无监督学习（Unsupervised Learning）

### 监督学习

顾名思义，监督学习存在一个“监督者”，利用经过良好“标注”的训练数据来教导或训练机器。所谓标注数据，是指部分输入数据已经标记了正确的输出结果。在监督学习中，提供给机器的训练数据就像监督者一样，指导机器正确预测输出结果。其理念与学生在教师指导下学习的过程相同。监督学习方法通过训练数据中的输入与输出样本对学习两者之间的关系，然后利用所学关系对新的“输入”数据进行预测。

监督学习技术可进一步分为两大类：回归（Regression）和分类（Classification）。

回归

是预测连续数值的过程，例如 “天气温度” 和 “年度收入”。

分类

是预测类别型输出的过程，例如“是（Yes）”或“否（No）”，以及“红色（Red）”“蓝色（Blue）”或“绿色（Green）”。

监督学习技术的示例包括：

- 线性回归 Linear regression
- 逻辑回归 Logistic regression
- 决策树 Decision tree
- 随机森林 Random forest
- 支持向量机 Support vector machines
- 神经网络 Neural networks

监督学习可应用于风险评估、图像分类、欺诈检测、垃圾邮件过滤等领域。

### 无监督学习

另一方面，无监督学习试图从未标记数据中学习隐藏的模式。由于在先前训练阶段没有提供带标签的数据，因此无监督学习能够自行发现数据集的底层结构，并根据相似性、模式和差异对数据进行分组。无监督学习可以类比为人类大脑在学习新事物时所经历的学习过程。通常，无监督学习能够识别数据中的聚类、群组以及频繁出现的模式。

无监督学习技术的示例包括：

- K均值聚类
- 层次聚类
- K最近邻算法
- Apriori 算法
- 主成分分析

无监督学习可用于购物篮分析、客户细分、异常检测、推荐系统等。

### 监督学习与无监督学习

| | 监督学习 | 无监督学习 |
| 训练数据 | 训练需要带标签的数据 | 不需要带标签的训练数据 |
| 计算复杂度 | 较简单 | 计算复杂度较高 |
| 准确性 | 准确率较高 | 准确率较低 |

### 什么是数据预处理

期望获得完全完美的数据是不现实的。数据收集过程中存在的缺陷、测量设备的局限性或人为错误都可能导致一些问题。为了解决这些问题，数据预处理是一种经过验证的有效技术。良好的数据准备工作能够提高后续分析的效率，减少错误，并确保所有必需的数据可供所有用户访问。

数据预处理是数据分析过程中的一个基础步骤，它将原始数据转换为可理解的格式。数据通常来自多个来源，而这些来源往往并不十分可靠，并且数据格式各不相同。在这种情况下，在处理数据分析问题时，往往有超过一半的时间被用于处理与数据质量相关的问题。

原始数据通常可能存在缺失值或不一致值，同时还包含大量冗余信息。原始数据最常见的问题可以分为以下三类：缺失数据、噪声数据和不一致数据。点击每张卡片了解更多内容。

缺失数据 Missing Data

缺失数据通常出现在数据收集阶段出现问题时，例如系统停机、数据录入错误或隐私相关问题。

噪声数据 Noisy Data

这一类别包括错误数据和离群值，这些都属于无意义的信息。噪声可能由人为错误、罕见异常情况、错误标注以及数据收集过程中出现的其他问题所导致。

不一致数据 Inconsistent Data

当数据以不同格式存储在多个文件中时，就会出现数据不一致的问题。不同格式的重复数据、名称编码中的错误，或者缺乏数据约束，往往会导致数据不一致。

如果不处理上述问题，最终结果可能是不恰当且不准确的。当在数据挖掘之前应用数据预处理技术时，它们能够显著提高所挖掘模式的整体质量或缩短实际数据挖掘过程所需的时间。

数据处理技术包括：

- 数据清洗 Data cleaning
- 数据集成 Data integration
- 数据转换 Data transformation
- 数据缩减 Data reduction

点击各个标签，了解更多关于这些技术的信息。

数据清洗

数据中可能存在许多缺失或无关的元素。数据清洗技术旨在填充缺失值、平滑噪声数据、剔除无关数据或解决数据中的不一致问题。

为了处理缺失数据，通常采用以下两种方法。

- 忽略包含缺失值的记录。当同一记录中存在多个缺失值时，该方法适用于大型数据集。
- 手动填充缺失值。缺失值是手动填充的，通常使用最可能的值或属性均值。这种方法不适用于大型数据集，且过程耗时。

平滑噪声数据主要有以下三种方法：

- 分箱 Binning: 该方法基于邻近值对存储的数据进行平滑处理。排序后的数值被划分为若干个“桶”（或称“箱”）。由于分箱法利用了邻近数据，因此也被称为局部平滑。可以将某个区间内的所有数据替换为该区间的平均值或边界值。
- 回归 Regression: 数据平滑也可以通过回归来实现，这是一种将数据值映射到函数的技术。线性回归旨在寻找一条“最佳”拟合直线来描述两个变量（或属性）之间的关系，从而利用其中一个变量来预测另一个变量。
- 聚类 Clustering: 针对一组数据点，该方法利用聚类算法将每个数据点分配到特定的组中。每个聚类包含一组彼此距离较近、但与其他聚类距离较远的数据点。位于聚类之外的数据点（即所谓的离群点）会被剔除。

数据集成

数据集成是另一种数据预处理技术，如下图所示，它通过将来自各种异构数据源的数据合并到一个统一的数据存储中，从而提供数据的统一视图。这些数据源可以包括平面文件、数据库或多个数据立方体。

谨慎的集成有助于避免并减少最终数据集中的不一致性和冗余，从而提高后续挖掘过程的速度与准确性。构建企业数据仓库被视为最常见的数据集成应用之一。

在实际操作中，数据集成面临着诸多挑战。

- 模式集成 Schema of integration: 将拟议或现有的数据库模式集成到一个统一的全局模式中。元数据也可以从各种来源进行集成。例如，两个模式中名为“设备（Equipment）”的属性可能指代不同的事物：第一个“设备”可能指计算机、复印机等，而第二个“设备”则指空调、家具等。
- 语义异构性 Semantic heterogeneity: 当独立方针对同一领域或数据库模式开发数据集时，不同来源中的相似值可能具有不同的含义。例如，某个数据库中的“Title”字段可能代表“Person Title”（个人头衔/称谓），而在另一个数据库中则代表“Job Title”（职位名称）。
- 记录重复 Record duplication: 这是数据冗余的另一种形式，即针对同一个特定的数据实体，存在两条或多条相同的记录。重复记录之间往往会出现不一致的情况，这通常是由于数据录入错误或仅更新了部分数据副本造成的。例如，一个采购订单数据库包含购买者的姓名和地址属性；如果缺乏与购买者数据库中相关信息的关联键（key），就可能出现数据不一致，比如同一购买者的姓名对应了不同的地址。
- 数据值冲突 Data value conflicts: 对于同一个现实世界实体，来自不同来源的属性值可能各不相同。这可能是由编码、量纲（尺度）或表示方式的差异引起的。例如，某个系统中以英制单位存储的重量属性，在另一个系统中可能以公制单位存储。为了实现成功的数据集成（参见数据审计），元数据通常是必不可少的。

数据转换

在数据转换过程中，数据被整合或转换为适合分析的格式，从而提高后续挖掘过程的效率，并使发现的模式更易于理解。

数据转换可以采用多种策略，包括：

- 平滑（Smoothing）：平滑是指去除数据中的噪声。平滑技术包括数据清洗中提到的分箱（binning）、回归和聚类。
- 聚合 （Aggregation）: 聚合是指应用统计指标（如均值、中位数和方差）来汇总数据的过程。生成的聚合数据将用于数据挖掘算法中。为了在多个粒度上分析数据，聚合通常用于构建数据立方体。
- 概括 （Generalisation）: 这包括利用概念层次结构，将低层级数据（原始数据）替换为高层级概念。
- 归一化 （Normalisation）: 归一化旨在确保每个样本的值具有同等权重，并能被统一理解。归一化在神经网络等分类算法，或最近邻分类和聚类等涉及距离度量的算法中非常有用。典型的归一化技术包括最小-最大归一化（min-max）、Z-score 标准化和十进制标度法（Decimal scaling）。

数据缩减

对海量数据进行复杂的数据分析和挖掘是一个耗时的过程，往往导致分析变得不切实际或不可行。可以采用数据缩减的方法来获取一个规模更小、但数据质量与原始数据相当的归约数据集。其目标是在降低数据存储和分析成本的同时，提高存储效率。.

数据缩减的策略包括：

- 数据聚合 Data aggregation: 常用于构建数据立方体，以便在多个抽象层级上进行数据分析。多维聚合信息存储在数据立方体中。
- 降维 Dimensionality reduction:也称为特征选择或属性子集选择。该方法通过检测并剔除弱相关、冗余或不相关的维度（或属性）来实现。降维的目标是确定一个最小属性集，使得由此产生的数据类概率分布尽可能接近使用所有属性时得到的原始分布。
- 数量归约 Numerosity reduction: 通过采用非参数模型（如数据聚合、抽样、聚类或直方图）或参数模型（如对数线性模型或回归模型），用更小的数据表示形式来替代原始数据。这使得存储数据模型（例如回归模型）成为可能，而无需存储全部数据。
- 抽样 Sampling: 这是数据选择的主要方法，它允许用较小的随机子集（或样本）来代表大型数据集。它常用于数据的初步探索以及最终分析。在数据分析中，由于处理整个数据集往往耗时或成本高昂，因此经常使用抽样。如果样本具有与原始数据集大致相同的（关注的）特性，则称该样本具有代表性。用于数据缩减的常见抽样方法包括简单随机抽样、不放回抽样、有放回抽样、聚类抽样和分层抽样。
- 离散化与概念层次生成 Discretisation and concept hierarchy generation: 数据离散化是一种数量归约形式，它将连续属性转换为分类属性。通过使用更高层的概念标签或较少数量的区间（即分箱/binning）来替代原始数据，从而简化数据并提高挖掘效率。离散化对于自动生成概念层次结构非常有益。在数据挖掘中，概念层次生成和离散化是强有力的工具，能够支持在多个数据抽象层面上进行数据挖掘。

单元二 | 分析与机器学习技术概述

聚类是将数据点划分为若干组的过程，使得同一组中的数据点彼此之间的相似度高于与其他组中数据点的相似度。简单来说，其目标是将相似的对象归为一组。

### 硬聚类与软聚类

聚类可以分为两大类：软聚类（Soft Clustering）和硬聚类（Hard Clustering）。

- 在硬聚类中，一个对象只能属于一个聚类，并且对象之间能够较容易地被划分到不同聚类中。
- 在软聚类中，由于各聚类之间不存在明确的界限，一个对象可能同时属于一个或多个聚类。

### 相似性与距离

相似性（similarity）与距离（distance）的概念彼此相反。两个数据点之间的距离非常短时，其相似性就非常高；反之亦然。

为了衡量项目之间的相似性，需要有一种方法来度量这些项目之间的距离。距离度量方法的选择非常重要，因为它会对聚类结果产生显著影响。常见的距离度量包括曼哈顿距离（Manhattan distance）、欧几里得距离（Euclidean distance）和余弦相似度（Cosine similarity）。根据数据类型和研究问题的不同，也可能更适合采用其他不相似性度量。例如，基于相关性的距离（correlation-based distance）常用于基因表达数据分析。

### 什么是好的聚类?

一种好的聚类方法能够生成高质量的聚类结果，即具有较高的类内相似性（intra-class similarity）和较低的类间相似性（inter-class similarity）。

聚类结果的质量既取决于该方法所使用的相似性度量，也取决于其具体实现方式。这两个方面将在本单元后续内容中进行讨论。聚类方法的质量还可以通过其发现部分或全部隐藏模式的能力来衡量。

### 选择标准

在选择聚类算法时，可以采用以下标准：

- 可扩展性

- 发现任意形状聚类的能力

数据可视化是通过图表、图形或地图等形式，向观看者传达数据之间关系的过程。与直接查看原始数据点相比，当人们看到图表或图像时，更容易从数据中获得洞察，例如识别相关性和异常值。

我们希望对数据进行可视化，因为数据本身只是对某些现象或事件的抽象表达，而这些现象或事件正是我们希望理解的对象。单纯的数字无法帮助我们理解情境并回答问题，因此将数据转换为可视化形式至关重要。人类是视觉导向的生物，擅长处理视觉信息；我们大脑中约有30% 的大脑皮层 (https://www.discovermagazine.com/mind/the-vision-thing-mainly-in-the-brain)专门负责视觉处理。

### 数据可视化过程

数据可视化过程包含若干要素，如下图所示。首先是数据；如果没有数据，就无法呈现任何信息。当数据被收集后，它会被转换或编码为图表或图形。随后，由人类观察这些可视化内容并感知其中的信息。在完成感知后，人类应能够通过查看可视化内容来回答某些问题。

何时

在整个项目过程中，持续展示数据是一种常见做法。你可能会为自己的实验快速创建数据可视化，以帮助解释和理解结果。可视化内容和分析结果可能会在团队会议中与团队成员分享，或在与利益相关者沟通时进行展示。项目报告中的一个重要组成部分也是数据展示。

建议你养成保存数据展示内容和数据可视化成果的习惯。特别是，要有条理地进行整理，并清晰记录数据来源（provenance）以及实验过程。这些资料将有助于你在项目期间重新利用所积累的相关成果和材料。

为什么

我们呈现数据，是为了让数据讲述一个故事。当然，每个数据故事都是独特的。然而，关于为什么要呈现数据，通常存在一些共通的主题。这些包括：

- 展示趋势
- 进行比较
- 识别异常值
- 展示关系
- 表明绩效水平（评估结果）
- 展示运作过程（图示）

当你准备向他人呈现数据时，请问自己：“我希望这些数据讲述什么故事？”也就是说，需要传达的核心信息是什么？它是否符合上述已知主题中的某一种？

如何

一般来说，呈现数据有三种方式：

1. 图表（plots/charts）
2. 表格（tables）
3. 图示（diagrams）

选择有效的数据呈现方式，将取决于你希望数据讲述的故事，以及受众的背景情况。接下来的章节将更详细地探讨各种可选方案。

### 表格的价值

是否使用表格不应是随意决定的。只有当表格能够满足沟通需求时，我们才选择用表格来呈现数据。当我们以表格形式向他人展示原始数据时，也是在表明我们对自己的分析结果或结论充满信心。读者可以利用表格自行得出结论，而这些结论往往会进一步证明我们的分析是正确的。

在以下情况下，表格可能比图表更适合：

- 人们需要查阅个别数据值。
- 需要比较成对的数据值，而不是比较整个数据集。
- 需要精确的数据值，并且可能需要同时提供汇总统计信息。
- 数据涉及不同的计量单位，而这些单位不适合放在同一图表中展示。
- 数据值之间差异过大，以至于无法使用统一的刻度进行绘图。
- 仅需展示少量数值（例如不超过 20 个数值）。

在使用表格呈现数据时，通常会对特殊数值进行突出显示（例如加粗处理），如异常值或获胜者。下面的示例展示了一种较为极端的方法，即将图形化表示叠加到表格中，从而提升表格的实用性。

### 优秀图示的提示

以下是一些创建有效图示的提示。你的图示应当……

易于理解

- 在图示符号的使用上保持一致。对于同一种概念，使用相同类型的形状；对于同一种关系，使用相同类型的线条。仅在需要表示方向性时使用箭头。
- 应将图示元素的使用视为一种表达含义的语言。
- 图表应尽量利用易于识别和理解的隐喻，例如填满水桶、建造房屋、液体流动、绘制旅程路线等。
- 优先使用传统且广为接受的图标形式，而不是自行创造新的图标（如垃圾桶、磁盘驱动器、云朵、表情符号等）
- 在使用正式图表时，应遵循所选正式图表方法论的规范。

易于阅读

- 应清楚区分哪些内容属于图表的一部分，哪些不属于。请在图表周围留出足够的留白，或使用边框线，或采用背景阴影，以明确界定图表的边界。
- 字体大小应足够清晰易读。通常情况下，图表中所使用的字体可以比报告正文中的字体略小，但不应小太多。
- 文字不应穿过线条，也不应被遮挡。
- 文字应尽量保持一致的阅读方向，并且无需旋转页面即可阅读。
- 尽量采用不依赖颜色或细微变化来表达含义的图表样式。应考虑图表在复印后的呈现效果。一般而言，图表并不适合展示细微差别，这类内容更适合通过文字说明来表达。
- 在使用阴影或颜色时，应确保具有足够的对比度。

一致性

- 尽量在所有图表中使用相同的字体、线条样式和配色方案。所使用的字体不必与报告正文的字体相同。
- 尽量保持对象大小的一致性。只有在需要强调某个重点时，才应改变对象的大小。

美观

- 图表应具有一定的对称性或平衡感。
- 确保所有对象都经过适当的对齐和均匀分布。
- 选择与内容的专业性和整体风格相协调的样式及配色方案。对于技术报告，应采用传统、稳重的视觉风格，避免使用柔和的粉彩色和过于突兀的颜色。

### ACCENT 原则

图表的本质在于清晰地传达定量信息。ACCENT 原则强调了决定数据可视化展示效果的六个方面。这些原则摘自 D. A. Burn 的《有效图形展示原则》（Principles for Effective Graphical Display）。

- Apprehension 理解性: 正确感知变量之间关系的能力。
图表是否最大程度地帮助读者理解变量之间的关系?
- Clarity 清晰性: 在视觉上区分图表所有元素的能力。 (最重要的元素或关系是否在视觉上最为突出？)
- Consistency 一致性: 基于与先前图表相似性来解释图表的能力。(图表中的元素、符号形状和颜色是否与之前图表中的用法保持一致？)
- Efficiency 效率性: 以尽可能简单的方式呈现可能较为复杂关系的能力。(图表元素是否得到经济且有效的使用？图表是否易于理解？)
- Necessity 必要性: 图表及其图形元素存在的必要性。(与其他表示方式相比，图表是否是展示数据的更有效方法？图表中的所有元素是否都有助于传达相关关系)
- Truthfulness 真实性: 图形元素的大小、位置和比例是否能准确反映其所代表的真实数值。 (图表元素的位置和比例是否准确？)

### 数据

与出租车公司协商后，项目确定使用三个数据集，分别是：出租车行程数据、出租车区域数据和天气数据。

出租车行程数据集包含出租车历史行程记录，具有以下字段：

- 上车日期
- 上车时间
- 下车日期
- 下车时间
- 上车地点（纬度和经度）
- 下车地点（纬度和经度）

- 行程距离
- 分项车费
- 费率类型
- 支付方式
- 司机报告的乘客数量

出租车区域（Taxi Zone）数据集是用于汇总乘客需求的社区区域数据。该数据采用shapefile格式存储，shapefile (https://doc.esri.com/zh-cn/arcgis-pro/latest/tool-reference/appendices/geoprocessing-considerations-for-shapefile-output.html) 是一种用于存储地理位置及其相关属性信息的数字矢量数据格式。

天气数据集（Weather dataset）包含历史天气记录，包括气温、降水和降雪信息。之所以使用该数据集，是因为天气是影响人们规划旅行的重要因素。天气数据集包含以下字段：

- 最低气温
- 最高气温
- 平均气温

- 降水量
- 降雪量
- 积雪深度

出租车行程数据集和出租车区域（Taxi zone）数据集将由出租车公司提供，而天气数据集需要从在线开放数据门户收集。在数据收集任务中，将开发一个计算机程序，通过数据 API（Application Programming Interface，应用程序编程接口）收集天气数据。

#### 将上车地点聚合到区域中

机器学习算法经常被用于在数据分析项目中构建预测模型，尤其是在涉及预测分析的项目中。在本周的学习过程中，我们将介绍四大类机器学习算法，包括线性模型、决策树、集成方法和神经网络。在深入学习这些技术细节之前，让我们先对它们形成一些基本认识。

线性模型

线性模型用于通过自变量（x）的线性组合来描述因变量（y）。构建线性模型的目标是建立一个数学公式，将 y 定义为 x 变量的函数，也就是说，通常表示为各个 x 值加权求和的结果。一旦确定了这个函数，我们便可以利用它根据新的 x 值预测未来的 y 值。在实践中，线性模型通常是进行建模时的首选尝试方法，因为它们相对简单。我们将在 2.11 线性模型族（Linear family） 页面学习线性模型的相关内容。

决策树

决策树是一种树状结构图，用于描述一系列相关决策可能产生的结果。它通常从一个称为“根节点（root node）”的单一节点开始。根节点分支出各种可能结果，而这些结果又会延伸出更多节点，并进一步分支出其他可能性，直至到达称为“叶节点（leaf nodes）”的终端节点。叶节点表示从根节点沿着某一决策路径到达的最终结果。构建决策树的关键在于找到最适合作为节点来对数据进行分支划分的变量。决策树具有非常强的可解释性，容易理解，但也容易出现过拟合问题。我们将在 2.12 决策树（Decision trees） 页面学习如何识别用于“分裂（splitting）”的节点。

集成方法

集成方法是一类通过构建多个模型并将其组合起来，从而生成改进模型的技术。与单一模型相比，改进后的模型通常具有更好的性能。集成方法背后的核心思想是“组合”。我们将在 2.13 集成方法页面向你介绍多种组合多个模型的方法。

神经网络

神经网络，也称为人工神经网络（Artificial Neural Networks），其设计灵感来源于生物神经系统处理数据的方式。神经网络是深度学习（Deep Learning）的核心组成部分，而深度学习已经在许多现实世界应用中取得了巨大成功。神经网络由多个节点层（node layers）组成，包括一个输入层（input layer）、一个或多个隐藏层（hidden layers），以及一个输出层（output layer）。节点（node），也称为人工神经元（artificial neuron），是神经网络中的基本单元。每个节点都与其他节点相连接，并且具有相应的权重（weight）。2.14 神经网络（Neural Networks） 页面将在第 2.2.2 节介绍的感知机模型（Perceptron Model）基础上，进一步介绍人工神经元的概念。神经网络通常能够实现非常高的预测准确率，但需要大量数据来训练模型。

单元二｜分析与机器学习技术概述

本页将介绍“线性（Linear）”模型族。这类模型广泛应用于数据分析项目中，既可用于回归问题，也可用于分类问题。

### 线性模型 Linear model

“线性模型”是一个统称，用来描述这样一种简单而直接的思想：目标变量与所有数据属性加权求和后的结果相关联。当满足适用条件时，即：当所有属性都是数值型数据，或者已经被转换为数值形式时，这一模型族通常能够提供有助于表示属性与目标变量之间关系的假设。

从 [圖:LaTeX: X_1, \dots, X_k] 形式上来看，给定各项属性，线性模型假设用于重现目标变量 Y 所需的全部信息都可以概括为一个单一数值，而这个数值[圖:LaTeX: a = x_1\cdot w_1 + x_2 \cdot w_2 + \dots + x_k \cdot w_k] 就是各数据属性加权求和后的结果。

感知机（Perceptron）模型族被视为线性模型的一个典型例子。感知机的设计灵感来源于生物神经系统：神经元通过与其他神经元的突触连接接收刺激信号，并据此决定自身状态。当累积的刺激超过某个阈值时，神经元被激活，并发出输出信号。

感知机模型族将线性模型的思想应用于二元分类问题，其过程如下：首先计算数据属性的加权和 a。然后将 a 与某个阈值进行比较，并根据比较结果预测目标变量。如果 a 超过该阈值，则样本被分类为某一类别，例如正类（positive class）；否则，被分类为另一类别，即负类（negative class）。

由于判断条件 a > b 等价于 a - b > 0，因此感知机分类器对数据样本的处理可通过以下比较方式进行。

[圖:LaTeX: x_1\cdot w_1 + x_2 \cdot w_2 + \dots + x_k \cdot w_k + w_0 > 0]

其中，该项 [圖:LaTeX: w_0] 同时容纳了在计算加权和 a 时的可选偏移常数（offset constant）以及前文提到的阈值（threshold）。在公式右侧，比较对象始终为 0，这也是两类分类结果命名的由来。 出于后续内容中将会说明的原因，习惯上将其中一类记为 +1，另一类记为 −1。也就是说，我们现在使用数字作为类别标签（class labels）。 感知机 𝑓 对某个数据样本 [圖:LaTeX: x_i] 进行预测并获得预测结果 [圖:LaTeX: y_i] 这一事实，可表示为：[圖:LaTeX: f(x_i) \mapsto \tilde {y}_i] ， 由于预测类别和真实类别（ground truth class）都属于{±1}，因此当且仅当（if and only if）满足相应条件 [圖:LaTeX: \tilde {y}_i \cdot y_i = +1] 时，预测才是“正确的”；若结果为 −1，则表示预测“错误”。 请注意，下标 𝒊 表示数据集中某个样本的索引（index），而不是某个数据属性（attribute）的索引，不应将两者混淆。

#### 动机

线性模型的动机是十分自然的。这类模型之所以受到广泛应用，是因为它们在两个方面都较为简单：一方面，它们能够表达的关系形式相对简单；另一方面，在给定数据的情况下，寻找线性模型中最优权重解的计算成本也相对较低。

在实际应用中，当数据属性为数值型，或者能够方便地转换为数值型时，线性模型族通常是经验法则下的首选尝试方法。

[圖:]

即将介绍的第二类机器学习技术是决策树（Decision Trees）。我们将探讨决策树如何根据属性（attributes）生成目标值（target value）

### 决策树模型

决策树模型体现了这样一种思想：通过逐一检验数据属性来消除目标变量的不确定性。直观地说，这一过程就是针对某个数据样本回答一系列问题，而每个问题都与某一项属性有关。根据这些问题的答案，我们对目标变量的猜测会逐渐缩小范围并变得更加准确。这个过程会持续进行，直到我们对目标变量达到足够满意的置信程度为止。

对于给定的数据样本，这一过程类似于沿着一棵树进行遍历：

- 从树的根节点（root）开始（当前节点 ← 根节点）。此时，除了知道目标值遵循总体数据分布之外，我们对目标值没有任何特定信息，因此不确定性最大。
- 在当前节点上进行处理。

- 叶节点终止(Leaf-node termination) 如果当前节点已经给出了目标值的预测结果，则终止流程并返回预测值；否则，
- 当前节点会指定一个数据属性。我们检查数据样本中对应的属性值。根据检查结果，当前节点会指定应当进入的子节点。随后将该子节点设为当前节点，并递归地继续这一过程。

在统计学习（Statistical Learning）的框架下，决策树这种以查询为导向的目标推测过程，可以理解为不断缩小数据空间中与目标概念对应的子集范围。决策树的假设（hypotheses）是能够表示为这些子集并集（union）的概念。例如，在二维（2D）数据空间中，某些区域可能属于正类（positive class）。

> ref: 2-dot-13-ji-cheng | updated 2026-10-15T23:16:04Z

单元二｜分析与机器学习技术概述

当处理复杂且困难的任务时，“分而治之”（divide-and-conquer）是一种自然而然的思路。对于机器学习问题而言，这意味着将多个经过学习得到的数据模型组合在一起，从而形成一个更复杂、更强大的模型。在本节中，我们介绍集成（ensemble）：集成是由多个预测器（predictors）组成的集合。我们可以将集成理解为一个负责执行预测任务的委员会。如果能够证明该委员会比其单个成员能够做出更可靠的预测，那么就有可能利用较弱的预测器构建出可靠且准确的预测模型。

对于集成中所使用的成员预测器类型并没有限制。这些成员预测器通常被称为“基预测器（base predictors）”、“弱预测器（weak predictors）”，或者根据具体任务被称为“基分类器／弱分类器”以及“基回归器／弱回归器”。出于实践上的便利，人们通常使用简单的决策树来构建集成模型，例如“决策树桩（decision stump）”，即仅在根节点（也是唯一节点）进行一次决策的决策树。

最直接的集成方法是对多个预测器的结果取平均值。请回顾，预测器是基于随机观测到的数据学习得到的。这样的随机过程不可避免地会给学习系统引入方差。对多个预测器实例的结果取平均值，有助于降低这种方差。

对于实际问题，人们从哪里获得构建集成所需的多个预测器呢？

一种实用的方法是重采样（resampling）技巧。我们从原始训练样本中随机重新抽取伪训练集（pseudo training sets），并在这些重采样得到的数据上训练预测器。这些训练集副本彼此并非独立。然而，我们仍然可以利用这些重采样的数据来训练弱预测器（weak predictors），并将这些训练得到的预测器组合起来，构成有效的集成预测器。此外，重采样还有助于衡量预测结果的方差（variance）。这种技术被称为自助抽样法（bootstrapping）。

已提出各种不同的集成方法，其区别主要在于：

- 如何对数据进行重采样;
- 如何利用重采样得到的数据副本来构建基预测器；以及
- 如何利用各个预测器组成委员会，从而形成集成模型

[圖:Bagging and boosting: explaining below.]改编自: Bagging and Boosting | Medium (https://medium.com/@saitejaposam9/bagging-and-boosting-2b6cd4a6bda1)

*parallel: 平行的；sequential：连续的

### Bagging（装袋法）

Bagging 是一种直接且简单的集成方法。给定一个训练数据集，通过有放回抽样（sampling with replacement）随机抽取数据样本，生成与原数据集大小相同的数据集副本。随后，在这些重采样（resampled）数据集上分别训练各个预测器。最终的集成模型包含所有单独训练的预测器，并通过投票的方式进行决策。

不仅可以对数据实例进行重采样，还可以随机选择属性，从而形成随机重采样的数据副本。利用不同的重采样策略，可以构建各种不同的决策树。随机森林就是一种集成模型，它由在随机数据实例和随机属性集合上训练得到的多个决策树组成。

### Boosting methods（提升法）

Boosting 方法是一类利用重采样训练样本构建集成模型的序列式迭代策略（sequential iterative strategies）。在每一次迭代中，都会从数据集中抽取一个带权重的随机样本。样本权重会根据当前模型对各个样本进行预测的难易程度动态计算（初始步骤中所有样本权重相同）。同时，基预测器也会根据其预测准确率被赋予不同的权重。

单元二｜分析与机器学习技术概述

神经网络（Neural Networks）是最成功的模型家族之一。神经网络最基本的实现形式也称为多层感知机（Multi-layer Perceptrons，MLP）。从这个名称不难看出，神经网络模型家族与某一种线性模型（linear model）有着密切联系。回顾一下，线性感知机模型（linear perceptron model）是对数据属性与预测目标之间关系的一种直接表达方式。

线性模型通过计算数据属性的加权和（weighted sum），再通过简单的阈值判断（thresholding，即与 0 进行比较）[圖:LaTeX: a=w_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + \dots] 将计算结果与预测结果联系起来：随后根据是否满足[圖:LaTeX: a > 0]进行预测。针对这种简单的方案，可以有多种扩展方式，从而使数据模型能够对具有更加复杂关系的数据[圖:LaTeX: (\mathcal X,\mathcal Y)]进行分类。

### 扩展类型 A

模型输出与数值 [圖:LaTeX: a] 的关联方式可以不同于二元阈值判断。例如，一个“软决策”可以是 [圖:LaTeX: \frac{1}{1 + e^{-a}}] 建议你绘制该函数在一系列输入值 [圖:LaTeX: a] 下的响应曲线，以便理解为什么它被称为“软决策”。

### 扩展类型 B

单元二｜分析与机器学习技术概述

深度学习是机器学习的一个分支。深度学习利用神经网络（其设计灵感来源于人脑的结构和功能）来执行分类、回归和表示学习等任务。近年来，深度学习因其能够处理大量数据，并完成图像识别、自然语言处理、语音翻译和推荐等复杂任务而受到广泛关注。

神经网络（也称为人工神经网络）由称为神经元的连接节点组成。神经元是一种函数，它接收一个或多个输入，对这些输入应用权重，并将其求和以生成输入。这一计算过程称为前向传播（forward propagation）。

在前一页“2.14 神经网络”中，我们已经了解到，神经网络通常包含一个输入层、一个或多个隐藏层以及一个输出层。仅包含一个隐藏层的神经网络称为浅层神经网络（shallow neural network）。包含多个隐藏层的神经网络称为深度神经网络（deep neural network）。“深度学习”中的“深度”一词，指的是使用由多个隐藏层组成的神经网络。隐藏层数量的选择取决于问题的性质以及数据集的规模。

目前有多种广泛使用的深度学习模型，包括卷积神经网络（Convolutional Neural Networks，CNNs）、循环神经网络（Recurrent Neural Networks，RNNs）、生成对抗网络（Generative Adversarial Networks，GANs）以及 Transformer 模型。

- 卷积神经网络 (CNNs) 是一类特别适合处理结构化网格数据（如图像）的神经网络。CNN 在其至少一个网络层中使用一种称为卷积（convolution）的技术，而不是通用矩阵乘法。它们能够自动且自适应地从输入图像中学习特征的空间层次结构，从而支持图像分类和目标检测等任务。与传统前馈神经网络不同，RNN 具有循环连接结构，即网络连接会反馈到自身。这使得先前时间步的信息能够影响当前输出，从而使网络能够保留对历史输入的记忆。CNN 的局限性包括计算成本高、容易出现过拟合，以及仅适用于网格状结构的数据。
- 循环神经网络 (RNNs) 是一类专门用于处理序列数据的神经网络，因此特别适合需要考虑上下文和顺序信息的任务，例如时间序列分析、自然语言处理以及语音识别。RNN 的两个常见变体是长短期记忆网络（Long Short-Term Memory，LSTM）和门控循环单元（Gated Recurrent Units，GRUs）。RNN 的局限性包括梯度消失或梯度爆炸问题，以及训练时间较长。
- 生成对抗网络 (GANs) 是一种用于生成与给定训练数据集相似的新数据样本的深度学习模型。GAN 由两个神经网络组成，分别称为生成器（Generator）和判别器（Discriminator），两者相互对抗，因此被称为“对抗式（adversarial）”。GAN 擅长学习数据的结构和模式，并利用这些知识生成与原始数据集相似的新样本。它们可用于图像生成、文本生成图像以及数据增强等任务。GAN 的局限性包括训练过程不稳定以及资源消耗较大。
- Transformer 模型 是一类于 2017 年提出的深度学习模型。由于采用了自注意力机制（self-attention mechanism），Transformer 相较于 RNN 具有一定优势。该机制使模型在进行预测时能够衡量序列中不同单词（或标记，tokens）的重要性。这有助于模型理解上下文以及单词之间的关系，而不受其在输入序列中位置的影响。Transformer 已彻底改变了自然语言处理（Natural Language Processing，NLP）领域，并且现已广泛应用于文本以外的多个领域，包括图像处理和强化学习。Transformer 的局限性包括计算成本高以及对大量数据的依赖。

单元二｜分析与机器学习技术概述

语言模型 Language Models (LMs) 是经过训练以理解和生成人类语言的机器学习模型。语言模型利用统计和概率方法来计算特定词序列在句子中出现的可能性。从本质上讲，语言模型可以被视为词序列上的概率分布。语言模型通过学习来自书籍、文章、网站及其他文本来源训练数据中词语和短语之间的统计关系，来预测句子中的下一个词，或根据给定提示生成连贯的文本。

大语言模型 Large Language Models (LLMs) 是大规模的语言模型。在这里，“大”既指训练模型所需的大量数据，也指模型所包含的数十亿甚至数万亿个参数。

自20世纪60年代以来，实现当今大语言模型能力的发展历程已经持续了数十年。如今，我们在第 2.15 节深度学习中介绍过的 Transformer 已成为大语言模型最先进的架构。Transformer 的一个关键特征是自注意力机制（self-attention mechanism），该机制能够通过关注输入中最相关的部分来处理更长的序列，从而克服早期模型所面临的记忆限制。与按顺序逐步处理输入的早期循环神经网络（Recurrent Neural Networks，RNN）不同，Transformer 能够并行处理整个序列，因此显著缩短了训练时间。

大语言模型特别擅长其最初设计的任务，即根据给定输入生成最合理、最符合语境的文本。除此之外，它们还具有广泛的应用场景，例如问答、翻译、摘要生成、搜索、推荐、虚拟助手、代码开发以及情感分析等。

### 提示工程 Prompt engineering

提示工程是设计和优化输入内容（即提示词，prompts）的过程，其目的是与大语言模型（LLMs）有效沟通任务需求。由于大语言模型并不会以传统意义上的方式“理解”内容，因此指令的措辞方式对于输出结果的质量、准确性和实用性具有至关重要的影响。提示工程涉及精心选择用词、结构、上下文，甚至示例，以引导模型生成符合预期的回答。这种实践在代码生成、摘要生成、数据提取或创意写作等应用场景中尤为重要，因为这些场景对清晰度和可控性有较高要求。提示工程还包括一些特定技术，例如少样本提示（few-shot prompting，即提供示例）、思维链提示（chain-of-thought prompting，即鼓励逐步推理），以及通过设定角色或约束条件来塑造输出结果。 归根结底，提示工程是在创造性地、精准地运用语言;有多种 API 可供使用，让你能够将大语言模型（LLMs）应用于各种场景，以最大限度发挥人工智能系统价值的过程。 请参阅这篇文章 (https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-the-openai-api)，了解使用 OpenAI API 进行提示工程的最佳实践。

### 微调 Fine-Tuning

微调（Fine-Tuning）是一种用于使预训练大语言模型适应特定任务或领域的技术，其方法是在较小的任务专用数据集上继续对模型进行训练。大多数现代语言模型基于 Transformer 架构构建，并首先在大规模且多样化的文本语料库上进行训练，以学习通用语言模式。在微调过程中，开发人员会准备带标签的示例数据，并进一步训练模型，使其参数得到调整，从而能够针对目标任务生成更准确的输出。该过程通常包括选择基础模型、准备并分词（tokenise）数据集、使用优化算法训练模型，以及评估模型性能等步骤。与提示调优（prompt tuning）不同，提示调优会保持模型参数固定，仅优化特殊的提示词标记（prompt tokens）来引导模型输出；而微调则会直接更新模型权重（weights），使模型能够更深入地内化特定任务相关的知识，但同时也需要更多的计算资源和数据支持。由于需要利用大型数据集更新数百万甚至数十亿个参数，因此对大语言模型进行微调通常计算成本高昂且费用较高。该过程需要多次遍历训练数据，大量使用图形处理器（GPU）或张量处理器（TPU），并进行精细的优化以避免过拟合（overfitting），这些都可能转化为高额的云计算或硬件成本。完整微调（full fine-tuning）还会消耗大量存储空间和内存，因为针对每个专门化任务，通常都需要维护模型的独立副本。为了降低成本，开发人员通常会采用参数高效（parameter-efficient）的技术，例如，LoRA微调技术的应用与优化 (https://cloud.tencent.com/developer/article/2672597)。LoRA 仅更新模型中的一小部分参数，同时保持大部分权重被冻结（frozen），与完整微调相比，可以显著降低计算成本和财务成本。如需进一步阅读，请查看 大模型微调实战：从原理到落地的完整指南 (https://developer.volcengine.com/articles/7605549043544965158)

### 检索增强生成 Retrieval-Augmented Generation

检索增强生成是一种通过结合外部信息检索能力与大语言模型生成能力来增强大语言模型性能的技术。RAG 并非仅依赖于编码在模型参数中的知识，而是首先从相关文档数据库、知识库或语料库中检索与用户查询相关的信息。 随后，检索到的内容会被整合到模型的输入提示中，使模型能够生成更加准确、更加及时且具有更强上下文依据的回答。 与提示调优（prompt tuning）仅通过优化特殊标记（tokens）或指令来引导冻结模型的输出不同，也不同于微调通过任务专用数据更新模型内部权重的方式，RAG 在推理阶段（inference time）动态注入外部知识，而不会修改模型本身。 这一特性使 RAG 特别适用于需要专业知识、事实准确性或访问专有信息的任务，同时无需承担微调所带来的高成本和复杂性。 如需进一步学习，请参阅相关教程 (https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-the-openai-api)。

### 大语言模型的局限性 Limitations of LLMs

- 训练大语言模型（LLMs）成本高昂，因为其需要海量数据集以及大量计算资源。
- 大语言模型有时会生成不准确或虚构的信息，这种现象被称为“幻觉（hallucination）”。当模型生成的回答看似合理，但实际上在事实层面错误或毫无意义时，就会出现这种情况。
- 由于这些模型是基于人类语言进行训练的，因此可能引发一系列伦理问题，例如语言被滥用的风险，以及与种族、性别、宗教等因素相关的偏见问题。
