## 先講結論

1. 13 個裡:**優先 4 個**(1 短租登記冊、3 公眾假期、8 機場每月客流、9 出入境每月人數)、**次要 8 個**(2、4、5、6、7、10、11、12)、**這次用不到 1 個**(13 房產成交,買房投資 11/14 決定不做)。
2. **最有用的是 8 和 9**:我們 11/17 查了三個官方入口都找不到「雪梨按月淡旺季」,這兩個正好是按月的。8 是雪梨機場(要從新聞稿一則一則抄);9 是全國或各州的入境人數(不是雪梨,但有現成 Excel)。
3. **3 個要申請帳號或權限**:1(NSW Planning Portal 的 API 權限,要審核)、4(Transport Open Data Hub 註冊)、11(Ticketmaster API key)。這些要 Kenny 或隊友自己申請。
4. 連結 13 個:12 個開得了;**6(犯罪統計)那條是 404**,要請 Stanly 給新網址。
5. **第 2 個(用房源照片判斷裝修)要小組先決定**:它能補「資料沒有裝修欄」的缺口,也剛好是報告要的前沿 AI;但照片放在 Airbnb 的圖床上,抓下來合不合規要先確認,而且「照片好看」不等於「裝修好」,沒有標準答案可以驗。
6. Stanly 的文件把專案分成「模塊 1(找同類、地圖)」「延伸 1(房價)」「延伸 2(淡旺季和假期提醒)」「新房東避坑」。**「延伸 1 房價」和 11/14 的「買房投資不做」是什麼關係,今晚組會要對一下。**
