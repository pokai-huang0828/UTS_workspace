## 0. 一句話

**創新生態系(innovation ecosystem)**是一群行動者、活動、產出物與制度互相影響、共同產生創新的系統;講座聚焦生態系裡的「新創支援機構」—— **CAISH = Co-working spaces、Accelerators、Incubators、Startup Hubs**,用 NSW(新南威爾斯州)的盤點、27 個個案訪談,提出**四層次的影響衡量指標**和**五項政策建議**。

### A. 什麼是創新生態系(Slide 1–6)
- **Slide 1** 標題:Innovation Ecosystems — Focus on: The Impact of Co-working Spaces, Accelerators, Incubators, and Start-up Hubs (CAISH)。
- **Slide 2 定義**(Granstrand & Holgersson, 2020, *Technovation*):創新生態系是影響創新產生與運用、以及創新績效的一組元件和因果關係,由**持續演變的行動者(actors)、活動(activities)、產出物(artifacts),以及制度(institutions)與關係**組成。圖:Actors、Activities、Artifacts 三者互相影響、各自演變,外面包著 Institutions。
- **Slide 3 價值共創模型**(Russell & Smorodinskaya, 2018, *Technological Forecasting & Social Change*):中心是「產業聚落組織(三螺旋網絡 triple helix network)」,周圍六類行動者 —— 既有企業、創新新創、服務機構、大學與學界、創投與贊助者、地方政府 —— 互動共創價值;從在地與全球市場**輸入**商品、資本、人才,再把共創的商品、服務、知識**輸出**到市場。
- **Slide 4 國家層級的衡量**(標題寫來源 GII,圖本身是一張「Innovation Metrics Scorecard」):澳洲 19 項創新指標和前 5 名國家平均比較。重點:
  - **強項(第一四分位)**:企業雲端運算普及 60.1%(第 2/26 名)、法規進入障礙低(8/33)、教育支出(8/36)、經品質調整的勞動投入成長(5/36)。
  - **弱項(後段)**:企業研發支出 BERD 0.94% GDP(前 5 名平均 2.96%,20/35)、企業合作創新比例 12.6%(平均 31.4%,23/35)、海外智財申請(26/37)、創投投資 0.030% GDP(平均 0.19%)、100 Mbps 以上寬頻(30/34)、PISA 數學(24/35)、全國研發支出 GERD 1.79%(18/34)。
  - 一句話:**澳洲「用」技術很快,但「投資研發與合作創新」偏弱**。完整 19 項見 .txt。

### B. 定義 CAISH(Slide 7–9)
| 類型 | 定義重點 |
|---|---|
| **共享工作空間 Coworking space** | 彈性、共用的辦公空間,通常短期租約;幾乎沒有商業發展服務,也沒有技術設施 |
| **加速器 Accelerator** | 一種支援**計畫**:**梯次制(cohort-based)、固定期間**、有篩選(依產業、成長潛力);提供導師、同儕交流、商業技能訓練、**募資準備(investment readiness)**與投資人連結 |
| **育成中心 Incubator** | 提供新創**實體空間＋成長相關服務**;不是梯次制也不固定期間(可能有最長進駐期);和共享空間的差別在**有沒有提供服務**(募資準備、投資人連結、智財建議、技術支援、同儕交流) |
| **新創/創新聚落 Startup hub / Innovation hub** | 實體空間(大樓、園區),把加速器、育成、共享空間等**集中在一起**,而且彼此有刻意的協調 |

**Slide 9 五項特徵比較**(哈維球,滿格 = 4):
| 特徵 | 共享空間 | 加速器 | 育成中心 | 新創聚落 |
|---|---|---|---|---|
| 共享實體空間 | 4 | 1 | 4 | 2 |
| 梯次/固定期間 | 0 | 4 | 1 | 0 |
| 成長相關服務 | 1 | 4 | 3 | 2 |
| 人脈/活動 | 1 | 4 | 3 | 4 |
| 募資準備 | 0 | 4 | 4 | 2 |

### G. 影響衡量指標(Slide 20–26)⭐ 和數據分析最相關
**四個層次**:①個別創業者 ②新創 ③CAISH 機構本身 ④與 CAISH 接觸的更大生態系/環境。每層都有指標類別＋範例指標(括號是衡量單位):

| 層次 | 類別 | 範例指標 |
|---|---|---|
| **1. 個別創業者** | 人力資本 | 創業意圖與行動(量表)、自我效能與堅持(量表)、學習(技能與知識量表) |
| | 社會資本 | 人脈擴展與網絡密度(數量)、計畫的使用(數量、比例) |
| **2. 新創** | 企業成長 | 創造就業、募得資金、營收、新產品/服務與網站流量、創新產出(研發預算、專利/著作權)、高成長企業比例、**和沒接受 CAISH 支援的企業比較成長率** |
| | 企業存活 | 畢業(成功離開 CAISH 的家數)、存活(1 年、5 年後仍營運的家數) |
| **3. CAISH 機構** | 計畫吸引力 | 區內/區外申請數(每個名額幾人搶)、贊助與資金 |
| | 參與度 | 支援新創數(每年)、空間等資源使用率、**淨推薦值 NPS** |
| | 多元性 | 女性創辦人比例、創辦人多元比例、性別分布 |
| | 網絡 | 輔導時數、合作夥伴數、活動數、校友參與、研究合作數 |
| **4. 系統** | 多元性 | 受支援新創的員工性別分布、CAISH 計畫的人口覆蓋率 |
| | 市場發展 | 受支援新創所在產業/技術(數量、比例) |
| | 網絡參與 | 參與的夥伴數、擔任導師/顧問的支持者數 |
| | 在地創業生態成長 | 歸屬感(量表)、合作活動出席、吸引創投等行動者進入 |
| | 外溢效果 | 研究機構技術移轉數、失敗後再創業比例 |
| | 合作品質與深度 | 資源循環(創辦人回頭當導師、天使投資、分享閒置辦公室)、文化改變(較不怕失敗、更接受創業為職涯) |

- Slide 22 引用一位女性創辦人的話:大意是被看見、被認可為女性創辦人,給了團隊很大的信心(說明「自我效能」這類指標的意義)。

**Slide 26 衡量的發現與困難**:
- **證據不一致(mixed evidence)**:多數學術研究只看前三層;**系統層級資料很少**;CAISH 確實有助新創**取得資金**;其他指標的證據不一致、沒有定論。
- **衡量挑戰**:自填資料(self-reported)的準確性、難以標竿比較(benchmarking)、衡量很耗資源、缺乏標準化方法、**歸因困難(attribution)**(很難證明成長是 CAISH 造成的)。

### H. 五項建議(Slide 27–32)
1. **建立更合作的新創支援社群**:CAISH 之間競爭激烈 → 區分各自服務、多辦聯名活動、多做合作計畫(例如 Boosting Business Innovation Program, BBIP)、資助社群經營。
2. **加強區域生態系內外的連結**:區域 NSW 比大雪梨服務不足 → 需要在地主導的 CAISH、區域之間更多串連、把 CAISH 支援掛到各地的特別發展區(special activation precincts)。
3. **與弱勢群體共同設計(co-design)支援**:EDI 型 CAISH 有助建立信心、克服排斥;NSW 明確服務原住民(First Nations)創業者的 CAISH 很少 → 要讓原住民主導的組織參與共同設計。
4. **為政府介入建立證據基礎**:系統層級資料與個別機構影響數據都很缺 → 建一套**多層次框架**來收集政府資助 CAISH 的資料;「公地悲劇」:大家都想看產業層級指標,但沒誘因貢獻自己的數據 → 先和 Startup Muster 合作提供產業層級洞察。
5. **投資後期新創、規模化(scaleup)與國際化**:目前偏重早期新創 → 政府與 CAISH 提供規模化的清楚支援路徑;可導向 NSW 政府的 Going Global 計畫,也可另開針對 scaleup 的計畫。

## 2. 重點整理(5 句話)

1. 創新生態系 = 行動者＋活動＋產出物＋制度的互動系統;CAISH 是其中的新創支援節點。
2. 四類 CAISH 的差別看五個特徵:空間、梯次/期限、成長服務、人脈活動、募資準備。
3. NSW 2023 有 276 個 CAISH(全澳最多),但集中在大雪梨;區域 NSW 服務不足。
4. 影響要分**四層**衡量(創業者 → 新創 → 機構 → 系統),每層有明確的量化或量表指標;最難的是系統層資料與歸因。
5. 政策建議的核心之一是**缺數據**:要建立多層次的資料收集框架和產業層級指標。
