## 圖的樣子

左邊一欄 8 個「+」熱點(Images、Audio Data、Sensor Data、Social、GPS、Video、Internet、Other Data)→ 一堆彩色圓點匯成 **Big Data** → 箭頭 → **Cyclic Model(循環模型)** → 箭頭 → 大圓 **Database(數據庫)**。

圖片替代文字(alt):圖示顯示多個數據來源,包括圖像、音頻、傳感器、社交媒體、GPS、影片、網際網路和其他數據。這些數據匯集為「大數據」,通過循環模型進行處理並儲存在數據庫中。

## 8 個熱點內容(全文,轉繁體)

| 熱點 | 內容 |
|---|---|
| Images | 圖像數據(Image data):記錄圖像中各個位置的像素和顏色的數據。 |
| Audio Data | 音頻數據(Audio data):以數位數據形式記錄的聲音。 |
| Social | 社交數據(Social data):記錄社交網絡活動並儲存在社交網絡系統中的數據。 |
| Sensor Data | 傳感器數據(Sensor data):從不同來源記錄的數據,附帶不確定性資訊。 |
| GPS | GPS 數據:基於衛星的全球定位系統(Global Positioning System)數據。 |
| Video | 影片數據(Video data):由圖像幀和音頻數據組合而成的數據。 |
| Internet | 網際網路數據(Internet data):為實現設備與系統通過網際網路進行連接和資訊交換而記錄的數據。 |
| Other Data | 其他形式的數據(Other forms of data):其他可識別形式的數據。 |

(註:H5P 設定裡熱點順序是 Images、Audio、Social、Sensor、GPS、Video、Internet、Other;圖上 Sensor 排在 Social 前面,內容對應不受影響。)
