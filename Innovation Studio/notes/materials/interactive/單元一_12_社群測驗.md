## 題目全文(原文簡體 → 繁體;選項依我看到的順序)

### 第 1 題(1/3)

以下哪一項是適當的項目目標?請選擇 1 項。(工具顯示:最多選擇 3 個答案)

- 嘗試使用隨機森林、支持向量機和深度學習,以確定能否可靠地預測客戶流失。
- 針對擬議的客戶留存激勵計劃,識別具有流失風險的目標客戶,以實現客戶淨利潤最大化。
- 建立客戶詳細信息及流失結果數據庫,以便針對性地開展擬議中的客戶留存激勵計劃。

### 第 2 題(2/3)

根據上一題中的項目目標,以下哪些選項可以作為適當的項目具體目標?請選擇最適當的 3 項。

項目目標:「針對擬議的客戶留存激勵計劃,識別具有流失風險的目標客戶,以實現客戶淨利潤最大化。」

- 對使用該預測器推動擬議的客戶留存激勵計劃開展定量成本效益分析(quantitative cost-benefits analysis)。
- 報告隨機森林、支持向量機和深度學習應用於客戶流失預測時的相對性能。
- 評估該預測器的準確性。
- 研究至少四種不同機器學習方法的優缺點,以及這些方法對於客戶流失預測的適用性。
- 開發客戶流失風險預測器(適用於單個客戶)。
- 建立包含客戶詳細信息和流失結果、適用於機器學習與評估的數據庫。

### 第 3 題(3/3)

根據前兩題中的項目總目標和具體目標,以下哪些選項可以作為適當的項目可交付成果?請選擇最適當的 3 項。

項目總體目標:「針對擬議的客戶留存激勵計劃,識別具有流失風險的目標客戶,以實現客戶淨利潤最大化。」
項目具體目標:
1. 開發客戶流失風險預測器(適用於單個客戶)。
2. 評估該預測器的準確性。
3. 對使用該預測器推動擬議的客戶留存激勵計劃開展定量成本效益分析(quantitative cost-benefits analysis)。

- 面向利益相關者開展原型、評估和成本效益分析的演示與講解。
- 一份技術報告,涵蓋對預測器的評估,以及對擬議客戶留存激勵計劃的成本效益分析。
- 一個使用 Python 或 R 開發的概念驗證軟件預測器。
- 可維護的生產級儀表盤,集成客戶流失預測功能。
- 一套客戶流失風險預測器的設計方案,並將其集成至現有在線報告系統。
- 一篇探討機器學習應用於客戶流失預測之有效性的碩士學位論文,其中包含來自世界各地電信公司的案例研究。

## 第 3 題推論(我的推論,不是官方答案,僅供參考)

依 1.7「交付概念驗證＋評估報告」和 1.8「可交付成果成熟度」的說法,最合理的 3 項是:
1. 一份技術報告(預測器評估＋成本效益分析)→ 對應具體目標 2、3
2. 一個 Python 或 R 的概念驗證預測器 → 對應具體目標 1
3. 面向利益相關者的演示與講解 → 把結果交給決策者

不選的理由:生產級儀表盤＝成熟度遠超概念驗證、超出範圍;「設計方案＋整合進現有系統」＝整合不在範圍內;碩士論文＝研究類成果,跟這個業務專案的技術目標不對應。

## 老師想讓你想的事(這題很重要,直接對應 AT2)

- **總體目標(aim)要寫業務成果,不是技術手段**:「試試三種演算法」是手段、「建資料庫」是中間步驟,都不是 aim。正確的 aim 有「為了誰的什麼決策、要達成什麼業務價值(淨利潤最大化)」。
- **具體目標(objectives)要具體、可達成、可驗證**,而且全部完成就能達成 aim:做出預測器 → 評估準不準 → 算划不划算。「比較演算法性能」「研究四種方法優缺點」偏研究、不直接服務 aim。
- **可交付成果(deliverables)要是有形、可核對的產出,且成熟度要符合範圍**(設計報告 < 概念驗證 < 原型 < 可部署組件)。
- 這套「aim → objectives → deliverables」就是 **1.12 第二週目標設定活動**(討論區 831616,要先個人寫、再團隊定稿)和 **AT2 計畫報告**要寫的東西。
