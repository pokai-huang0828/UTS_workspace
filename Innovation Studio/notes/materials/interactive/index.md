## 重點結論

1. **8 個 Atomic 活動全部不計分**(工具設定 graded / isGraded = false;每週導覽頁也寫「閱讀以下每週學習頁面,並參與形成性(不計分)活動」)。
2. **同學回覆目前一則都看不到**:6 個討論中,4 個設定「先發文才能看」(1.3、1.15、單元一總結、單元二總結);另外 2 個(1.6、2.4)不用先發文也能看,而且 0 則 → 代表到 10/24 還沒有人發文(課程第 1 週 10/26 才開始)。
3. **Atomic 討論的 iframe 裡幾乎沒有題目**,只有「在此輸入你的回答……」之類的提示＋回覆框(1.6 連提示都沒有)。**真正的題目都寫在 Canvas 頁 iframe 上方**,已經收錄在 notes/01、notes/02。
4. **兩個社群測驗「只能交一次、交了不能改」**(allowResponseChanges = false),交了馬上看到結果。1.8 那個會打亂選項順序。
5. **1.8 第 1 題題幹寫「請選擇 1 項」,工具卻顯示「最多選擇 3 個答案」** → 照題幹只勾 1 個。
6. **genial.ly 4 個都是單頁靜態圖,沒有熱點、沒有隱藏內容**;Apple ID 那組有數字與拼字不一致(LinkedIn $69.9 vs $69.99;Disnep+/Disep+),而且頁面說「突出顯示 LinkedIn」但長條圖其實沒上強調色。
