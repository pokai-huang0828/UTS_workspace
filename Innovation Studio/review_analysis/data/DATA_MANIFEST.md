# 評論試跑樣本:資料清單(2026-11-21)

## 來源

- Inside Airbnb 雪梨 2026-09-16 期的 `reviews.csv.gz`(欄位:listing_id、id、date、reviewer_id、reviewer_name、comments)。
- 檔案位置:`scratchpad/insideairbnb_sydney/2026-09-16/data/reviews.csv.gz`(只在 Kenny 本機;約 230 MB,沒有複製進這個資料夾)。
- 讀檔時**不讀** reviewer_id、reviewer_name 兩欄。

## 怎麼抽的(`src/01_sample.py`,種子 42)

| 步驟 | 剩幾條 |
|---|---|
| 全部評論 | 829,163 |
| 只留「可比房源」6,639 間的評論 | 363,829 |
| 只留 2025-01-01 以後的 | 150,832 |
| 其中看起來是英文、至少 15 個字 | 104,775 |
| 其中長度在 150–1,200 字元之間(符合抽樣條件) | 76,479 |

- 2025 年以後的評論裡,**48.3% 短於 150 字元**(長度中位數 156 字元)。這些多半是一兩句話的好評,這次沒有抽。
- 符合抽樣條件的占 2025 年以後評論的 50.7%。
- 抽 50 條:**35 條隨機**抽;**15 條**從「評分最低一成的房源」(總評分 ≤ 4.5)的評論裡抽,目的是讓樣本裡有抱怨可以看。兩組合起來再打亂順序,編號 R01–R50。
- 50 條來自 50 間不同的房源。樣本長度中位數 378 字元。

## 要小心的地方

- 這 50 條**不是全部評論的縮影**:短評論沒抽、非英文沒抽、低分房源刻意多抽。所以「負評占幾成」這類數字不能往全體推。
- 英文判斷是很粗的規則(英文字母占九成以上),沒有用語言偵測套件。
- 樣本檔的 sha256 記在 `sample_stats.json`。
