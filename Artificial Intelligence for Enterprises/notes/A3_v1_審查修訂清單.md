## 一、整體判定

### 1.1 四條 rubric 的當前落點

**合計現況預估 = 82–85 分。** 若四項全部卡在優良天花板:21.25 + 25.5 + 25.5 + 12.75 = **85**。
這與獨立進行的數字事實查核給出的「85–88」預估**交叉吻合**,也與 A2a 的 88.75 幾乎同水位——
換句話說,**v1 現狀是在複製 A2a 的結果,不是超越它**。以 40% 權重計,等於把總成績再釘回中位數附近。

### 1.2 最關鍵的三個問題

**① 論證地基與 A1 直接矛盾(下檔風險,不只是上檔機會)**
v1 §1.1 的整條主線建立在「挑戰②(CDR/Macquarie)沒有任何 AI 對應 = 🔴 空白」。
但 A1 表二第②列白紙黑字寫著「數位顛覆與競爭(Macquarie +19%、CDR)| 速度軸:AI 加速信貸審批」,
A1 正文第四節更直接寫「第二,速度軸回擊 Macquarie 與 fintech」。
**「空白」是 v1 把速度軸抽離出來、降格成表格下方附註所製造出來的,不是 A1 的事實。**
評分者正是 A1 的批改人(自述每份看兩遍、一個字一個字看),5 分鐘答辯又專問決策論證,
而他 08-05 全場批評的普遍問題正是前後不一致(原話:「你說一,你推薦那個 random,但你後邊那個結果肯定不是」)。
一旦被問「你 A1 說審批加速就是在回應 Macquarie,現在為什麼變空白?」,選案支柱當場塌掉——
**這不是掉檔次,是 25 分項有掉到「良好」的實質風險。**(三位審查者獨立指出此點)

**② 「一年能省多少錢、賺多少錢」在整份 v1 裡答不出來(第三次踩同一顆雷)**
v1 唯一的金額算式是「房貸結餘 A$611.5bn × 假設流失率 × NIM 2.08% = 年度曝險」。三個結構性錯誤:
不做這個專案也存在的**存量曝險**不是專案**增量**;集團 NIM 套進房貸簿是高估(房貸為集團內低 margin 產品);
**整份提案完全沒有「留存優惠讓利成本」這一項**——這個系統的本質就是用降息換留客,給折扣就是直接壓縮 NIM,
理論上可能出現「挽回的收入 < 讓出的利差」,提案淨值為負。
這是 A1「門檻非可驗證,無基準值、目標值、期間」→ A2a「需要加強具體量化和對業務的影響」→ A3 的**第三次復發**,
同一位老師連續三次。他 08-05 原話:「我一年能省多少錢,我賺多少錢……老闆最喜歡看你省錢或挣錢。」

**③ 兩個 30 分項的 HD 要件各缺一塊明文要素,是逐字比對就能發現的缺項**
Project plan 的「資源」零覆蓋(只有一句「成本區間必須以區間+假設呈現」的自我指示);
Description 的「可行性評估」沒有對應頁面(最接近的第 5 頁講的是「方法在**電信資料集**上可行」,
不是「**在 CBA** 可行」,是不同命題)。
**缺明文要件,無論其他部分寫得多好都上不了 HD。** 而這兩塊的補救**完全不需要外部事實**:
人月是提案人的規劃值不是事實宣稱,可行性評估是把已有素材重新編排——是全份投報比最高的兩處。

### 1.3 一條策略性判斷

老師 08-05 說「即使是錯的,如果說你的論述也是對的,我一般我都給了」+「資料不必真實,只要能自圓其說,但別太離譜」。
→ **論述鏈的完整度優先於數字的絕對正確。**
v1 §八「絕不編造」的紀律方向正確,但**執行方式(留白)恰好會重現 A1 的原扣分理由**:
投影片上出現「—」和「待內部資料」的空格,他看到的就是「無基準值、目標值、期間」。
**正解不是留白,是「標明為假設 + 假設的依據 + 低/中/高情境 + 敏感度反解」。**
本清單所有涉及數字的建議都照這個原則寫。
