# notes/ 命名與分工規則

> 2026-07-25 建立。**既有檔案不改名**——handoff.md 是 append-only,改名會讓歷史 entry 的路徑全部指空(實查:改名會斷 24 處引用)。本檔的作用是讓**新增**檔案不再走偏。

## 日期前綴:看是「事件」還是「活文件」

| 類型 | 規則 | 例 |
|------|------|-----|
| **事件快照**(當天發生、之後不再改) | **加** `YYYY-MM-DD_` 前綴 | `2026-07-16_Zoom_週四場_李春平_摘要.md` |
| **活文件**(會持續更新) | **不加**日期,靠 git 看版本 | `A2a_作戰計畫.md`、`A1_成績復盤與優化清單.md` |

判準:「這份三週後還會被我改嗎?」會 → 不加日期。

## 資料夾分工

| 資料夾 | 放什麼 | 不放什麼 |
|--------|--------|----------|
| `notes/`(根) | 經過整理、可直接用的摘要與計畫 | 逐字原文 |
| `notes/raw/` | **一手來源逐字落檔**,分析時當基準,不編輯 | 整理過的東西 |
| `notes/transcripts/` | Zoom 逐字稿(語音+聊天室) | 摘要 |
| `notes/practice/` | 練習用 notebook(含輸出) | 交件用 notebook(那些放 `AssessmentX/`) |

## `raw/` 的尾綴有區別,不要統一

- `_raw.txt` = **頁面/成績單逐字落檔**(Canvas 原文照抄)
- `_extract.txt` = **從既有檔案抽取**的內容(例:`A1_body_extract.txt` 是從 docx 抽出的正文)

兩者來源不同,分開命名是刻意的。

## 「rubric」保留英文

課程與 Canvas 都用 rubric 這個詞,檔名沿用以便搜尋。**不要**改成「評分規準」。
