## 四、Unit 2 概念重點(老師講授;Kenny 已讀到 3.2.1,可當複習對照)

1. **資料處理是 A2/A3 的地基**:先理解問題 → 定義預測目標(target)→ 分析欄位是否有用(給了資料庫不代表每個 column 都有用)→ 統計描述/圖表檢驗 → 清洗 → 轉換 → 得到高品質資料集,**然後才**選模型;不是「哪個模型火就試哪個」。
2. **Pareto 80/20**(Unit 2.3.1):資料分析師 80% 時間花在理解/清洗/整理資料,20% 才是實際分析。
3. **基本概念**:資料集 = 多個 data objects(客戶/交易/產品…);描述 object 的欄位 = features;組合起來 = feature vector。
4. **四種常見屬性類別**(老師展示投影片但只細講兩種;課堂小考:「頭髮顏色」= **nominal** 標稱屬性):nominal 無序(城市:悉尼/墨爾本/上海/北京)、類 ordinal 的可比較屬性(會員等級、客戶滿意度)——另外兩種(Unit 教材中的 interval/ratio)課上未展開。**nominal 特徵要先轉換(如 encoding)才能餵模型**;不同模型對不同屬性類別表現不同 → 屬性分析決定模型選擇與前處理。
5. **統計描述與正規化**:平均數易受極端值影響;選平均數/中位數/最大值做正規化前,先看分布(居中/常態/離散)。
6. **缺失值與極端值**:先判斷是**錄入錯誤還是真實特定值**,不能機械刪除;不管用哪種常見處理法(如平均值代替),都要能**解釋為什麼這麼選 + 預測它對後續建模的影響**——A2a notebook 裡每步處理都該有這種說明。
7. **資料品質五面向**:準確性、完整性、一致性、時效性、**可解釋性**。可解釋特徵範例:購買日期本身無意義 → 轉成「距上次購買間隔天數」就能解釋購買行為(feature engineering 思路)。
8. **可視化每一個特徵的分布**:不只為報告好看,是檢查偏斜、異常值、類別是否重疊(類別分得開 → 模型好學、表現好;高度重疊 → 分類難達預期)。Unit 2 練習多,老師建議多練。
9. **模型層面量力而行**:「Python module library 裡的這些模型基本上就夠用」(老師原話,未點名套件;前一晚管濟偉場明確提過 scikit-learn),可用簡單模型/cluster 的**組合**提升表現;重新架構模型不必要。表現力上限取決於資料處理與理解深度。
