## 一、組版:`build_deck.py` 是版面庫,`build_deck_v3.py` 是內容

`build_deck_v3.py` 只做一件事 —— 從 `build_deck.py` import 版面 helper,然後逐頁擺內容。
**v4 照抄這個結構,新開 `v4/scripts/build_deck_v4.py`。**

### 可用的常數(from `build_deck.py`)

```
FIG                 圖檔目錄(v4 要改指到 v4/figures)
NAVY RED GREY DARK WHITE LIGHT     RGBColor
FONT = "Microsoft JhengHei"
W H                 版面尺寸(16:9)
TOP = 1.05          標題下緣
BOT = 0.70          底部註記區
SAFE_R              右下淨空區(留給錄影人像小窗)
SECTIONS = ["介紹", "AI 機會", "業務影響", "效益與衡量", "項目計畫"]
```

### 可用的 helper

| 函式 | 用途 |
|---|---|
| `txt(slide, x, y, w, h, text, size=18, color=DARK, bold=False, spacing=…)` | 純文字框 |
| `header(slide, title, section_idx, sub=None)` | 頁首標題 + 五段導軌高亮(`section_idx` 對 `SECTIONS`) |
| `picture(slide, name, top=…, avoid_safe=True, maxw=…, maxh=…, left=…)` | 置圖,**自動避開右下淨空區** |
| `note(slide, text, color=GREY, size=11)` | 底部一行註記 |
| `card(slide, x, y, w, h, title, body, col=NAVY, tsize=13, bsize=11)` | 標題色塊 + 內文卡片 |

### v3 的每頁樣式(v4 照用)

- **內容頁**:`header(...)` + `picture(...)` + `note(...)`
- **摘要 / 結論頁**:`header(...)` + 四張 `card(...)` 橫排(卡寬 `cw = 2.62`、間距 `gap = 0.16`、起點 `x = 0.55`)+ 一段大字 `txt(...)`
- **參考文獻頁**:`header(...)` + 一大塊 `txt(..., size=13, spacing=1.5)`

⚠️ **v4 是 10 頁內容 + 1 頁引用 + 封面 = 12 張投影片**(v3 是 14 張,超了)。

## 二、出圖:`make_figs_v3.py` 的 helper 直接搬

**字型與負號已經處理好,不要再踩**:

```python
plt.rcParams["font.sans-serif"] = ["Microsoft JhengHei"]
plt.rcParams["axes.unicode_minus"] = False   # ← 這行就是 U+2212 缺字的解方
```

### 可用的 helper

| 函式 | 用途 |
|---|---|
| `save(fig, name)` | 同時輸出 **png + svg,300 dpi**,`bbox_inches="tight"`,白底 |
| `newfig(w=12.5, h=6.4, title=None)` | 開一張 0–1 座標的空白畫布,可帶標題 |
| `box(ax, x, y, w, h, text, fc, fs, tc, ec, lw, bold, ls)` | 圓角方塊 + 置中文字 |
| `panel(ax, x, y, w, h, title, body, col, tfs, bfs, fc)` | 有色標題列的面板(最常用) |
